# Blender UI Swedish vertex terminology review

Date: 2026-10-19
Project: Blender UI / UI / Swedish
Scope: Live Weblate query `target:vertex`.

## Terminology applied

* `vertex` is translated as `hörnpunkt`.
* Compounds use `hörnpunkts-`, for example `hörnpunktsgrupp`, `hörnpunktsfärg`, `hörnpunktsnormal` and `hörnpunktsindex`.
* Literal API identifiers and method names remain unchanged, including `vertex_indices_set` and `VertexGroup.add()`.

## Live review

The 217 query hits were reviewed in Weblate. User-facing Swedish occurrences of `vertex` were converted to the terminology above. Remaining English spellings in translated text are literal Blender/Python API identifiers or enum values and were intentionally retained.

Examples updated in the live component include export options, vertex colour controls, vertex group controls, geometry-node descriptions, mesh operations and glTF export strings.

This is a review record. The current component PO could not be downloaded from Blender Translate for a source-equivalent archive.
