# Blender UI – granskning av övre fältet (2026-11-08)

Fem tidigare odokumenterade strängar i Blenders övre fält granskades i
`space_topbar` och dess menydefinitioner. De gäller projektväljaren och listan
över nyligen använda filer/projekt.

| Engelska | Svenska | Bedömning |
| --- | --- | --- |
| Other Recent Files | Övriga senaste filer | Korrekt. |
| New... | Ny... | Korrekt kort menyetikett. |
| Clear Recent Projects List... | Rensa listan över senaste projekt… | Korrekt och idiomatiskt. |
| No Recent Projects | Inga senaste projekt | Korrekt. |
| Project: {} | Projekt: {} | Korrekt; platshållaren bevarad. |

Ingen textändring behövs och därför finns ingen importfil för gruppen.
