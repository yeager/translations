# Blender UI – projektfel, svensk sats 2026-10-21

- 11 strängar granskade och skickade till Blender Translate.
- XML välformad med 11 svenska målsträngar.
- `svlang skrivregler` och Hunspell kördes på målsträngarna.
- Gitleaks: inga fynd i exporten.
- Weblate: den filtrerade kön `state:empty` nådde slutet efter inskick.

Hunspell kan markera facktermer och namn; resultaten har granskats i sitt sammanhang.
