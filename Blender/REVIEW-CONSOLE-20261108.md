# Blender UI – Python Console, 2026-11-08

Den aktuella exportens 15 tidigare ospårade strängar för Blenders inbyggda
Python Console har granskats rad för rad. Konsolen är en programmeringsyta;
termer som *skript*, *konsol* och *kontext* har därför kontrollerats mot
Blenders UI-kontext och inte normaliserats som allmän prosa.

## Granskade och behållna

| Engelska | Svenska |
| --- | --- |
| Zoom In / Zoom Out | Zooma in / Zooma ut |
| Copy / Paste / Cut | Kopiera / Klistra in / Klipp |
| Copy as Script | Kopiera som skript |
| Move to Previous Word / Move to Next Word | Gå till föregående ord / Gå till nästa ord |
| Move to Line Begin / Move to Line End | Flytta till radens början / Flytta till radslut |
| Delete Previous Word / Delete Next Word | Ta bort föregående ord / Ta bort nästa ord |
| Backward in History / Forward in History | Bakåt i historien / Framåt i historien |
| Context changed during paste, console execution may be incomplete | Kontexten ändrades under inklistringen, körningen i konsolen kan vara ofullständig |

Samtliga 15 målsträngar är korrekta och konsekventa. Ingen deltafil skapades,
eftersom en identisk uppladdning bara skulle hoppas över av Weblate.

## Avgränsning

Detta dokumenterar lokal radgranskning mot `blender-ui-ui-sv (5).po`. Det
bevisar inte ett importresultat eller granskningsstatus på Blender Translate.
