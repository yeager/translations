# Blender UI – Hair Nodes-guidekurvor, batch 1 262

Beskrivningen för interpolering av hårkurvor använde det allmänna låneordet
*guider*, trots att samma nod och projektets terminologi använder
**guidekurvor**. Den här enpostsbatchen normaliserar den specifika
Hair Nodes-betydelsen utan att ändra andra, orelaterade användningar av
*guide* i Blender.

| Källa | Granskad svensk text |
| --- | --- |
| Splits guides into separate groups. New curves interpolate existing curves from a single group | Delar upp guidekurvor i separata grupper. Nya kurvor interpolerar befintliga kurvor från en enda grupp |

Kontroller som passerade: `msgfmt`, l10n-lint, svlang (konsekvens,
skrivregler och svengelska), Hunspell, diffkontroll och Gitleaks.
