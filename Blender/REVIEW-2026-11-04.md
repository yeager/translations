# Blender UI – kontrollgenomgång 2026-11-04

## Omfattning

Granskning av samtliga fem aktiva Weblate-kontroller av typen
`check:reused` i komponenten **Blender UI / UI / svenska**.

## Resultat

Samtliga fem kontroller var riktiga svenska återanvändningar och avfärdades
individuellt i Blender Translate. De ändrades inte enbart för att tysta en
kontroll.

| Källsträng | Svensk text | Bedömning |
| --- | --- | --- |
| `Add-ons` | `Tillägg` | Källsträngarna *Add-on*, *Extension* och pluralformerna betecknar samma UI-begrepp. |
| `Asset Libraries` | `Resursbibliotek` | Singularformen *Asset Library* delar korrekt den svenska UI-etiketten. |
| `Import SVG as Grease Pencil` | `Importera SVG som Grease Pencil` | Samma sakbegrepp som den kortare källsträngen *SVG as Grease Pencil*; produktnamnet behålls. |
| `Extensions` | `Tillägg` | *Add-on* och *Extension* används som samma begrepp i Blenders inställningar. |
| `Extension` | `Tillägg` | Singularformen delar korrekt målterm med närliggande UI-rader. |

## Terminologisk slutsats

Kontrollen får inte användas som skäl att skapa konstlade svenska synonymer.
För Blender ska terminval i stället styras av sammanhanget och den etablerade
svenska katalogen. Se [TERMINOLOGY.md](TERMINOLOGY.md).

## Verifiering

- Weblate-sökningen `check:reused` gav inga återstående träffar efter
  genomgången.
- Texten är granskad med `svlang skrivregler`.
- Filen är skannad med Gitleaks.
