# Widelands Add-Ons: Website Maps — karttitlar

Widelands 1.3.1 släpptes 2026-02-22. Batchen kompletterar två beskrivande
karttitlar i Website Maps.

- Resurs: `o:widelands:p:widelands-addons:r:websitemaps`
- Språk: svenska (`sv`)
- Omfattning: 2 tidigare oöversatta karttitlar
- Källkontext: `po/websitemaps/sv.po`, `input:10`

Resursens befintliga titelpraxis är etablerad: `Coastal Mountainsides` är
redan översatt till `Kustnära bergssluttningar`, och andra generiska titlar
översätts till svenska. Versionstillägget `v1.1` bevaras.

Lokal kontroll med `msgfmt`, `l10n-lint`, svlang, Hunspell-sv, diffkontroll
och Gitleaks passerade utan fel eller fynd. Hunspell-sv markerar endast
versionsbeteckningen `v1.1`. Båda strängarna sparades i Transifex den
2026-11-14 och återlästes med rätt måltext. Resursens `translated:no` visar
nu 26 återstående strängar. Kontot saknar granskningsbehörighet, så
Transifex visar översättningarna som ogranskade.
