# Granskade svenska kartutmaningar

Fyra korta kartbeskrivningar och utmaningstexter har granskats och sparats i Transifex. Radbrytningarna i kartbeskrivningen bevaras.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 50 till 46 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
