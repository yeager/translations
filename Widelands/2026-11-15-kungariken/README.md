# Granskade svenska beskrivningar för kungariken

Fyra kartbeskrivningar med bristfälliga engelska källtexter har skrivits om till sammanhängande svensk speltext och sparats i Transifex.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 25 till 21 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
