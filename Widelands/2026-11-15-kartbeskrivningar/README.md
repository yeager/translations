# Granskade svenska kartbeskrivningar

Fyra beskrivande strängar för karttillägg har granskats och sparats i Transifex.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 58 till 54 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
