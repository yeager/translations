# Granskade svenska poängtermer

Tre sammanhängande strängar för poängberäkning i tillägget har granskats och sparats i Transifex. Formuleringarna använder projektets etablerade term `militärbyggnad` och den befintliga termen `erövringsområde`.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 76 till 73 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
