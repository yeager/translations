# Granskade svenska stridsvärden

En förklarande byggnadspoäng och tre sammanhängande strängar om soldaters effektiva styrka har granskats och sparats i Transifex.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 69 till 65 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
