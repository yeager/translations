# Widelands Add-Ons: Europeans Map Modified

Widelands 1.3.1 släpptes 2026-02-22. Resursen innehåller två tidigare
oöversatta varianter av samma färgnyckel för Europakartan.

- Resurs: `o:widelands:p:widelands-addons:r:europeans-map-modified-wad`
- Språk: svenska (`sv`)
- Omfattning: 2 tidigare oöversatta färgnycklar
- Källkontext: `europeans_map_modified.wad`

De befintliga svenska varianterna med mellanrum kring likhetstecknet används
som projektintern översättningsminneskälla. Den engelska stavvarianten
`Vkings` normaliseras till svenska `vikingar`.

Lokal kontroll med `msgfmt`, `l10n-lint`, svlang, Hunspell-sv, diffkontroll
och Gitleaks passerade utan fel eller fynd. Båda strängarna sparades i
Transifex den 2026-11-14. En färsk återläsning av `translated:no` visade 0
oöversatta av resursens 8 strängar och båda måltexterna överensstämde exakt
med deltafilen. Kontot saknar granskningsbehörighet, så Transifex visar
översättningarna som ogranskade.
