# Granskade svenska poängetiketter

Fyra etiketter för poängöversikten har granskats och sparats i Transifex.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 73 till 69 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
