# Widelands Add-Ons: Basic Outpost

Widelands 1.3.1 släpptes 2026-02-22. Basic Outpost är ett startvillkor som
ger färre varor än ett fullständigt startläge, men tillräckligt med resurser
för att bygga några verktyg och komma igång snabbare.

- Resurs: `o:widelands:p:widelands-addons:r:basic-outpost-wad`
- Språk: svenska (`sv`)
- Omfattning: 1 tidigare oöversatt tilläggsbeskrivning
- Källkontext: `addons/basic-outpost.wad/addon`

Terminologin följer Widelands befintliga svenska kataloger: `startvillkor`,
`Kämpande utpost` och `Enkel utpost`. HTML-radbrytningarna bevaras som
platshållare.

Lokal kontroll med `msgfmt`, `l10n-lint`, Hunspell-sv, diffkontroll och
Gitleaks passerade utan fel eller fynd. svlang markerar två falska
V2-varningar för korrekta huvudsatser. Strängen sparades i Transifex den
2026-11-14; en färsk återläsning av `translated:no` visade 0 oöversatta av
resursens 3 strängar. Båda `<br>`-taggarna och den escaped-kolon som finns i
källsträngen bevarades. Kontot saknar granskningsbehörighet, så Transifex
visar översättningen som ogranskad.
