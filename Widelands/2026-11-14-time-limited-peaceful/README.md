# Widelands Add-Ons: Time Limited Peaceful

Widelands 1.3.1 släpptes 2026-02-22. Det här skripttillägget begränsar det
fredliga spelläget till ett antal minuter. Den enda saknade svenska strängen
är tilläggets beskrivning.

- Resurs: `o:widelands:p:widelands-addons:r:time-limitted-peaceful-wad`
- Språk: svenska (`sv`)
- Omfattning: 1 tidigare oöversatt tilläggsbeskrivning
- Källkontext: `addons/time-limitted-peaceful.wad/addon:6`

HTML-radbrytningarna och filnamnet `init.lua` bevaras. Befintliga svenska
strängar i samma resurs använder `fredligt läge` för *peaceful mode*.

Lokal kontroll med `msgfmt`, `l10n-lint`, Hunspell-sv, svlang, diffkontroll
och Gitleaks passerade utan fel eller fynd. Hunspell-sv och svlang behandlar
endast filnamnet `init.lua` som ett ovanligt ord.

Strängen sparades i Transifex den 2026-11-14. Plattformens taggkontroll
verifierades särskilt efter sparning: båda `<br>`-taggarna bevarades som
platshållare. En färsk återläsning av `translated:no` visade 0 oöversatta av
resursens 7 strängar. Kontot saknar granskningsbehörighet, så Transifex visar
översättningarna som ogranskade.
