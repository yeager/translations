# Granskad svensk poängberäkning

Två förklarande strängar om soldatstatistik och poängberäkning har granskats och sparats i Transifex.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 65 till 63 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
