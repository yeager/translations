# Granskade svenska militärpoäng

Fyra förklarande strängar om militärbyggnader, soldatpoäng och områdespoäng har granskats och sparats i Transifex. `Lagerbyggnad` följer etablerad svensk Widelands-terminologi.

Statusen är `uploaded-and-read-back`: sparandet bekräftades genom att den öppna strängräknaren minskade från 63 till 59 efter omladdning. Detta innebär inte någon uppströmsgranskning eller sammanslagning.
