# Warzone 2100 – speltext, svensk terminologi

Gäller den lokala kampanj 1-batchen från 2026-11-13. Besluten bygger på källans uppdrags- och briefingkontext; de ersätter inte webbplatsens separata terminologibeslut.

| Engelska | Svenska | Kontext |
| --- | --- | --- |
| objective | mål | Uppdragsmål och markörer. |
| artifact | artefakt | Återställningsbart forskningsföremål. |
| Scavenger | skrotare | Faktion och dess styrkor i kampanjen. |
| synaptic link / synaptic link technology | synapslänk / synapslänksteknik | Centralt tekniskt begrepp i berättelsen. |
| forward base | framskjuten bas | Tillfällig offensiv bas i ett uppdrag. |
| transport | transporten | Spelets transportfarkost i uppdragsbriefingar. |
| truck | konstruktionsfordon | Enhetstyp som bygger försvar och uppgraderar byggnader. |
| power generator | energigenerator | Basbyggnad som tar emot energimodulen. |
| power module | energimodul | Artefakt som uppgraderar energigeneratorn. |
| landing zone | LZ | Synlig förkortning i uppdragstexten; behålls oförändrad. |
| The Project | projektet | Löpande berättelsetext i denna batch. |
| New Paradigm / NEXUS | New Paradigm / NEXUS | Fraktions- och egennamn som behålls. |
| The Collective | The Collective | Fraktionsnamn som behålls i berättelsetext och UI. |
| VTOL | VTOL | Synlig teknisk förkortning för vertikal start och landning. |
| NASDA | NASDA | Organisationsnamn som behålls. |
| convoy | konvoj | Fientlig eller egen transportstyrka i uppdragsmål. |
| containment camp | interneringsläger | Plats där civila hålls fångna i kampanj 2. |
| bring online | driftsätta | Ta reaktorn i aktiv drift. |
| satellite uplink site | satellitlänksplats | Anläggning för kommunikation med satelliter. |
| SAM site | SAM-ställning | Luftvärnsrobotställning; förkortningen bevaras i uppdragstiteln. |
| safe haven | säker zon | Evakueringsplats som spelaren ska upprätta. |
| missile silo | robotsilo | Byggnad som rymmer och avfyrar robotar. |
| warhead | stridsspets | Kärnvapenrobotens explosiva del. |
| high orbit | hög omloppsbana | Rymdteknisk kontext i satellituppdraget. |
| away team | insatsgrupp | Fristående styrka i kampanj 3. |
| task force | insatsstyrka | Organiserad fientlig styrka i ett uppdragsmål. |
| ambush | lägga ett bakhåll | Aktivt uppdragsmål mot NEXUS-styrkor. |
| site of operations | operationsbas | Bas som erbjuds för fortsatta operationer. |
