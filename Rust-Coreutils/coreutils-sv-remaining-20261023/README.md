# Rust Coreutils: återstående svenska poster

Dessa Fluent-filer innehåller de sju tomma och två posterna markerade som behov av redigering i Hosted Weblate den 23 oktober 2026. Formuleringarna har jämförts med den granskade GNU Coreutils-mallen i `tp-sv/coreutils-9.12-pre1.sv.po`.

Komponenten `join` var låst i Hosted Weblate eftersom arkivet inte kunde slås samman. Filerna är därför en granskningsbar delta och ska lämnas som förslag tills komponenten låses upp.
