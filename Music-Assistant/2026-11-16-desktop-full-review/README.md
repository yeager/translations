# Music Assistant Desktop – fullständig svensk granskning

Datum: 16 november 2026

Skrivbordsappens 159 svenska strängar har granskats rad för rad. Elva
språkrättningar sparades via Lokalise API och varje ändrat värde lästes
sedan tillbaka från tjänsten.

Rättningen omfattar bland annat huvudmenyn **Arkiv**, verbformen **Zooma**,
naturligare svensk benämning på den kompletterande appen och **läsas in** för
inställningsfilen. Tankstrecket i produktnamnet följer källtextens struktur.

`qa-sv.json` har kontrollerats med svlang och Hunspell-sv. `changes.json`
är underlaget för ändringarna. En sparad och återläst översättning betyder
inte att en ny programversion har byggts eller publicerats.
