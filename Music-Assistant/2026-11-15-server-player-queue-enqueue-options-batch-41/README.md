# Music Assistant Server – köalternativ för spelarköer, batch 41

Datum: 2026-11-15

Trettiosex svenska UI-texter för inställningarna som bestämmer hur album,
artister, ljudböcker, mappar, genrer, direktingångar, spellistor, poddar och
spår köläggs i spelarkön.

Status: lokalt granskad och arkiverad. Albumets beskrivning finns redan med en
annan svensk formulering i Lokalise och lämnades orörd 2026-11-15. Övriga
nycklar måste jämföras med Lokalise före eventuell manuell sparning.
