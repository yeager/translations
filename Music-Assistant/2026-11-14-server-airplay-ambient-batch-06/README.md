Datum: 2026-11-14

Elva radgranskade svenska strängar för AirPlay-mottagaren och Ambient Sounds.

rosa och vitt brus följer projektets terminologilista.

- Lokalise-uppladdning: väntande.
- `l10n-lint` och `svlang`: godkända.
- `msgfmt`: inte tillämpligt på JSON.
