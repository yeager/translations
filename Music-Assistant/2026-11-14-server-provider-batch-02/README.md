# Music Assistant Server – svensk leverantörsbatch 2

Datum: 2026-11-14

Komponent: `music-assistant/server`, Lokalise-projektet **MA Server**.

Åtta svenska strängar för Ambient Sounds. De beskriver ljudprofiler i musikbiblioteket, inte tekniska inställningar. Översättningarna använder etablerade svenska ljudtermer och bevarar den lugna, beskrivande tonen.

| Källa | Svenska |
| --- | --- |
| Brown noise | Brunt brus |
| Pink noise | Rosa brus |
| White noise | Vitt brus |
| Ocean waves | Havsvågor |
