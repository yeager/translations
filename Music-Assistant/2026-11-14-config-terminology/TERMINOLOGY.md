# Music Assistant server — svensk terminologi

Datum: 2026-11-14

| Källa | Svenska | Anmärkning |
| --- | --- | --- |
| Smart | Intelligent | Konfigurationslägen, inte egennamn. |
| Smart shuffle | Intelligent slumpning | Köalgoritm som varierar urvalet utifrån nyligen spelat innehåll. |
| Smart crossfade | Intelligent övertoning | Väljer övergång utifrån spårparets analys. |
| Flow Mode | köflödesläge | Beskriver en enda sömlös ljudström för kön. |
| sample rate | samplingsfrekvens | Etablerad ljudteknisk term. |
| resample | sampla om | Används i den konkreta ljudinställningskontexten. |
| crossfade | övertoning | Samma term används i spelarinställningarna. |
| queue playback | köuppspelning | Namn på kategorin för köns uppspelningsbeteende. |
| player controls | spelarkontroller | Namn på kategorin för spelarens kontroller. |
| plugin | insticksmodul | Används för utbyggnadskomponenter i gränssnitt och dokumentation. |
| offset | förskjutning | Sendspin: justering för synkronisering i millisekunder. |
| static playback delay | fast uppspelningsfördröjning | Sendspin: bestående, manuellt angiven fördröjning. |
| scan genre mappings | sök igenom genremappningar | Bakgrundsåtgärd; undviker det onödiga lånet *skanna*. |
| codec | kodek | Svensk fackterm; formatnamn som AAC, FLAC och PCM behålls. |
| soundtrack | filmmusik | Synligt musikgenre-/biblioteksnamn. |
| marching band | marschorkester | Musikgenre, inte den bredare aktiviteten marschmusik. |
| spoken word | talad text | Musikgenre-/bibliotekskontext. |
| brown noise | brunt brus | Etablerad ljudterm för brus med tyngd i låga frekvenser. |
| pink noise | rosa brus | Etablerad ljudterm för brus med avtagande energi vid högre frekvenser. |
| white noise | vitt brus | Etablerad ljudterm för jämnt fördelat frekvensinnehåll. |
| load/import | läs in / importera | *Läs in* för lokalbibliotekets inläsning, *importera* för uttalad importåtgärd. |
| render (TTS) | syntetisera | I talsynteskontext beskriver *syntetisera* resultatet tydligare än den generella termen *återgivning*. |

Behåll produkt-, standard- och formatnamn när de är synliga identifierare: exempelvis AirPlay, DTS, ICY, OAuth, PCM och Pure Direct. Internationellt etablerade genrenamn som jazz, soul, reggae och tango är avsiktligt oförändrade.
