# l10n-lint 1.23.33 — TOML support

Date: 2026-11-14

`l10n-lint` now reads TOML localization catalogs, including nested tables and
string lists. TOML values are treated as target-only translations; table and
key paths provide context. Reference comparison reports missing and obsolete
key paths.

Validation completed before release:

- `pytest`: 389 passed.
- TOML tests also passed on Python 3.9, exercising the `tomli` fallback.
- `msgfmt -c`, diff check and Gitleaks passed.
- Source distribution and wheel were built and the installed wheel was smoke-tested.
- GitHub Actions passed on Python 3.9, 3.11 and 3.14, plus the GTK smoke test.
