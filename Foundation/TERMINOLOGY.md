# Foundation – svensk terminologi

Terminologilistan gäller Foundation i Crowdin och används vid fortsatt svensk granskning.

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| backer | finansiär | Används för personer som stöttat projektet. |
| building | byggnad | Inte *hus* när termen är generell. |
| building part | byggnadsdel | |
| content | innehåll | |
| DLC | DLC | Oböjt i UI; skriv `DLC har` i plural. |
| enable / enabled | aktivera / aktiverad | För funktioner, DLC och lägen. |
| disable / disabled | inaktivera / inaktiverad | |
| feature | funktion | |
| founder | grundare | `Founders Church` behålls som produktnamn när det avser tillägget. |
| game save / save | sparfil | Inte *spelsparning* i kort UI. |
| load save | läsa in sparfil | |
| menu | meny | |
| newsletter | nyhetsbrev | `Sign up` → `Prenumerera`. |
| preview | förhandsvisning | |
| request | begäran | |
| save file | sparfil | |
| village | by | |
| workbench | arbetsbänk | För FreeCAD-relaterade tillägg, inte Foundation. |

## Stilregler

- Bevara namn på DLC, byggnader, egenskaper och interna nycklar exakt när de är produktnamn eller kodliknande, till exempel `Founders Church`.
- Bevara radbrytningar, variabler, HTML/markup och skiljetecken från källan.
- Använd normal svensk meningsstil, inte engelsk rubrikstil, om det inte är ett varumärke eller en synlig kommandotext.
- Föredra korta verb i knappar: `Prenumerera`, `Aktivera`, `Inaktivera`.
- Skriv `e-postadress` med bindestreck.
