# Foundation svenska — help.json, slutförd radgranskning

Granskningen avslutades 2026-11-20 via Crowdin API. Samtliga 382 strängpositioner (offset 0–380, 10 per hämtning) har lästs rad för rad mot aktuell svensk text och tillhörande sammanhang. Hämtningsblocket vid offset 390 returnerade 0 strängar.

Alla dokumenterade förslag har:
- validerats med `l10n-lint --language sv`;
- stavningskontrollerats med `hunspell -d sv_SE`;
- skickats direkt till Crowdin;
- arkiverats i delrapporterna `foundation-sv-help-part1-20261120.md` till `foundation-sv-help-part37-20261120.md`.

Platshållare, Markdown, Steam-/UI-formatering och betydelsefulla blanktecken har bevarats vid varje ändring. Crowdin-svar om redan befintliga identiska översättningar redovisas i respektive delrapport.
