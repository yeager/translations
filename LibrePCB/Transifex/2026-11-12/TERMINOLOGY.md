# LibrePCB-termer, svenska

| Engelska | Svenska | Sammanhang och källa |
| --- | --- | --- |
| component | komponent | Befintliga LibrePCB-översättningar använder *Komponent*. |
| device | enhet | Befintlig LibrePCB-översättning av *Device*. En enhet kopplar bland annat symbol och paket. |
| package | paket | Befintliga LibrePCB-översättningar använder *Paket*. |
| pad | pad | Befintliga LibrePCB-översättningar använder *Pad*. Böjs här som *padar*. |
| designator | beteckning | Elektronisk komponentbeteckning, till exempel R1. |
| clearance | frigång | Kopparfrigång i PCB-redigeraren. |
| wire | ledare | Schematisk ledare som en etikett kan fästas vid. |
| schematic | schema | Används i panelens konkret beskrivna funktion. |
| usage | användning | Menykommandot *Find Usages*. |

Termerna ovan bygger på den svenska LibrePCB-resursen som hämtades från
Transifex 2026-11-12 och på de aktuella källförekomsterna i LibrePCB.
