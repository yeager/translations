# iD Editor, presets relations, svenska

Datum: 2026-11-12. Delbatch med 12 relation-, vattenvägs-, järnvägs- och
trafikposter i `presets`.

Batchen är mottagen i Transifex. Efterkontrollen visar 41 oöversatta poster
kvar i hela komponenten. l10n-lint, svlang, hunspell-sv, diffkontroll och
Gitleaks passerade. Lintens informationsnotiser för två sökordsposter gäller
att instruktionernas vinkelparenteser avsiktligt inte är del av den svenska
sökordslistan. `msgfmt` är inte tillämpligt för JSON-resursen.
