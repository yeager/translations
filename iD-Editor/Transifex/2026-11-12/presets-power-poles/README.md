# iD Editor, presets power poles, svenska

Datum: 2026-11-12. Delbatch med 11 stolpkonstruktioner i `presets`.

Batchen är mottagen i Transifex och efterinventeringen visar 22 oöversatta
poster kvar. Termerna följer OpenStreetMaps definitioner av stolpdesign:
armlös, asymmetrisk, enpolig, triangelformad samt en till fyra nivåer. `Delta`
bevaras som konstruktionstyp. l10n-lint, svlang, hunspell-sv, diffkontroll
och Gitleaks passerade. `msgfmt` är inte tillämpligt för JSON-resursen.
