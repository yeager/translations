# Obtainium – svensk katalogkontroll

Datum: 2026-11-14

Komponent: `assets/translations/sv.json`
Källversion: Obtainium 1.7.4, publicerad 2026-11-01

Obtainium följer program från deras egna utgivningskällor och hjälper användaren
att installera och uppdatera dem. Den svenska JSON-katalogen innehåller exakt
samma 642 nycklar som engelskan, utan saknade eller tomma värden. Ingen ändring
behövde därför skickas upstream.

Gitleaks kördes utan träffar. Status: lokalt kontrollerat och arkiverat.
