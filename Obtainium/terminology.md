# Obtainium – svensk terminologi

Senast granskad: 2026-11-14

Listan gäller gränssnittet i `assets/translations/sv.json`. Den bygger på
strängarnas användning i Obtainiums Flutter-vyer och är inte en ersättning för
ny kontextgranskning.

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| app | app | Används som etablerad Android-term. |
| app list | applista | Sammanhållen beteckning för listvyn. |
| background checks | bakgrundskontroller | Kontroller som körs utan att appen är öppen. |
| update health | uppdateringsstatus | Vyn samlar varningar om uppdateringsmöjligheter. |
| release | utgåva | Gäller publicerade programversioner. |
| pre-release | förhandsutgåva | Gäller versioner före stabil utgåva. |
| repository | förråd | Gäller GitHub- och GitLab-förråd. |
| source | källa | En konfigurerad källa för appens utgåvor. |
| Downloads | Hämtade filer | Androids mapp- och filväljarkontext. |
| export | exportera, export | Verb respektive exporterad fil eller operation. |
| certificate | certifikat | Gäller TLS- och signeringscertifikat. |
| token | token | Behålls som teknisk synlig UI-term. |
| swipe actions | svepåtgärder | Åtgärder som visas genom att svepa i applistan. |
