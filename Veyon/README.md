# Veyon, svensk Transifex-granskning

Den 12 november 2026 granskades den då enda oöversatta svenska komponenten
`addons` i Transifex-projektet `veyon-solutions/veyon`. Veyon 4.11.4
publicerades den 15 oktober 2026 och projektet uppfyller därmed
aktualitetskravet.

Tio dokumentationssträngar om Microsoft Intune, API-behörigheter och
internetåtkomst översattes och skickades med Transifex bulk-API. En färsk
API-avläsning efter uppladdningen visar 0 oöversatta svenska strängar i
komponenten.

Arbetet är lokalt granskat, arkiverat och uppladdat. Upstreamgranskning eller
publicering kan inte utläsas från Transifex API och är inte verifierad.

Se `Transifex/2026-11-12/addons-batch01/` för deltafil, API-kvitto och
oförändrad efterexport.
