# GNU Mailman Core: kontroll av aktuell release

Kontrollerad 2026-10-27 mot GNU Mailmans officiella GitLab-releaser.

Senaste stabila release är `v3.3.10`, publicerad 2024-10-02. Den uppfyller
48-månadersregeln och Core får därför granskas och kompletteras.

Den aktuella svenska katalogen ligger på GitLabs `master`; dess senaste
uppdatering ska alltid jämföras med lokala deltafiler innan komponentvis
import, särskilt eftersom Mailman använder flera mallnära textfiler.
