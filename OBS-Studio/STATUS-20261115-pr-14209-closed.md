# OBS Studio: PR #14209 stängd utan merge

PR #14209, som lade till svenska kataloger för ASIO och VST3, stängdes den 15 november 2026 utan merge.

OBS Studio bekräftade i PR-kommentaren att översättningar hanteras via projektets Crowdin och att pull requests inte är rätt bidragsväg för denna typ av ändring. Ingen ändring gjordes i Crowdin. Den lokala kontrollen och arkivet behålls som underlag, men upstream-statusen är stängd utan merge.
