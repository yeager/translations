# 0 A.D. – svensk terminologi

Senast uppdaterad: 2026-11-14

Denna lista används vid svensk översättning av 0 A.D.-spelet och webbplatsen.
Projektets egen kontext och den aktuella användargränssnittstexten har alltid
företräde framför en generell termträff.

| Källterm | Svensk term | Anmärkning |
| --- | --- | --- |
| Command Center | kommandocentral | Byggnad i spelets spelguide. |
| Command Panel | kommandopanel | Synligt UI-namn i spelguiden. |
| building structures | byggnader | Använd den kortare UI-termen när sammanhanget tillåter. |
| wonder | underverk | Spelbyggnad; inte *mirakel*. |
| civic center | stadscentrum | Byggnad/strategiterm. |
| concept art | konceptbilder | Sidans övergripande benämning. |
| screenshot | skärmbild | Bildtext på webbplatsen. |
| ambient occlusion | Ambient Occlusion | Teknisk grafikfunktion; behåll det synliga funktionsnamnet. |
| water depth rendering | vattendjupsrendering | Teknisk bildtext. |
| Carthage / Carthaginian | Karthago / kartagisk | Historisk kontext. |
| Mauryan | mauryansk | Böjs efter satsen, till exempel *mauryanska byggnader*. |
| Giza Plateau | Giza-platån | Historiskt geografiskt namn. |
| Athenian | atensk | Till exempel *Atens gymnasion*. |
| support | support | Avser hjälpkanal på webbplatsen; undvik tekniskt tvetydiga omskrivningar. |
| torrent | torrent | Etablerad BitTorrent-term. |
| seed | seed | Behåll termen i den pedagogiska BitTorrent-ordlistan. |
| peer | peer | Behåll termen i den pedagogiska BitTorrent-ordlistan. |

Egennamn, namn på antika folk och platser, filformat, produktnamn, kod,
API-namn och synliga tekniska funktionsnamn behålls när deras etablerade form
är korrekt i sammanhanget.
