# Open Shaders, gemensamt UI, svensk granskning 2026-10-18

Den här komponentkatalogen innehåller alla 44 `ui.*`-poster ur den aktuella Open Shaders-katalogen. Den omfattar cachehantering, tangentbindningar, beskärning, VR-handkontroller och tabellrubriker.

Kontroller:

- JSON-syntax samt nyckel- och platshållarkontroll: godkända
- `l10n-lint`: 0 fel, 0 varningar
- `svlang skrivregler`: godkänd
- `hunspell-sv`: träffar granskade som teknikord, formatsträngar, filändelser eller produktnamn
- `gitleaks`: inga läckor

Den globala Open Shaders-katalogen innehåller fler komponenter och är inte färdig.
