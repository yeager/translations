Offlineversion av OpenStreetMap-instrumentpanelen för <a href="https://codeberg.org/OpenTracksApp/OpenTracks">OpenTracks</a>.
Kan även användas som fristående GPX- och platsvisare.

Den visar ett valt spår med start- och slutpunkt på en karta från <a href="https://openstreetmap.org">OpenStreetMap</a>, baserad på biblioteket <a href="https://github.com/mapsforge/vtm">Mapsforge VTM</a>.
Den här versionen stöder endast offlinekartor som måste hämtas manuellt.

Gå med i OSM-gemenskapen och hjälp till att förbättra kartan,
se <a href="https://www.openstreetmap.org/fixthemap">www.openstreetmap.org/fixthemap</a>.

Vissa offlinekartor finns här:

- <a href="http://download.mapsforge.org/">Mapsforge</a>
- <a href="https://www.freizeitkarte-osm.de/android/en/">Freizeitkarte Android</a>
- <a href="https://www.openandromaps.org/en">OpenAndroMaps</a>

Vissa kartor kräver särskilda teman för att återges korrekt. De måste hämtas och konfigureras.

Vissa webbläsare, till exempel Firefox, kräver ett långt tryck på länken och valet ”Öppna länk i extern app”. Välj sedan OSMDashboard.

Manuellt hämtade offlinekartor eller kartor som delas med andra appar kan öppnas från din Android-enhet.
Välj katalogen i menyn ”Kartkatalog”.
