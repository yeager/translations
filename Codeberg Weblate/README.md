# Codeberg Weblate

`STATUS.md` är arbetsjournalen för de svenska komponenter som har granskats i denna arbetsomgång. Den redovisar vilka ändringar som har publicerats och verifierats i Codeberg Weblate, samt komponenter som inte gick att publicera eftersom de var låsta eller där Weblates API avvisade en pluraluppdatering.

Journalen är inte en påstådd komplett kopia av hela tjänsten: inventeringen omfattar 605 offentliga projekt och 828 befintliga svenska komponenter, och fortsatt granskning återstår.
