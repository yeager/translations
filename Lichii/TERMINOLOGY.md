# Lichii – svensk terminologi

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| Recent Files | Senaste filer | Avser nyligen öppnade filer, inte rekommenderade filer. |
| Clear Recent Files | Töm listan över senaste filer | Klargör att historiklistan töms. |
| shader | shader | Etablerad teknisk term i emulerings- och grafikgränssnittet. Böj vid behov `shader`/`shaders`. |
| firmware | fast programvara | Använd i löptext; behåll `firmware` när det är ett synligt fil- eller produktnamn. |
| save data | sparade data | Inte `sparning` när gränssnittet avser användarens sparfiler. |
| controller | styrenhet | Använd konsekvent för fysisk eller emulerad handkontroll. |
| OpenGL support | OpenGL-stöd | Bindestreck enligt svensk sammanskrivning. |
| Lichii | Lichii | Produktnamn, översätts inte. |
| Eden directory | Eden-katalog | Behåll Eden i historiska data- och konfigurationskataloger enligt Lichiis kompatibilitetspolicy. |
