# Bottles, svensk terminologi

| --- | --- | --- |

| runner | körprogram | Befintlig projektterm |
| staging patch | staging-patch | Teknisk term; staging behålls |
| Steam Runtime | Steam Runtime | Produktnamn, översätts inte |
| library | bibliotek | UI-navigering |
| runner | körprogram | Används konsekvent i gränssnittet |
| snapshot | ögonblicksbild | Versionshanteringsfunktion |
| dependency | beroende | Menynamn: beroendemeny |
| shortcut menu | snabbmeny | Filhanterarens kontextmeny |
| sandbox | sandlåda | Säkerhetsisolering |
