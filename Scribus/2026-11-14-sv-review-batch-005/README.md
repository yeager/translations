# Scribus svenska radgranskning, batch 005

Datum: 2026-11-14

Komponent: `scribus` på Transifex, språk `sv`.

Batchen omfattar aktuella poster 601–750. Femton konkreta ändringar sparades via Transifex API och lästes tillbaka. De rättar streckkodsalternativ, synliga typsnittsnamn, klippboksflödet och knappens skalningsval.

Kontroller: Qt `lrelease`, platshållar- och acceleratorgranskning, diffkontroll, `svlang` och Hunspell-sv för ny text. Den enda ordlistträffen är produktnamnet Scribus.

Transifex-token kan spara översättningar men saknar behörighet att markera dem som formellt granskade. Importen är verifierad som sparad; granskningsstatusen i Transifex är oförändrad.
