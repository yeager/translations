# Scribus svenska radgranskning, batch 003

Datum: 2026-11-14

Komponent: `scribus` på Transifex, språk `sv`.

Batchen omfattar aktuella poster 301–450. Tjugotvå granskade ändringar sparades via Transifex API och lästes tillbaka. Arbetet omfattar svenska UI-verb, märke- och notterminologi, samt konsekventa svenska PDF-kontroller och specialtecken.

Kontroller: Qt `lrelease`, platshållar- och acceleratorgranskning, diffkontroll, `svlang` och Hunspell-sv på de ändrade formuleringarna. Träffarna gäller produktnamnet Scribus samt förväntade tekniska sammansättningar som Bézierkurva och notstilar.

Transifex-token kan spara översättningar men saknar behörighet att markera dem som formellt granskade. Importen är verifierad som sparad; granskningsstatusen i Transifex är oförändrad.
