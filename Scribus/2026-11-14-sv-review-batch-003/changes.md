# Ändringar

- Homepage och Online Documentation fick svenska benämningar.
- Get Vector File blev `Läs in vektorfil`.
- Märken, notstilar och hänvisningar normaliserades.
- Snap to Items blev `Fäst vid objekt` och Eye Dropper blev `Pipett`.
- Bézierkurva och de sex PDF-formulärkontrollerna rättades.
- Föråldrade eller engelska specialteckensnamn ersattes med svenska benämningar.
- Textlänkning fick verbet `Bryt`; Truncate blev `Förkorta`.
