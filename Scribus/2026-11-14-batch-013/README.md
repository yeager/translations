# Scribus svenska UI - granskningsbatch 013

Datum: 2026-11-14
Komponent: Scribus UI (`o:scribus:p:scribus:r:scribus`)
Språk: svenska (`sv`)

Tolv radgranskade strängar för stavnings- och avstavningsdialoger,
bildinformation, import av CGM, CorelDRAW och IDML samt hjälpens navigering.

Alla ändringar sparades via Transifex REST API och återlästes exakt.
`lrelease`, Hunspell-SV och svlang kördes lokalt. Hunspell-SV markerade
endast formatnamn, produktnamn och korrekta sammansättningar. Gitleaks körs
mot arkivbatchen före push.
