# Scribus svenska radgranskning, batch 002

Datum: 2026-11-14

Komponent: `scribus` på Transifex, språk `sv`.

Batchen omfattar de följande 150 aktuella posterna efter batch 001. Tjugoen kvalitetssäkrade ändringar sparades via Transifex API och lästes tillbaka. Ändringarna rättar bland annat UI-verb, ordval för ritverktyg, teckennamn och felaktiga tre punkter i stället för källtextens tre punkttecken.

Kontroller: Qt `lrelease`, platshållar- och acceleratorgranskning, diffkontroll, `svlang` och Hunspell-sv på den ändrade texten. Hunspell- och svlang-träffarna var förväntade tekniska fackord och sammansättningar: Bézierkurva, halvfyrkantsmellanslag, icke-sammanfogare, mellanbrett och sammanfogare.

Transifex-token kan spara översättningar men saknar behörighet att markera dem som formellt granskade. Importen är verifierad som sparad; granskningsstatusen i Transifex är oförändrad.
