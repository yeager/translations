# Scribus svenska radgranskning, batch 004

Datum: 2026-11-14

Komponent: `scribus` på Transifex, språk `sv`.

Batchen omfattar aktuella poster 451–600. Tjugofem konkreta förbättringar sparades via Transifex API och lästes tillbaka. De omfattar PDF-formulärkontroller, anteckningar, justering/fördelning, mallsidor och streckkodsfunktionen.

Kontroller: Qt `lrelease`, platshållar- och acceleratorgranskning, diffkontroll, `svlang` och Hunspell-sv för nya formuleringar. Kvarvarande ordlistträffar gäller produktnamn och synliga tekniknamn: Scribus, Barcode Writer, Pure PostScript och PostScript.

Transifex-token kan spara översättningar men saknar behörighet att markera dem som formellt granskade. Importen är verifierad som sparad; granskningsstatusen i Transifex är oförändrad.
