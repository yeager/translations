# Scribus svenska UI - granskningsbatch 051

Datum: 2026-11-14
Komponent: Scribus UI (`o:scribus:p:scribus:r:scribus`)
Språk: svenska (`sv`)

20 radgranskade ändringar för arkivfel, åtgärdshistorik, linjer,
teckensnitt, banor och lager. Bland annat rättades den felaktiga
översättningen av `Send to layer` och flera trasiga sammansättningar.

Ändringarna sparades en och en via Transifex REST API och återlästes
exakt. `lrelease`, diffkontroll, Gitleaks, Hunspell-SV och svlang
kördes lokalt. Hunspell-SV och svlang markerade endast etablerade
Scribus- och grafiska facktermer samt sammanfogade UI-etiketter.

Upstreamstatus: sparad via API och läsverifierad; ingen separat
upstreamgranskning har verifierats.
