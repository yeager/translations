# Scribus svenska UI - granskningsbatch 052

Datum: 2026-11-14
Komponent: Scribus UI (`o:scribus:p:scribus:r:scribus`)
Språk: svenska (`sv`)

34 radgranskade ändringar i åtgärdshistoriken för lager, banor,
mallsidor, tabeller, övertoningar och text. Direkta felöversättningar,
engelska restord och trasiga sammansättningar har rättats.

Ändringarna sparades en och en via Transifex REST API och återlästes
exakt. `lrelease`, diffkontroll, Gitleaks, Hunspell-SV och svlang
kördes lokalt. Hunspell-SV gav inga träffar. svlang-larmen är falska
positiva från sammanfogade korta UI-etiketter.

Upstreamstatus: sparad via API och läsverifierad; ingen separat
upstreamgranskning har verifierats.
