# Scribus svenska UI - granskningsbatch 007

Datum: 2026-11-14
Komponent: Scribus UI (`o:scribus:p:scribus:r:scribus`)
Språk: svenska (`sv`)

11 radgranskade strängar i teckenpaletten och dokumentkontrollen.
Ändringarna förtydligar PDF-anteckningar, placerade PDF-filer,
sidplacering, textöverflöd och diagnostik för bild- och textramar.

Sparade via Transifex REST API och exakt återlästa efter varje uppdatering.
`lrelease` och Hunspell-SV kördes lokalt före inskick. Hunspell-SV saknar
de korrekta facktermerna `TrueType-teckensnitt` och `sidplacering`.
Formell granskningsstatus kunde inte ändras eftersom token saknar den behörigheten.
