# Terminologi – OpenCloud Rclone Crypt

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| vault | valv | Följer befintlig OpenCloud-översättning. |
| end-to-end encryption | end-to-end-kryptering | Vedertagen teknisk term; bindestreck följer källans skrivsätt. |
| password manager | lösenordshanterare | Tydlig svensk UI-term. |
| reset link | återställningslänk | Förklarar att någon återställningsväg saknas. |
| admin override | administrativ åsidosättning | Skiljer från återställning och säkerhetsfråga. |
| encrypted space | krypterad arbetsyta | `space` är projektspecifikt `arbetsyta`. |
| decrypt | dekryptera | Etablerad fackterm i denna säkerhetskontext. |
