# Terminologi – OpenCloud web-files

| Engelska | Svenska | Källa och sammanhang | Anmärkning |
| --- | --- | --- | --- |
| Space | arbetsyta | befintlig svensk resurs och `SpaceHeader.vue` | Projektspecifik benämning, inte det allmänna `utrymme`. |
| space image | arbetsytans bild | `SpaceHeader.vue` | Etikett för att förstora eller förminska bild i en arbetsyta. |
| share receiver | delningsmottagare | skärmläsaretikett i `Collaborators/ListItem.vue` | Kort och entydig benämning av mottagare för en delning. |
| restore version | återställa version | versionshantering | Verb som passar i felmeddelande. |
| trash bin | papperskorg | `views/trash/Overview.vue` | Följer etablerad svensk skrivbordsterminologi. |
| duplicate | duplicera | kopiering av arbetsyta | Skiljer åtgärden från vanlig filkopiering. |
| conflict dialog | konfliktdialogruta | uppladdningskonflikt | UI-komponent, inte själva konflikten. |
| README | README | filnamn och teknisk dokumentation | Behålls oöversatt. |
