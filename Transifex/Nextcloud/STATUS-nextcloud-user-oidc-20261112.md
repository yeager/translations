# Nextcloud user_oidc – svenska översättningar

8 OIDC- och JWT-relaterade strängar granskades i autentiseringskontext och validerades med l10n-lint, svlang, Hunspell, `git diff --check` och Gitleaks. Förväntade Hunspell-träffar är OIDC-, JWT-, JWKS- och IdP-termer samt platshållaren `jwksUrl`. Batchen skickades via Transifex API 2026-11-12. HTTP 200 och en färsk separat API-läsning visar 0 oöversatta svenska strängar. `msgfmt` är inte tillämpligt för JSON-resursen.
