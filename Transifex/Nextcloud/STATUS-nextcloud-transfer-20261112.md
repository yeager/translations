# Nextcloud transfer – svenska översättningar

7 filöverförings- och felsträngar granskades i klient- och nätverkskontext, validerades med l10n-lint, svlang, Hunspell, `git diff --check` och Gitleaks samt skickades via Transifex API 2026-11-12. Hunspell-träffen `reason` är en platshållare. HTTP 200 och en ny API-läsning bekräftar 0 oöversatta svenska strängar. `msgfmt` är inte tillämpligt för JSON-resursen.
