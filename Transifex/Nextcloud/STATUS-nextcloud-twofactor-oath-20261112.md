# Nextcloud twofactor_oath – svenska översättningar

8 strängar om OATH, reservkoder och tokenhantering granskades i säkerhetskontext och validerades med l10n-lint, svlang, Hunspell, `git diff --check` och Gitleaks. Produktnamn, modulnamn, `occ` och tekniska tokennamn är förväntade Hunspell-träffar. Batchen skickades via Transifex API 2026-11-12; HTTP 200 och en ny API-läsning bekräftar 0 oöversatta svenska strängar. `msgfmt` är inte tillämpligt för JSON-resursen.
