# Nextcloud – svensk terminologi

| Engelskt begrepp | Rekommenderad svenska | Sammanhang | Källa eller undantag |
| --- | --- | --- | --- |
| backup code | reservkod | tvåfaktorsautentisering | `twofactor_oath` |
| managed user | hanterad användare | central token- och kodhantering | `twofactor_oath` |
| token | token | OATH, OIDC och hårdvarutoken | Behålls som etablerad teknisk term. |
| end-to-end encrypted | end-to-end-krypterad | krypterade mappar | Behåll källans etablerade säkerhetsterm. |
| metadata | metadata | versionsformat v1/v2 | Ingen pluraländring i svensk facktext. |
| private key JWT authentication | JWT-autentisering med privat nyckel | OIDC-inställningar | Förklara inte förkortningen i UI. |
| group claim | gruppanspråk | OIDC-gruppmappning | OIDC-terminologi. |
| authorization | auktorisering | OAuth-förlopp i Talk Desktop | Skiljs från autentisering. |
| grant access | ge åtkomst | OAuth-förlopp | Verbfras för synlig UI-text. |
| download limit | hämtningsgräns | Filer och policy | `files_downloadlimit` |
| transfer | överföring | filöverföring och fel | `nextcloud-transfer` |
| target folder | målmapp | filöverföring | `nextcloud-transfer` |
| speaker view | talarvy | Talk-layout | `android-talk` |
| call view mode | visningsläge för samtal | Talk-layout | `android-talk` |
| timeline | tidslinje | Memories fotovy | Sortering efter fotograferingsdatum. |
| external sharing | extern delning | Memories album och delning | Skiljs från intern Nextcloud-delning. |
| preview | förhandsvisning | Memories bildhantering | Gäller genererade bildförhandsvisningar, inte dialogförhandsvisning. |
| reverse geocoding | omvänd geokodning | Memories kartvy | Teknisk geografisk term. |
| video transcoding | videoomkodning | Memories videouppspelning | Beskriver konvertering för uppspelning. |
| map tile server | kartplattsserver | Memories kartinställning | Etablerad GIS- och webbkartterm. |
| manage media | hantera medier | Memories enhetsbehörighet | Android-behörighet; undvik det tvetydiga "media" som svenskt substantiv. |
| space | arbetsyta | OpenCloud, inte Nextcloud | Projektbunden term; använd inte automatiskt i Nextcloud. |
| signer | undertecknare | LibreSign och signeringsflöden | Avser person som undertecknar, inte en kryptografisk komponent. |
| signature request | signeringsbegäran | LibreSign-notifieringar | Begäran om en elektronisk underskrift. |
| signing invitation | inbjudan att underteckna | LibreSign-e-post | Idiomatisk uppmaning i mottagarens kontext. |
| validate a signature | validera en signatur | LibreSign-kontroll | Teknisk kontrollterm. |
| delivery is not confirmed | leveransen är inte bekräftad | LibreSign-notifieringar | Skilj från att notifieringsbegäran har behandlats. |
| signing flow | signeringsflöde | LibreSign-konfiguration | Flödet från begäran till slutförd underskrift. |
| footer | sidfot | LibreSign-dokumentmallar | Avser dokumentets sidfot, inte en allmän UI-sidfot. |
| signature stamp | signaturstämpel | LibreSign-dokumentmallar | Grafisk stämpel kopplad till signaturen. |
| background processing | bakgrundsbearbetning | LibreSign-notifieringar | Bearbetning via tillgängliga jobbkörningar. |
| tile | ruta | Souvenirs-album | Ett flyttbart och storleksändringsbart innehållsobjekt på en albumsida. |
| reframe | beskär | Souvenirs-foton | Justera bildutsnittet inom en ruta. |
| soundtrack | ljudspår | Souvenirs-albumsida | Ett ljudspår kan fortsätta över flera sidor. |
| freehand drawing | frihandsteckning | Souvenirs-albumsida | Teckning ovanpå sidans rutor. |
| inventory | lager | Pantry | Behålls som substantiv för en namngiven samling med lagervaror. |
| checklist | checklista | Pantry | Namngiven lista med rader som kan kopplas till lagervaror. |
| restock | fyll på | Pantry | Verb för att öka lagersaldot. |
| template | mall | Pantry | Mall för checklisteinnehåll. |
| on hand | tillgänglig mängd | Pantry-lager | Aktuell mängd i lager, skild från målnivå. |
| reorder point | beställningspunkt | Pantry-lager | Nivå då varan bör köpas eller fyllas på. |
| expiry | utgångsdatum | Pantry-lager | Datum då en vara inte längre bör användas. |
| stock mode | lagerläge | Pantry-lager | Hantering som antal eller nivåerna fullt, lågt och slut. |
| restock checklist | checklista för påfyllning | Pantry-lager | Checklista som varor med låg lagerstatus läggs till i. |
| shopping list | inköpslista | Pantry | Lista med varor som ska köpas. |
| house | hem | Pantry | Delat organisatoriskt område för listor, foton och anteckningar. |
