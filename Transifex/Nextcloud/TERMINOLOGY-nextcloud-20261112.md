# Nextcloud – svensk terminologi

| Engelskt begrepp | Rekommenderad svenska | Sammanhang | Källa eller undantag |
| --- | --- | --- | --- |
| backup code | reservkod | tvåfaktorsautentisering | `twofactor_oath` |
| managed user | hanterad användare | central token- och kodhantering | `twofactor_oath` |
| token | token | OATH, OIDC och hårdvarutoken | Behålls som etablerad teknisk term. |
| end-to-end encrypted | end-to-end-krypterad | krypterade mappar | Behåll källans etablerade säkerhetsterm. |
| metadata | metadata | versionsformat v1/v2 | Ingen pluraländring i svensk facktext. |
| private key JWT authentication | JWT-autentisering med privat nyckel | OIDC-inställningar | Förklara inte förkortningen i UI. |
| group claim | gruppanspråk | OIDC-gruppmappning | OIDC-terminologi. |
| authorization | auktorisering | OAuth-förlopp i Talk Desktop | Skiljs från autentisering. |
| grant access | ge åtkomst | OAuth-förlopp | Verbfras för synlig UI-text. |
| download limit | hämtningsgräns | Filer och policy | `files_downloadlimit` |
| transfer | överföring | filöverföring och fel | `nextcloud-transfer` |
| target folder | målmapp | filöverföring | `nextcloud-transfer` |
| speaker view | talarvy | Talk-layout | `android-talk` |
| call view mode | visningsläge för samtal | Talk-layout | `android-talk` |
| timeline | tidslinje | Memories fotovy | Sortering efter fotograferingsdatum. |
| external sharing | extern delning | Memories album och delning | Skiljs från intern Nextcloud-delning. |
| preview | förhandsvisning | Memories bildhantering | Gäller genererade bildförhandsvisningar, inte dialogförhandsvisning. |
| reverse geocoding | omvänd geokodning | Memories kartvy | Teknisk geografisk term. |
| video transcoding | videoomkodning | Memories videouppspelning | Beskriver konvertering för uppspelning. |
| map tile server | kartplattsserver | Memories kartinställning | Etablerad GIS- och webbkartterm. |
| manage media | hantera medier | Memories enhetsbehörighet | Android-behörighet; undvik det tvetydiga "media" som svenskt substantiv. |
| space | arbetsyta | OpenCloud, inte Nextcloud | Projektbunden term; använd inte automatiskt i Nextcloud. |
