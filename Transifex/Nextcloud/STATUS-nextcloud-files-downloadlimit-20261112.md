# Nextcloud files_downloadlimit – svenska översättningar

3 UI-strängar om hämtningsgränser granskades i filhanteringskontext och validerades med l10n-lint, svlang, Hunspell, `git diff --check` och Gitleaks. De skickades i en Transifex API-batch 2026-11-12; HTTP 200 och efterföljande API-läsning bekräftar 0 oöversatta svenska strängar. `msgfmt` är inte tillämpligt för JSON-resursen.
