# Terminologi – Eden Emulator

| Engelska | Svenska | Kontext | Anmärkning |
| --- | --- | --- | --- |
| hash | kontrollsumma | uppdaterarens integritetskontroll | Förklarar funktionen bättre än det tekniska låneordet i felmeddelandet. |
| staging directory | mellanlagringskatalog | uppdaterarens tillfälliga arbetskatalog | Behåller katalog som etablerad datorterm. |
| updater executable | uppdateringsprogrammets körbara fil | start av extern uppdaterare | Förtydligar vilken körbar fil som avses. |
| local cache directory | lokal cachekatalog | lokal kopia för uppdateraren | `cache` används som etablerad fackterm i sammansättning. |
| extraction | uppackning | installering av ny version | Naturlig svensk UI-term. |
| download | hämtning | nätverkshämtning av uppdatering | Följer vanlig svensk programvaruterminologi. |
