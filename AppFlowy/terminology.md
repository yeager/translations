# AppFlowy, svensk terminologi

Senast uppdaterad: 13 november 2026. Listan gäller den svenska UI-resursen och
ska prövas mot varje strängs funktion; den är inte en mekanisk ersättningslista.

| Källterm | Svensk term | Anmärkning |
| --- | --- | --- |
| page | sida | Används för dokumentets navigerbara innehåll. |
| board | tavla | Den konkreta sidtypen, inte en fysisk anslagstavla. |
| notification | avisering | Gäller meddelandecentralens händelser och status. |
| reminder | påminnelse | Gäller datumväljarens tidsstyrda påminnelser. |
| favorite | favorit | Gäller märkta sidor och deras sidofältsåtgärder. |
| quick note | snabbanteckning | Gäller AppFlowys korta, fristående anteckningar. |
| block | block | AppFlowys redigeringsenhet; används i platshållare och instruktioner. |
| page icon | sidans ikon | Ikon som representerar en sida i titelraden. |
| reference | hänvisning till | Gäller redigerarens snabbinfogningsmeny, följt av objektets typ. |
| request access | begär åtkomst | Gäller begäran till en sidägare, inte en administrativ behörighetsdialog. |
| upload | läsa in | Gäller lokal import i uppladdarens instruktioner; behåll format- och API-namn. |
| log file | loggfil | Gäller filer som delas vid felsökning. |
| unread | oläst | Används i filter och status för aviseringar. |
| archive | arkivera | Verb för att flytta en avisering till arkivet. |
