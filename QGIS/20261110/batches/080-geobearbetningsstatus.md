# QGIS: status i geobearbetningsdialogen 080

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar körningsstatus och åtgärder i QGIS geobearbetningsdialog.
Platshållarna `{}` och `{0}/{1}`, HTML-markering och den inbäddade
radbrytningen i HTML-resultatet bevaras. `CRS` används i den fastställda
formen **koordinatreferenssystem**.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `&lt;b&gt;Algorithm '{0}' starting&amp;hellip;&lt;/b&gt;` | `&lt;b&gt;Algoritm '{0}' starting&amp;hellip;&lt;/b&gt;` | `&lt;b&gt;Algoritmen '{0}' startar&amp;hellip;&lt;/b&gt;` |
| `Modify Selected Features` | `Modifiera valda objekt` | `Ändra valda objekt` |
| `Modify All Features` | `Modifiera alla objekt` | `Ändra alla objekt` |
| `Algorithm started at: {}` | `Algoritm startad vid: {}` | `Algoritmen startade: {}` |
| `Executing iteration {0}/{1}…` | `Exekverar omgång {0}/{1}…` | `Kör iteration {0}/{1}…` |
| `Unmatching CRS's` | `Koordinatsystem överensstämmer inte` | `Koordinatreferenssystemen stämmer inte överens` |
| `Unable to execute algorithm` | `Kan inte köra algoritm` | `Det går inte att köra algoritmen` |
| `Execution completed in {}` | `Beräkningen utfördes på  {}` | `Körningen slutfördes efter {}` |
| `Execution failed after {}` | `Beräkningen misslyckades efter  {}` | `Körningen misslyckades efter {}` |
| `Algorithm '{0}' finished` | `Algoritm '{0}' avslutad` | `Algoritmen '{0}' är klar` |
| `HTML output has been generated by this algorithm.\nOpen the results dialog to check it.` | `HTML utdata har skapats av algoritmen.\nÖppna resultatdialogen för att kontrollera.` | `HTML-utdata har skapats av den här algoritmen.\nÖppna resultatdialogen för att kontrollera den.` |

Ingen extern ändring har gjorts. Aktuella Transifex-enhetsidentifierare måste
hämtas innan en separat deltafil kan skapas.
