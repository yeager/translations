# QGIS: kartrutnät i layout 190

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar kartrutnätets ram, koordinattexter och format i
layoutdesignern. `CRS` återges som `koordinatreferenssystem` och `offset`
som `förskjutning`. Rutnätsmarkeringar behandlas som streck, inte prickar.
