# QGIS: PostGIS-projekt och schema 100

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar projekt- och schemaåtgärder i PostGIS-datakällpanelen. Den
bevarar `%1`, `%2`, `%3`, `qgis_projects` och dialogellipsen `…` enligt
källsträngarna. `schema` används som etablerad PostgreSQL-term.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Import Projects…` | `Importera projekt...` | `Importera projekt…` |
| `Set Comment…` | `Ställ in kommentar…` | `Ange kommentar…` |
| `Schema '%1' deleted successfully.` | `Borttagning av schema '%1' lyckades.` | `Schemat '%1' har raderats.` |
| `Schema '%1' renamed correctly to '%2'.` | `Schema '%1' bytte namn rätt till '%2'.` | `Schemat '%1' har bytt namn till '%2'.` |
| `%1 '%2' renamed correctly to '%3'.` | `%1 '%2' bytte namn rätt till '%3'.` | `%1 '%2' har bytt namn till '%3'.` |
| `Materialized view '%1' refreshed successfully.` | `Materialiserad vy '%1'uppdaterad.` | `Den materialiserade vyn '%1' har uppdaterats.` |
| `QGIS Bundled Project Format` | `QGIS packade projektformat` | `Paketerat QGIS-projektformat` |
| `Set Project Comment` | `Ange projektets kommnentar` | `Ange projektkommentar` |
| `Failed to set project comment for '%1'` | `Misslyckades med att lagra projektkommentar för "%1"` | `Det gick inte att ange projektkommentaren för '%1'.` |
| `Comment updated for project '%1'` | `Kommentar uppdaterad för projektet '%1'` | `Kommentaren för projektet '%1' har uppdaterats.` |
| `Versioning of QGIS projects already active in schema “%1”.` | `Versionshantering av QGIS-projekt redan aktivt i schema "%1".` | `Versionshantering av QGIS-projekt är redan aktiv i schemat “%1”.` |
| `Versioning of QGIS projects setup in schema “%1”.` | `Versionshantering av QGIS-projekt inställt i schema "%1".` | `Versionshantering av QGIS-projekt har konfigurerats i schemat “%1”.` |
| `Project “%1” saved to schema “%2”.` | `Projekt “%1” sparat i schema “%2”.` | `Projektet “%1” har sparats i schemat “%2”.` |

Ingen extern ändring har gjorts. Aktuella Transifex-enhetsidentifierare måste
hämtas och måltexterna jämföras före en separat deltafil kan skapas.
