# QGIS: konsolens API-inställningar 068

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`  
Kontext: `ConsoleOptionsWidget`

Konsolens inställningar innehåller en kategori för dataleverantörer och två
instruktioner för API-filer vid kompilering. Den etablerade QGIS-termen
`leverantör` används, och instruktionerna skrivs med naturlig svensk
uppmaningsform.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Providers` | `Dataplugin` | `Dataleverantörer` |
| `You need to add some APIs file in order to compile` | `Du behöver lägg till några API-filer för att kunna kompilera` | `Du behöver lägga till några API-filer för att kunna kompilera.` |
| `Please specify API file or check "Use preloaded API files"` | `Vänligen specificera API-fil eller klicka i "Använd förladdade API-filer"` | `Ange en API-fil eller markera "Använd förladdade API-filer".` |

`API` och den synliga inställningsetiketten bevaras. Ingen extern ändring har
gjorts; aktuella Transifex-enhetsidentifierare behöver hämtas innan en deltafil
kan skapas.
