Datum: 10 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar tidsnavigering, JSON-validering och textformat. HTML-länken
och platshållarna `%1` och `%2` bevaras oförändrade.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Successfully exported animation to <a href="%1">%2</a>` | `Lyckades exportera animation till <a href="%1">%2</a>` | `Animationen exporterades till <a href="%1">%2</a>` |
| `source timestamps` | `tidsstämpel från källa` | `källtidsstämplar` |
| `Current frame: %1/%2` | `Aktuell ram: %1/%2` | `Aktuell bildruta: %1/%2` |
| `Current frame: %1 ≤ <i>t</i> &lt; %2` | `Aktuell ram: %1 ≤ <i>t</i> &lt; %2` | `Aktuell bildruta: %1 ≤ <i>t</i> &lt; %2` |
| `Automatically reset and repeat the animation endlessly` | `Återställ och repetera animationen automatiskt utan slut` | `Återställ och upprepa automatiskt animationen kontinuerligt` |
| `Loop` | `Loopa` | `Upprepa` |
| `Animation range` | `Animationsomfång` | `Animationsintervall` |
| `Total frames` | `Totalt antal ramer` | `Totalt antal bildrutor` |
| `Frame rate (frames per second)` | `Bildhastighet (bilder per sekund)` | `Bildfrekvens (bildrutor per sekund)` |
| `Your JSON was invalid and has been reverted back to the last valid edit or the original data` | `Ditt JSON var ogiltigt och har återställts till senast giltiga redigering eller ursprunglig data` | `JSON-data var ogiltiga och har återställts till den senast giltiga ändringen eller ursprungliga data` |
| `Not set` | `Inte satt` | `Ej angivet` |
| `Square` | `Fyrkantig` | `Kvadrat` |
| `Select Buffer Color` | `Välj färg på buffert` | `Välj buffertfärg` |
| `Select Stroke Color` | `Välj Pennfärg` | `Välj konturlinjefärg` |
| `Select Shadow Color` | `Välj färg på skugga` | `Välj skuggfärg` |

hämtas och måltexterna jämföras före en separat deltafil kan skapas.
