# QGIS: OGR-status och fältexport 265

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar OGR-providerns korta statusmeddelanden och exportfel.
`GDAL` bevaras som produktnamn. `Feature` följer QGIS-termen `objekt` och
fältnamn samt platshållare bevaras exakt.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Non existing feature` | `Icke existerande objekt` | `Objektet finns inte.` |
| `Success` | `Succé` | `Lyckades` |
| `GDAL result code: %1` | `GDAL resultatkod: %1` | `GDAL-resultatkod: %1` |
| `Creating the data source %1 failed: %2` | `Skapandet av datakällan %1 misslyckades: %2` | `Det gick inte att skapa datakällan %1: %2` |
| `Unknown vector type of %1` | `Okänd vektortyp av %1` | `Okänd vektortyp för %1` |
| `field %1 with unsupported type %2 skipped` | `fält %1 med en icke stödd typ %2 hoppades över` | `Fältet %1 med den typ som inte stöds, %2, hoppades över.` |
| `creation of field %1 failed` | `skapandet av fält %1 misslyckades` | `Det gick inte att skapa fältet %1.` |

Ingen extern ändring har gjorts. De rekommenderade texterna är lokala
kandidater tills de har jämförts mot aktuella Transifex-enheter vid en senare
uppladdning. Ändringarna är lokalt granskade och inte skickade externt.
