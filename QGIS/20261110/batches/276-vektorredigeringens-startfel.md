# QGIS: vektorredigeringens startfel 276

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar fel som uppstår när en gemensam redigeringssession eller
transaktion ska startas. Platshållaren `%1` och de omgivande enkla
citattecknen bevaras så att lagnamn och dataleverantör återges oförändrade.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Can't start editing invalid layer '%1'.` | `Kan inte starta redigering i ogiltigt lager "%1".` | `Det går inte att börja redigera det ogiltiga lagret '%1'.` |
| `Can't start editing layer '%1' with invalid data provider.` | `Kan inte starta redigering i lager "%1" med ogiltig datakälla.` | `Det går inte att börja redigera lagret '%1' med en ogiltig dataleverantör.` |
| `Can't start editing. Layer '%1' doesn't support editing.` | `Kan inte starta redigering. Lager "%1" stöder inte redigering.` | `Det går inte att börja redigera. Lagret '%1' har inte stöd för redigering.` |
| `Circular relation between some layers. Correct saving order of layers can't be guaranteed` | `Cirkulär relation mellan några lager. Korrekt ordning för att spara lagren kan inte garanteras` | `Cirkulär relation mellan vissa lager. Korrekt sparordning för lagren kan inte garanteras.` |
| `Layer '%1' doesn't have a valid data provider` | `Lager "%1" har inte en giltig datakälla` | `Lagret '%1' har ingen giltig dataleverantör.` |

Ingen extern ändring har gjorts. De rekommenderade texterna är lokala
kandidater tills de jämförts mot aktuella Transifex-enheter i en senare
uppladdningsbatch.
