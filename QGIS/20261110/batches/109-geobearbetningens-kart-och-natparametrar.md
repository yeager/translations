# QGIS: geobearbetningens kart- och nätparametrar 109

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar kartlager-, matris- och nätparametrar i geobearbetningen.
Terminologin följer diskussionsunderlaget för Qgis.se: `dataset` blir
`datamängd` och `mesh layer` blir `nätlager`. Exempelvärdet `base maps`
bevaras oförändrat.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Vector (Point)` | `Vektor (Punkt)` | `Vektor (punkt)` |
| `Vector (Line)` | `Vektor (Linje)` | `Vektor (linje)` |
| `Vector (Polygon)` | `Vektor (Polygon)` | `Vektor (polygon)` |
| `Vector (Any Geometry Type)` | `Vektor (Alla geometrityper)` | `Vektor (valfri geometrityp)` |
| `Vector (No Geometry Required)` | `Vektor (Ingen geometri krävs)` | `Vektor (geometri krävs inte)` |
| `Mesh` | `Mesh` | `Nät` |
| `map theme as a string value (e.g. 'base maps')` | `karttema som textvärde (t.ex. 'baskarta')` | `karttema som strängvärde (till exempel 'base maps')` |
| `comma delimited string of values, or an array of values` | `kommaseparerad textsträng med värden eller en array med värden` | `kommaseparerad sträng med värden eller en matris med värden` |
| `%1 dataset groups selected` | `%1 datasetsgrupper valda` | `%1 datamängdsgrupper har valts` |
| `Current Active Dataset Group` | `Nuvarande aktiva datasetsgrupp` | `Aktuell datamängdsgrupp` |
| `Select in Available Dataset Groups` | `Välj bland tillgängliga datasetsgrupper` | `Välj bland tillgängliga datamängdsgrupper` |
| `Dataset Groups Available` | `Tillgängliga datasetsgrupper` | `Tillgängliga datamängdsgrupper` |
| `Dataset group time step` | `Tidssteg i datasetsgrupp` | `Tidssteg för datamängdsgrupp` |
| `path to a mesh layer` | `sökväg till ett mesh-lager` | `sökväg till ett nätlager` |
| `Could not load model %1` | `Kunde inte öppna modell %1` | `Kunde inte läsa in modell %1` |
| `“%1” from algorithm “%2”` | `"%1" från algoritm "%2"` | `“%1” från algoritmen “%2”` |
| `Multiple Selection` | `Flera val` | `Flera markeringar` |
| `Select File(s)` | `Välj Fil(er)` | `Välj fil(er)` |
