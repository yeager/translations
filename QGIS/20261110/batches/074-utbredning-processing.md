# QGIS: utbredning i bearbetningsverktyg 074

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen tillämpar QGIS-projektets fastställda term **utbredning** för *extent*
i parameternamn, verktygstips och algoritmbeskrivningar. Den avgränsade
översättningen `GRASS` lämnas som produktnamn.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Match the extent of the clipped raster to the extent of the mask layer` | `Passa utsträckningen för klippt raster med utsträckningen av masklagret` | `Anpassa det klippta rastrets utbredning till masklagrets utbredning` |
| `Target extent` | `Målets utsträckning` | `Målutbredning` |
| `Clip vector by extent` | `Klipp vektordata från utsträckning` | `Klipp vektordata efter utbredning` |
| `GRASS region extent` | `GRASS områdesutsträckning` | `GRASS-områdets utbredning` |
| `Map extent` | `Kartans utsträckning` | `Kartans utbredning` |
| `Select features by extent (defined in input layer CRS)` | `Välj objekt efter utsträckning (definierad i indatalagrets referenskoordinatsystem)` | `Välj objekt efter utbredning (definierad i indatalagrets referenskoordinatsystem)` |
| `Clip the input layer using the above (rectangle) extent` | `Klipp ingående lager med hjälp av ovanstående (rektangel) utsträckning` | `Klipp indatalagret med hjälp av ovanstående rektangulära utbredning` |
| `Limit exported features to those with geometries intersecting the provided extent` | `Begränsa exporterade objekt till de vars geometrier skär den angivna utsräckningen` | `Begränsa exporterade objekt till dem vars geometrier skär den angivna utbredningen` |

Ingen extern ändring har gjorts. Aktuella Transifex-enhetsidentifierare måste
hämtas innan en separat deltafil kan skapas.
