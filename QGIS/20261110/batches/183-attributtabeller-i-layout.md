# QGIS: attributtabeller i layout 183

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar inställningarna för attributtabeller i QGIS layoutdesigner.
`feature` återges som `objekt`, medan `atlas feature` är `atlasobjekt`.
`Toggle` återges med verbet `Växla`, vilket gör verktygstipsen handlingsbara.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Layer Features` | `Objekt från lager` | `Lagerobjekt` |
| `Current %1 Feature` | `Aktuellt %1 objekt` | `Aktuellt %1-objekt` |
| `Change Table Text Format` | `Ändra textformat för tabell` | `Ändra tabellens textformat` |
| `Current Atlas Feature` | `Aktuellt kartboksobjekt` | `Aktuellt atlasobjekt` |
| `Relation Children` | `Relation "barn"` | `Relationens underordnade objekt` |
| `Toggle Visible Features Only` | `Växla Endast Synliga Objekt` | `Växla visning av endast synliga objekt` |
| `Toggle Table Filter Duplicates` | `Växla Filtrera Tabelldubbletter` | `Växla filtrering av tabelldubbletter` |
| `Toggle Empty Frame Mode` | `Växla till läge för tomma ramar` | `Växla läge för tom ram` |
| `Toggle Background Display` | `Växla Visning av Bakgrund` | `Växla visning av bakgrund` |
| `Toggle Table Atlas Filter` | `Tabell Kartboksfilter Av/På` | `Växla tabellens atlasfilter` |
| `Toggle Table Feature Filter` | `Växla Filter för Tabellobjekt` | `Växla tabellens objektfilter` |
| `Change Table Alignment` | `Ändra Tabelljustering` | `Ändra tabelljustering` |
| `Change Table Header Mode` | `Ändra Läge för Tabellhuvud` | `Ändra läge för tabellhuvud` |
| `Change Table Wrap String` | `Ändra Tabellens Radbrytstext` | `Ändra tabellens radbrytningstext` |
| `Change Resize Mode` | `Ändra Storleksändringsläge` | `Ändra storleksändringsläge` |

| `Change Show Empty Rows` | `Ändra visa tomma rader` | `Ändra visning av tomma rader` |
| `Remove duplicate rows from table` | `Ta bort duplicerade rader från tabell` | `Ta bort dubblettrader från tabellen` |

| `Wrap text on` | `Bryt text på` | `Radbryt text vid` |
| `Message to display` | `Meddelande att visa` | `Meddelande som ska visas` |

Ingen extern ändring har gjorts. Aktuella Transifex-enhetsidentifierare måste
hämtas och måltexterna jämföras före en separat deltafil kan skapas.
