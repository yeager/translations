# QGIS: nätredigering och höjdegenskaper 211

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar höjdegenskaper och redigering för nätlager. `mesh` återges
som `nät`, `dataset` som `datamängd` och `Z` bevaras som koordinatbeteckning.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Remove Extra Dataset from Mesh` | `Ta bort extra dataset från Mesh` | `Ta bort extra datamängd från nät` |
| `Display dataset` | `Visa dataset` | `Visa datamängd` |
| `Prefer mesh, then Z Widget` | `Föredra mesh, sen Z.widget` | `Föredra nät, därefter Z-widgeten` |
| `Get interpolated value from the existing mesh.\nIf vertex lies outside the mesh, get the value from the Z value widget instead.` | `Hämta interpolerat värde från existerande mesh.\nOm brytpunkten ligger utanför mesh, hämta värdet från Z-widget istället.` | `Hämta interpolerat värde från det befintliga nätet.\nOm brytpunkten ligger utanför nätet hämtas värdet i stället från Z-värdewidgeten.` |
| `Prefer mesh, then terrain` | `Föredra mesh, sen terräng` | `Föredra nät, därefter terräng` |
| `Get interpolated value from the existing mesh.\nIf vertex lies outside the mesh, get the value from the project terrain instead.` | `Hämta interpolerat värde från existerande mesh.\nOm brytpunkten ligger utanför mesh, hämta värdet från projektets terräng istället.` | `Hämta interpolerat värde från det befintliga nätet.\nOm brytpunkten ligger utanför nätet hämtas värdet i stället från projektets terräng.` |
| `Z Widget` | `Z-widget` | `Z-värdewidget` |

| `Forcing line` | `Tvinga linje` | `Styrande linje` |
| `vertices Z value` | `Brytpunkters Z-värde` | `Brytpunkternas Z-värde` |
| `Not set` | `Inte satt` | `Inte angivet` |
| `Mesh Elevation Properties` | `Höjdegenskaper mesh` | `Höjdegenskaper för nät` |

markup bevaras i en senare deltafil. Ingen extern ändring har gjorts.
