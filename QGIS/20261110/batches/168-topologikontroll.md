# QGIS: topologikontroll 168

Datum: 10 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar topologitilläggets panel och felmeddelanden. `feature`
översätts som `objekt` i QGIS gränssnitt och `plugin` som `tillägg`.
Platshållaren `%1` och båda pluralformerna bevaras.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Validate Extent` | `Validera utsträckning` | `Validera utbredning` |
| `Select automatic fix` | `Välj automatisk lösning` | `Välj automatisk åtgärd` |
| `Fix!` | `Lös!` | `Åtgärda!` |
| `No errors were found` | `Inga fel funna` | `Inga fel hittades` |
| `Invalid first layer` | `Ogiltigt första lager` | `Första lagret är ogiltigt` |
| `Topology plugin` | `Topologi-plugin` | `Topologitillägg` |
| `Invalid first geometry` | `Ogiltig första geometri` | `Första geometrin är ogiltig` |
| `Feature not found in the layer.\nThe layer has probably changed.\nRun topology check again.` | `Objekt inte funnet i lagret.\nLagret har förmodligen ändrats.\nKör topologikontrollen igen.` | `Objektet hittades inte i lagret.\nLagret har förmodligen ändrats.\nKör topologikontrollen igen.` |
| `Invalid second layer` | `Ogiltigt andra lager` | `Andra lagret är ogiltigt` |
| `Invalid second geometry` | `Ogiltig andra geometri` | `Andra geometrin är ogiltig` |
| `%n error(s) were found` | `%n fel funna` i båda pluralformerna | `%n fel hittades` i båda pluralformerna |
| `Topology fix error` | `Topologi fixa fel` | `Fel vid topologiåtgärd` |
| `Fixing failed!` | `Lösning misslyckades!` | `Åtgärden misslyckades!` |
| `Show errors on the canvas` | `Visa fel på kartyta` | `Visa fel på kartytan` |

Ingen extern ändring har gjorts. Aktuella Transifex-enhetsidentifierare måste
hämtas och måltexterna jämföras före en separat deltafil kan skapas.
