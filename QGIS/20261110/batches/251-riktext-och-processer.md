# QGIS: riktext och processer 251

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar riktextredigerarens bilddialog och meddelanden från
processkörning. `URL` och platshållaren `%1` bevaras.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Enter the URL of an image:` | `Skriv in URL för en bild:` | `Ange bildens URL:` |
| `Failed to download the image: %1` | `Misslyckades med att ladda ner bilden: %1` | `Kunde inte hämta bilden: %1` |
| `The URL did not return an image.` | `URL returnerade inte en bild.` | `URL:en returnerade ingen bild.` |
| `Link URL:` | `Länk-URL:` | `Länkens URL:` |
| `Action` | `Kommando` | `Åtgärd` |
| `Unable to run command\n%1` | `Kan inte utföra kommandot\n%1` | `Det gick inte att köra kommandot\n%1` |
| `Unable to run command %1` | `Kan inte utföra kommandot %1` | `Det gick inte att köra kommandot %1` |

Ingen extern ändring har gjorts. De rekommenderade texterna är lokala
kandidater tills de har jämförts mot aktuella Transifex-enheter vid en senare
uppladdning.
