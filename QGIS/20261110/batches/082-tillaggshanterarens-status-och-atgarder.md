# QGIS: tilläggshanterarens status och åtgärder 082

Datum: 10 november 2026  
Resurs: `qgis-application`, språk `sv`  
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar tilläggshanterarens statusrader och beskrivningar av
åtgärdsknappar. I QGIS-gränssnittet används `tillägg` konsekvent. `Repository`
är `centralkatalog` när det är en tilläggskatalog, men `code repository` är ett
kodförråd.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `This plugin requires a missing module` | `Detta plugin kräver en saknad modul` | `Det här tillägget kräver en modul som saknas.` |
| `This plugin is broken` | `Detta plugin är trasigt` | `Det här tillägget är trasigt.` |
| `There is a new version available` | `Det finns en ny version tillgänglig` | `Det finns en ny version.` |
| `This is a new plugin` | `Detta är ett nytt plugin` | `Det här är ett nytt tillägg.` |
| `Installed version of this plugin is higher than any version found in repository` | `Installerad version av detta plugin är högre än vad som finns i centralkatalogen` | `Den installerade versionen av det här tillägget är nyare än någon version i centralkatalogen.` |
| `This plugin is deprecated` | `Detta plugin är föråldrat` | `Det här tillägget är föråldrat.` |
| `bug tracker` | `felsökare` | `felhanteringssystem` |
| `code repository` | `centralkatalog för kod` | `kodförråd` |
| `updated at %1 %2` | `uppdaterad vid %1 %2` | `uppdaterades %1 %2` |
| `updated at %1` | `uppdaterad vid %1` | `uppdaterades %1` |
| `Upgrades selected plugin to latest stable version` | `Uppgraderar vald tillägg till senaste stabila version` | `Uppgraderar det valda tillägget till den senaste stabila versionen.` |
| `Downgrades selected plugin to latest stable version` | `Nedgraderar vald tillägg till senaste stabila version` | `Nedgraderar det valda tillägget till den senaste stabila versionen.` |
| `Installs latest stable version of the selected plugin` | `Installerar senaste stabila version av vald tillägg` | `Installerar den senaste stabila versionen av det valda tillägget.` |
| `Reinstalls latest stable version of the selected plugin` | `Återinstallerar senaste stabila version av vald tillägg` | `Installerar om den senaste stabila versionen av det valda tillägget.` |
| `Installs experimental version of the selected plugin` | `Installerar experimentell version av vald tillägg` | `Installerar den experimentella versionen av det valda tillägget.` |
| `Reinstalls experimental version of the selected plugin` | `Åternstallerar experimentell version av vald tillägg` | `Installerar om den experimentella versionen av det valda tillägget.` |
| `Upgrade Experimental Plugin` | `Uppgradera experimentell tillägg` | `Uppgradera experimentellt tillägg` |
| `Downgrade Experimental Plugin` | `Nedgradera experimentell tillägg` | `Nedgradera experimentellt tillägg` |
| `Install Experimental Plugin` | `Installera experimentell tillägg` | `Installera experimentellt tillägg` |
| `Reinstall Experimental Plugin` | `Ominstallera experimentell tillägg` | `Installera om experimentellt tillägg` |

Platshållarna `%1` och `%2` är oförändrade. Ingen extern ändring har gjorts.
Aktuella Transifex-enhetsidentifierare måste hämtas och måltexterna jämföras
före en separat deltafil kan skapas.
