# QGIS: GPX och GRASS-feltexter 260

Datum: 11 november 2026
Resurs: `qgis-application`, språk `sv`
Källsnapshot: `raw/qgis-application-sv-transifex-live-20261110.ts`

Batchen granskar GPX-datakällan och GRASS-providerns korta feltexter.
`GPX` är det etablerade formatnamnet, medan `GISRC`, `stdout` och `stderr`
är tekniska identifierare som inte översätts.

| Källa | Befintlig svenska | Rekommenderad svenska |
|---|---|---|
| `Parse error at line %1 : %2` | `Tolkningsfel på rad %1 : %2` | `Tolkningsfel på rad %1: %2` |
| `GPS eXchange format provider` | `GPS eXchange format datakälla` | `GPX-datakälla` |
| `Cannot read vector map region` | `Kan inte läsa vektorkartans region` | `Det gick inte att läsa vektorkartans region.` |
| `Cannot find module %1` | `Kan inte hitta modul %1` | `Det gick inte att hitta modulen %1.` |
| `Cannot open GISRC file` | `Kan inte öppna GISRC-fil` | `Det gick inte att öppna GISRC-filen.` |
| `Cannot run module` | `Kan inte köra modul` | `Det gick inte att köra modulen.` |
| `Attempt to copy from different location.` | `Försöker kopiera från annan plats.` | `Det går inte att kopiera från en annan plats.` |
| `Delete confirmation` | `Radera bekräftelse` | `Bekräfta borttagning` |
| `Are you sure you want to delete %1 %2?` | `Är du säker att du vill radera %1 %2?` | `Är du säker på att du vill ta bort %1 %2?` |
| `Cannot insert, statement: '%1' error: '%2'` | `Kan inte infoga, uttryck: '%1' fel: '%2'` | `Det gick inte att infoga. Uttryck: '%1'. Fel: '%2'.` |

Ingen extern ändring har gjorts. De rekommenderade texterna är lokala
kandidater tills de har jämförts mot aktuella Transifex-enheter vid en senare
uppladdning. Ändringarna är lokalt granskade och inte skickade externt.
