# OpenCloud web-admin-settings – svenska översättningar

3 administrationssträngar granskades i UI-kontext, validerades med l10n-lint, svlang, Hunspell, diffkontroll och Gitleaks, samt skickades i en Transifex API-batch 2026-11-12. HTTP 200 bekräftades och en ny API-läsning visade 0 oöversatta svenska strängar. Hunspell-träffen `user` är ett platshållarnamn. `msgfmt` är inte tillämpligt för JSON-resursen.
