## Omfattning

Tjugo dokumentationsenheter har granskats rad för rad och sparats i Hosted Weblate med dess REST API. De behandlar ordlistor, terminologi, TBX, ordlistespråk och synkronisering.

## Lokal granskning

reST-referenser, TBX, flaggor, produktnamn och terminologibegrepp har bevarats. Svenskan följer Weblates egen ordliste- och redigerarkontext.
