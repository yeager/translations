Tjugo dokumentationsenheter har granskats rad för rad och sparats i Hosted Weblate med dess REST API. De behandlar behörighetscachar, LLM, PostgreSQL, Granian, arbetsflödesprestanda och Discover Weblate.

## Lokal granskning

reST-referenser, kod, protokoll, produktnamn, UI-namn och tekniska begrepp har bevarats. Terminologi följer administrations- och driftsättningskontexten.

Ändringarna sparades i Hosted Weblate via REST API och lästes tillbaka som översatta, med statusen **väntar på granskning**. De är inte verifierade som upstream-granskade eller mergade.
