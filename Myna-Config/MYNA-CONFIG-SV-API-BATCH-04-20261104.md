# Myna Config: svensk API-batch 04

Datum: 2026-11-04

Källa: Hosted Weblates autentiserade API,
`ubuntu-desktop-translations/myna-config/sv`, sida 4 av oöversatta poster.

## Kontext och avgränsning

Batchen täcker installation av den lokala dikteringsmiljön, dess status- och
felinformation samt inställningen för när en modell laddas ur ur minnet.
Platshållarna `{setting}`, `{size}`, `{step}` och `{percent}` bevaras exakt.
`D-Bus` och den tekniska benämningen *demon* behålls som etablerade
systemtermer.
