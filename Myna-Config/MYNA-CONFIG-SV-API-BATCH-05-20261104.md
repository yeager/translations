# Myna Config: svensk API-batch 05

Datum: 2026-11-04

Källa: Hosted Weblates autentiserade API,
`ubuntu-desktop-translations/myna-config/sv`, sida 5 av oöversatta poster.

## Kontext och avgränsning

Batchen omfattar fel- och statusmeddelanden för Myna Settings samt anslutna
tal-till-text-modeller. *Switching* betyder här att byta aktiv modell, inte
att slå på eller av programmet. I modellbeskrivningen bevaras de
icke-radbrytande mellanrummen runt mittpunkten exakt.
