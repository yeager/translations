# Myna Config: svensk API-batch 02

Datum: 2026-11-04

Källa: Hosted Weblates autentiserade API,
`ubuntu-desktop-translations/myna-config/sv`, sida 2 av oöversatta poster.

## Kontext och konsekvens

Batchen gäller Myna Settings huvudfönster och introduktionsflöde. `Myna` är
produktnamn. Menyrader behåller inledande understreck som snabbtangent och
tecknet `…`. Termerna `diktering`, `modell`, `tangentbordsgenväg` och
`komponent` följer batch 01.
