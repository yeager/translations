# Cacti WMI: kontroll av aktuell release

Kontrollerad 2026-10-27 mot `Cacti/plugin_wmi` på GitHub.

Projektet har varken officiella GitHub-releaser eller Git-taggar. Det finns
färska käll- och Weblate-synkroniseringscommitar, men de fastställer inte ett
officiellt publiceringsdatum. Därför går det inte att verifiera att senaste
releasen är högst 48 månader gammal.

Enligt lokaliseringspolicyn ska inget nytt gransknings-, import- eller
uppladdningsarbete göras för WMI förrän en officiell aktuell release eller
annan verifierbar releasekanal kan visas. Den arkiverade deltafilen behålls
som historiskt underlag men är inte redo för import.
