# RetroArch, svensk Crowdin-kontroll

Datum: 11 november 2026

Crowdins API kontrollerades med den etablerade projektåtkomsten för den
svenska målgruppen. Samtliga komponenter som returnerades av filprogress-API:t
har `translationProgress` 100. Ingen svensk RetroArch-fil har alltså en
ofullständig översättning.

Huvudkomponenten omfattar 4 820 fraser och 34 634 ord, samtliga översatta.
Godkännandegraden för den komponenten är 46 % (2 998 fraser och 16 002 ord).
Godkännande är ett separat projektflöde och ändrades inte i denna kontroll.

Ingen lokal deltafil skapades och inget skickades upstream, eftersom API:t
inte visar någon oöversatt sträng.
