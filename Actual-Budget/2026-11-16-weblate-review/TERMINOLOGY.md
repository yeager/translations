# Actual Budget Swedish terminology

| English | Swedish | Context and decision |
| --- | --- | --- |
| account | konto | Financial account in the main UI. |
| category | kategori | Budget category. |
| category group | kategorigrupp | Group containing budget categories. |
| payee | betalningsmottagare | Named recipient or merchant on a transaction. |
| transaction | transaktion | Financial transaction. |
| schedule | schema | Recurring transaction schedule. |
| due schedule | schema som förfaller | A schedule due today; do not use the misleading `förfallet schema`. |
| post transaction | bokför transaktion | Creates the scheduled transaction in the account. |
| opening balance | ingående saldo | Established Swedish accounting term. |
| closing balance | utgående saldo | Established Swedish accounting term. |
| tracking budget | uppföljningsbudget | Actual's documented alternative to Envelope Budget. |
| tracking budgeting | uppföljningsbudgetering | The mode or action of using a tracking budget. |
| To Be Budgeted | Att budgetera | Visible product metric; preserve capitalization when it is a UI label. |
| Saved | Sparat | Visible product metric in Tracking Budget. |
| hard cap | hårt tak | UI label for a spending limit; retain the contrast with `soft cap`. |
| soft cap | mjukt tak | UI label for a spending limit; retain the contrast with `hard cap`. |
| query | fråga | Formula/query feature. Avoid the general-search sense `sökning` when the source denotes a query definition. |
| regular expression | reguljärt uttryck | Standard technical term. |
| data directory | datakatalog | Actual storage location. |
| load (verb) | läs in | Read data, a report or a backup into the application. Avoid the vague UI loan translation `ladda` in this sense. |
| loading | läser in / inläsning | Use a verb for live progress text and `inläsning` where a noun is required. |
| server sync | serversynkronisering | Synchronization with Actual's server. |
| end-to-end encryption | totalsträckskryptering | Established Swedish security term. |

Product names, API names, placeholders, formula literals, currency codes and
visible identifiers are retained unchanged unless a separate source explicitly
defines a Swedish form.
