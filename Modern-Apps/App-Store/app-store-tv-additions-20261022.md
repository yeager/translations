# Modern Apps App Store – TV-tillägg

Källa: aktuella oöversatta enheter i Hosted Weblate, granskade 2026-10-22.

| Nyckel | Engelska | Svenska |
| --- | --- | --- |
| `tv_browse_title` | App Store | App Store |
| `tv_detail_back` | Back | Tillbaka |
| `tv_detail_about` | About | Om |
| `tv_detail_author` | Developer | Utvecklare |
| `tv_compat_declared` | Works on TV — the source lists a TV version | Fungerar på TV – källan anger en TV-version |
| `tv_compat_unverified` | TV compatibility unverified — checked at install | TV-kompatibilitet ej verifierad – kontrolleras vid installation |

Den lokala XML-exporten saknar dessa nyligen tillagda källsträngar. För att undvika att äldre katalogdata skrivs upp över nyare upstreaminnehåll ska en ny export hämtas när Hosted Weblate öppnar, och exakt dessa sex måltexter sedan föras in.
