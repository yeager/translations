# Ymir: svensk översättning av uppdateringsdialogen

Den lokala Ymir-patchen lägger till svenska texter för dialogen med automatiska uppdateringskontroller.

- Svenskt språkläge väljs via `LC_ALL`, `LC_MESSAGES` eller `LANG` med prefixet `sv`.
- Kontroller: `git diff --check` utan fel, svlang utan skrivregelfel och Gitleaks utan träffar.
- Hunspell markerade endast egennamnet `github.com`.
- Denna säkerhetskopia innehåller hela den lokala, oskickade Ymir-diffen vid tidpunkten för granskningen.
