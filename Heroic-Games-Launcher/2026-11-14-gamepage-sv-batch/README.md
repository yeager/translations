# Heroic Games Launcher, svensk GamePage-batch

Datum: 14 november 2026

Hosted Weblate visar 24 berörda svenska poster i GamePage: 19 tomma och fem
fuzzy. Batcher täcker spelåtgärder, omslagsbilder, SteamGridDB, Steam Deck-
status och itch.io-import. Alla fem fuzzy-poster normaliseras till aktuella
etiketter samtidigt som de tomma posterna fylls i.

`Cover Art` och `Cover Image` översätts som `Omslagsbild`; `Square Art` och
`Square Image` som `Kvadratisk bild`. SteamGridDB, itch.io, API och
platsmarkören `{{hours}}` behålls.

## Upstream

Batchen är inte inskickad. Den inloggade Hosted Weblate-sessionen har
skrivbehörighet först efter att bidragsgivaren har godkänt Heroic Games
Launchers licensavtal för bidragsgivare. Editorn visar därför 24 av 24
berörda poster, men Spara och Föreslå är avstängda. Ett sådant avtal kan inte
godkännas automatiskt.

När avtalet har godkänts kan den här deltafilen skickas in och resultatet
återläsas i Weblate.
