# Heroic Games Launcher – svensk terminologi

Senast uppdaterad: 2026-11-15  
Källor: Heroic Games Launcher UI, `v2.22.4`, svenska login-page och etablerad
svensk spel- och programvaruterminologi.

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| game | spel | Standardterm. |
| game page | spelsida | Sidan för ett enskilt spel. |
| game library | spelbibliotek | Samling av spel. |
| launcher | startprogram | Använd “Heroic” när produktnamnet avses. |
| launch | starta | Verb för att köra ett spel. |
| install | installera | Verb; “installation” som substantiv. |
| uninstall | avinstallera | Ta bort installerat spel. |
| update | uppdatera | Verb; “uppdatering” som substantiv. |
| download | hämta | UI-verb; “nedladdning” som substantiv/status. |
| cloud save | molnsparning | Speldata synkroniserad via molnet. |
| save file | sparfil | Inte “spara fil”. |
| compatibility | kompatibilitet | Spel- eller plattformskompatibilitet. |
| compatibility layer | kompatibilitetslager | Wine/Proton-liknande teknik. |
| prefix | prefix | Teknisk Wine-term. |
| wrapper | omslag | Endast när UI-kontexten kräver den. |
| settings | inställningar | UI-sida eller val. |
| configuration | konfiguration | Mer teknisk beständig kontext. |
| log | logg | Loggfil eller felsökningsinformation. |
| log in / sign in | logga in | Använd konsekvent. |
| account | konto | Tjänstekonto. |
| credentials | inloggningsuppgifter | Säkerhets- och inloggningstext. |
| API key | API-nyckel | Standardterm. |
| clipboard | urklipp | Systemfunktion. |
| install path | installationssökväg | Teknisk sökväg. |
| default | standardvärde | Kodvärdet `default` lämnas oförändrat. |
| error | fel | Kort UI-status. |
| warning | varning | Risk- eller kompatibilitetsinformation. |

## Lämnas oförändrat

Heroic, Steam, Steam Guard, Steam Mobile, itch.io, Epic Games, GOG, Amazon
Games, Discord, GitHub, API, QR, URL, Wine, Proton, DXVK, VKD3D, Linux, macOS,
Windows, SID, OAuth och anticheat. Bevara dessutom kod, miljövariabler,
filändelser, länkar, HTML-markup och platshållare exakt.
