# Wine, svensk terminologi

| Engelska | Svenska | Sammanhang |
| --- | --- | --- |
| uninstall | avinstallera | Programhantering |
| modify | ändra | Programhantering |
| pair | para ihop | Bluetooth |
| PIN/passkey | PIN-kod/lösenord | Bluetooth; behåll värdeplatshållare |
| proxy server | proxyserver | Nätverksinställning |
| Web Proxy Auto-Discovery | automatisk identifiering av webbproxy | Behåll WPAD |
| Proxy Auto-Config script | proxykonfigurationsskript | Behåll PAC |
| game controller | spelkontroll | Inställningspanel |
| compilation error | kompileringsfel | JScript |
| runtime error | körningsfel | JScript |
| exception | undantag | Programmeringsfel |
| remaining | återstår | Tidsåterstående; bevara `!u!`-platshållare |
| flip on short/long edge | vänd längs kort-/långsidan | Dubbelsidig utskrift |
| display mode | visningsläge | Bildskärmsinställning |
| codec | kodek | Behåll tekniknamnet IYUV/Indeo |
| axes | axlar | Spelkontroll |
| rumble | vibration | Spelkontroll |
| property | egenskap | ECMAScript-fel |
| accessor | åtkomstfunktion | ECMAScript-fel |
| typed array | typad array | ECMAScript-fel |
| non-extensible | icke-utbyggbar | ECMAScript-objekt |
| DataView | DataView | API-namn, översätt inte |
