# NxEmu

`sv.po` är den aktuella svenska katalogen för NxEmus gemensamma gränssnitt på
skrivbord och Android. Den motsvarar PR [N3xoX1/nxemu#489](https://github.com/N3xoX1/nxemu/pull/489),
som mergades 2026-10-28 med commit `c11c05dd`.

Filerna under `android/` är äldre arbetsunderlag från tiden då Android hade en
egen översättningslösning. De sparas för spårbarhet men ska inte användas för
nya ändringar.
