# Azahar, terminologi

| Engelska | Rekommenderad svenska | Sammanhang | Undantag |
| --- | --- | --- | --- |
| permission | behörighet | Android-systemdialoger | Följer Androids svenska UI-språk. |
| local network | lokalt nätverk | Åtkomst för anslutning till fysisk 3DS | Inte ”LAN” i användargränssnittet. |
| per-application settings | inställningar per program | Inställningar som åsidosätter globala värden | Konsekvent i etiketter och hjälptexter. |
| global settings | globala inställningar | Delade inställningar för programmet | Skiljs från per-program-inställningar. |
| binding | bindning | Handkontrollens tilldelning | Inte ”koppling”, som är tvetydigt i UI:t. |
| frame | bildruta | Emulerings- och GPU-kö | Stämmer med etablerad grafikterminologi. |
| input latency | inmatningsfördröjning | Svarstid för kontroller | Klarare än engelskt lånord. |
| savestate | snabbsparning | Emulatorfunktion | Etablerad emulatorbenämning. |
| control mask | styrmask | Bildstyrning | Används om motsvarande term dyker upp i fler resurser. |
| GPU, 3DS, Adreno, Vulkan, Anime4K, homebrew | oförändrade | Produkt-, teknik- och plattformsnamn | Översätts inte. |
