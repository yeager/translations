# Warzone 2100 webbplats – svensk terminologi

Den här listan gäller den lokala arbetskopian av `themes/wz2100net/i18n/en.json`. Den är inte uppladdad till Crowdin och blir en granskningsgrund när svenska har aktiverats.

| Engelsk term | Svensk term | Kontext och beslut |
| --- | --- | --- |
| Download | hämta | Knappetikett för nedladdning av Warzone 2100. |
| Download mirror | nedladdningsspegel | Alternativa värdar för samma utgåva. |
| Installer | installationsprogram | Windows- och Snap-hämtningar. |
| Portable version | bärbar version | Version som körs från en lokal mapp eller USB-minne. |
| Settings / saves | inställningar och sparade spel | Spelfiler som lagras lokalt. |
| Source code | källkod | Källarkiv eller källkodspaket. |
| Development build | utvecklingsbygge | Bygge från projektets pågående utveckling. |
| Development source code | källkod för utvecklingsversioner | Länk till källan för pågående utveckling. |
| Release | utgåva | Publicerad Warzone 2100-version. |
| AI Bot | AI-motståndare | Datorkontrollerad motståndare i drabbning eller flerspelarläge. |
| Cross-platform | plattformsoberoende | Beskriver stöd mellan operativsystem. |
| Open source | öppen källkod | Programvarans licens- och utvecklingsmodell. |
| Campaign | kampanj | Spelets berättelsedrivna enspelarläge. |
| Multiplayer | flerspelarläge | Nätspel via LAN eller internet. |
| Tech tree | teknikträd | Spelmekanik med forskningsvägar. |
| Unit Designer | enhetskonstruktör | Namn på spelets system för att skapa enheter. |
| The Project | The Project | Egennamn i spelets bakgrundshistoria; lämnas på engelska. |
| WMIT | WMIT (Warzone Model Import Tool) | Produktnamn och förkortning; lämnas oförändrade. |
| MSIX, Flatpak, Snap, DEB | MSIX, Flatpak, Snap, DEB | Paketformat och synliga produktnamn; lämnas oförändrade. |
| App Bundle | app-paket | Paketformat för macOS; bindestrecket undviker tre lika konsonanter i följd. |
| SHA256 | SHA256 | Kryptografisk kontrollsumma; lämnas oförändrad. |
