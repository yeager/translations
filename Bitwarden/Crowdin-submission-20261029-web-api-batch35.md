# Bitwarden Web — Crowdin API-häfte 35

Tretton PAM-händelser för åtkomstanslutningar och målsystem skickades via
Crowdins API. De följer den redan arkiverade Bitwarden-terminologin
*åtkomstanslutning* och *målsystem*.

- Underlag: `Bitwarden-Web-api-connectors-batch35-20261029.json`.
- Översättnings-id: `1980857`–`1980881`.
- Samtliga tretton måltexter lästes tillbaka och jämfördes exakt via API.

Åtta förslag har QA-status `passed`. Fem har QA-status `failed` och lämnas
som ogranskade förslag; inga har auto-godkänts.

JSON, `svlang skrivregler` och `hunspell-sv` passerade innan uppladdningen.
En API-kontroll bekräftade före POST att dessa nycklar saknade svenska
måltexter.
