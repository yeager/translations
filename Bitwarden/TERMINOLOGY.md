# Bitwarden – svensk terminologi

Uppdaterad 2026-11-11 efter granskning av Browser, mobil, Desktop och Web.

| Källterm | Svensk term | Anmärkning |
| --- | --- | --- |
| vault | valv | `vault item` = post i valvet. |
| credential | autentiseringsuppgift | Används även i PAM-flöden. |
| access | åtkomst | `access request` = åtkomstbegäran. |
| access rule | åtkomstregel | PAM-regel som styr begäranden. |
| access connector | åtkomstanslutning | Körs i det lokala nätverket. |
| target system | målsystem | System där lösenord roteras. |
| managed credential | hanterad autentiseringsuppgift | PAM-objekt med rotationsinställning. |
| rotation | rotation | `password rotation` = lösenordsrotation. |
| shared folder | delad mapp | Synligt Bitwarden-begrepp. |
| seat | användarplats | Abonnemangs- och gränsvärdeskontext. |
| desktop app | skrivbordsapp | Inte datorapp. |
| audit log | granskningslogg | `audit` i exempel och verb granskas efter lokal kontext. |
| Privileged Controls | Privileged Controls | Produktnamn, översätts inte. |
| Bitwarden Password Manager | Bitwarden Password Manager | Produktnamn, översätts inte. |
| Secrets Manager | Secrets Manager | Produktnamn, översätts inte. |
| Active Directory | Active Directory | Produktnamn, översätts inte. |

## Stil

- Behåll kod, platshållare och produktnamn ordagrant.
- Skriv `i dag` i UI-text och använd inte em dash om källtexten saknar den.
- Använd naturlig svensk imperativ i knappar, till exempel `Välj`, `Lägg till` och `Ta bort`.
