# Bitwarden Web — Crowdin API-häfte 33

Häftet omfattar elva revisionshändelser för rotationsflödet i PAM.
Terminologin följer de tidigare arkiverade Bitwarden-formerna:
*rotera*, *rotationsjobb*, *målsystem* och *åtkomstanslutning*.

- Projekt: Bitwarden - Web (`308189`), svenska (`sv-SE`).
- Underlag: `Bitwarden-Web-api-rotation-batch33-20261029.json`.
- Översättnings-id: `1980813`–`1980833`.

Alla elva måltexter skapades via API och lästes sedan tillbaka med exakt
textjämförelse. Sex har Crowdins QA-status `passed`; fem sparades som förslag
med QA-status `failed` och inväntar projektets granskning.

Före uppladdning passerade giltig JSON, `svlang skrivregler` och
`hunspell-sv`. Övriga aktuella svenska måltexter kontrollerades via API före
POST och ingen av dessa elva nycklar hade en svensk översättning.
