# Audacity: svensk terminologi

| Engelska | Svenska | Kontext |
| --- | --- | --- |
| Speed Limit | hastighetsgräns | Värdegräns i tidsstyrningsspårets hastighetsdialog. |
| Lower/Upper Speed Limit | nedre/övre hastighetsgräns | Fältnamn i samma dialog. |
| Legacy | äldre | Äldre, fortfarande tillgänglig effekt eller menygrupp. |
| Limiter | begränsare | Ljudeffekt som begränsar signalnivån. |
| Compressor | kompressor | Ljudeffekt som komprimerar dynamiskt omfång. |
| Latency | fördröjning | Tidsfördröjning för inspelning eller uppspelning. |
| Audio Unit | Audio Unit | Apples protokollnamn; översätts inte. |
| Audio Unit Effects | Audio Unit-effekter | Effekter via Apples Audio Unit-protokoll. |
| Property list | egenskapslista | Serialiserat Apple-format för inställningar. |
| Plugin | insticksmodul | Audacitys tillägg för effekter, ljud och funktioner. |
| Timer Recording | timerinspelning | Schemalagd inspelning med start- och stopptid. |
| Auto Duck | automatisk duckning | Effekt som sänker nivån i spår automatiskt utifrån ett kontrollspår. |
| Make-up Gain | kompensationsförstärkning | Förstärkning som kompenserar för nivåminskning vid dynamikbearbetning. |
| Equalization | equalizer | Effekt för frekvensberoende nivåjustering. |
| Noise Floor | brusgolv | Lägsta brusnivå i dynamik- och förvrängningseffekter. |
| Loudness | ljudstyrka | Upplevd ljudstyrka, exempelvis mätt med LUFS. |
| Noise Profile | brusprofil | Analys av brus som används som underlag för brusreducering. |
| Reverb | efterklang | Effekt som simulerar rummets akustiska återklang. |
| Wet/Dry | effekt/torrsignal | Förhållandet mellan bearbetad och obearbetad signal. |
