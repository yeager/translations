# Audacity: svensk terminologi

| Engelska | Svenska | Kontext |
| --- | --- | --- |
| Speed Limit | hastighetsgräns | Värdegräns i tidsstyrningsspårets hastighetsdialog. |
| Lower/Upper Speed Limit | nedre/övre hastighetsgräns | Fältnamn i samma dialog. |
| Legacy | äldre | Äldre, fortfarande tillgänglig effekt eller menygrupp. |
| Limiter | begränsare | Ljudeffekt som begränsar signalnivån. |
| Compressor | kompressor | Ljudeffekt som komprimerar dynamiskt omfång. |
| Actual compression | faktisk komprimering | Den uppmätta komprimeringen i dynamikbearbetarens graf, till skillnad från ett målvärde eller aktuell inställning. |
| Latency | fördröjning | Tidsfördröjning för inspelning eller uppspelning. |
| Audio Unit | Audio Unit | Apples protokollnamn; översätts inte. |
| Audio Unit Effects | Audio Unit-effekter | Effekter via Apples Audio Unit-protokoll. |
| Property list | egenskapslista | Serialiserat Apple-format för inställningar. |
| Plugin | insticksmodul | Audacitys tillägg för effekter, ljud och funktioner. |
| Timer Recording | timerinspelning | Schemalagd inspelning med start- och stopptid. |
| Auto Duck | automatisk duckning | Effekt som sänker nivån i spår automatiskt utifrån ett kontrollspår. |
| Make-up Gain | kompensationsförstärkning | Förstärkning som kompenserar för nivåminskning vid dynamikbearbetning. |
| Noise Gate | brusgrind | Effekt som dämpar signaler under en vald tröskel. |
| Gate threshold | grindtröskel | Signalnivå där brusgrinden öppnar eller stänger. |
| Equalization | equalizer | Effekt för frekvensberoende nivåjustering. |
| Noise Floor | brusgolv | Lägsta brusnivå i dynamik- och förvrängningseffekter. |
| Loudness | ljudstyrka | Upplevd ljudstyrka, exempelvis mätt med LUFS. |
| Noise Profile | brusprofil | Analys av brus som används som underlag för brusreducering. |
| Reverb | efterklang | Effekt som simulerar rummets akustiska återklang. |
| Wet/Dry | effekt/torrsignal | Förhållandet mellan bearbetad och obearbetad signal. |
| Buffer | buffert | Grupp av samplar som skickas till en effekt vid en iteration. |
| Latency Compensation | fördröjningskompensation | Kompenserar för fördröjning som en insticksmodul introducerar. |
| High-pass | högpass | Filter som släpper igenom högre frekvenser. |
| Spectral effect | spektral effekt | Effekt som tillämpas på ett valt frekvensintervall i spektrogramvyn. |
| Spectral selection | spektral markering | Markering av ett frekvensintervall i spektrogramvyn. |
| Sample | samplar | Digitala mätvärden i en ljudström; används i bland annat buffertbeskrivningar. |
| Sample rate | samplingsfrekvens | Antal samplar per sekund i ett ljudspår, angivet i hertz. |
| Sub-view | undervy | Delvy i ett vågspår som kan visas, ordnas om och stängas. |
| Raw data | rådata | Obearbetade ljuddata vid import. |
| Resample | sampla om | Ändrar samplingsfrekvensen för ljudet. |
| Byte order | byteordning | Ordningen för byte i råa ljuddata. |
| Render | återge | Sammanräkna ett eller flera ljudspår till ett nytt, spelbart ljudresultat. |
| Realtime effect | realtidseffekt | Effekt som bearbetar ljud under uppspelning eller redigering. |
| Amplitude envelope | amplitudkurva | Kurva som styr ett spårs nivå över tid. |
| Silent monitoring | tyst medlyssning | Medlyssning utan att signalen hörs i programmets utgång. |
| Clip | klipp | Avgränsat ljudavsnitt i ett spår. |
| Loop | loop | Markerad del som upprepas vid uppspelning. |
| Input monitoring | medlyssning av insignalen | Lyssning på inkommande ljud under inspelning. |
| PCM | PCM | Formatnamn som behålls, med bitdjup och samplingsintervall på svenska. |
| MIDI Synth Latency | MIDI-syntens fördröjning | Fördröjning för MIDI-ljudgenerering, angiven i millisekunder. |
| Key binding | tangentbindning | Koppling mellan ett kommando och en tangent eller tangentkombination. |
| Crossfade | övertoning | Gradvis övergång mellan två ljudavsnitt. |
| Scrubbing | skrubbning | Variabel uppspelning som hjälper användaren att hitta ett ljud med hörseln. |
| Scrub | skrubba | Åtgärden att spela upp ljud variabelt vid avsökning. |
| Zero padding | nollutfyllnad | Utfyllnad med nollor före FFT-analys. |
| Frequency gain | frekvensförstärkning | Förstärkning per frekvensområde i spektrogrammet. |
| Peak frequency | toppfrekvens | Nästa högre eller lägre lokala frekvenstopp i spektrogramvyn. |
| Playhead | uppspelningshuvud | Markör som visar aktuell uppspelnings- eller inspelningsposition. |
| Time signature | taktart | Musikaliskt mått med täljare och nämnare. |
| Snap | fästning | Fäster markör eller markering till närliggande tids- eller ljudpunkt. |
| Clip pitch | klipptonhöjd | Tonhöjd som gäller för ett enskilt klipp. |
| Clip speed | klipphastighet | Uppspelningshastighet som gäller för ett enskilt klipp. |
| Wah Frequency Offset | wahwah-frekvensförskjutning | Frekvensförskjutning i wahwah-effekten. |
| Grabber | draghandtag | Greppyta för att flytta ett verktygsfält eller spår. |
| Undo level | ångranivå | En sparad punkt i ångrahistoriken som kan tas bort för att frigöra diskutrymme. |
| Alias file | aliasfil | Extern ljudfil som ett Audacity-projekt refererar till. |
| Alias summary file | aliassammanfattningsfil | `.auf`-fil som sammanfattar en aliasfil för vågformsvisning. |
| Block file | blockfil | Intern projektfil som lagrar ljud- eller sammanfattningsdata. |
| Orphan block file | föräldralös blockfil | Oanvänd blockfil som kan höra till ett annat projekt. |
