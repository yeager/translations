# ReactOS CACLS, svensk terminologi

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| access control list | åtkomstkontrollista | Förkortningen ACL behålls |
| access rights | åtkomsträttigheter | CACLS-hjälptext |
| container/object inherit | behållar-/objektärvning | Förklaring av CI/OI |
| access denied | nekad åtkomst | Feltext |
| GENERIC_READ m.fl. | oförändrat | API-/Windows-konstanter, översätts inte |

## Ping

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| host | värd | Kommandorads- och feltext |
| echo request/reply | ekobegäran/ekosvar | ICMP-termer |
| timeout | tidsgräns | Tidsgräns i millisekunder |
| round-trip time | tur- och returtid | Pingstatistik |
| Time To Live (TTL) | livstid (TTL) | TTL behålls som standardförkortning |
| Don't Fragment | Don't Fragment | Paketflaggans etablerade namn behålls |
