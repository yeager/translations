# Weblate Documentation – svensk granskningsbatch 126

Datum: 2026-11-16
Komponent: Documentation (`weblate/documentation`, svenska)

## Sparad och återläst grupp

Tjugo inaktuella svenska dokumentationsöversättningar har ersatts efter
radgranskning mot den engelska källan. Gruppen omfattar arkivåtgärder,
webbkrokar för Forgejo, löpande uppdateringar, serverfel via e-post,
privata webbkrokar och VCS samt autentisering med Microsoft Entra ID.

UI-etiketter, reST- och HTTP-roller, inställningsnycklar, URL:er och
produktnamn är bevarade: `:guilabel:`, `:http:post:`, `:setting:`, `:ref:`,
Forgejo, Weblate, VCS, Microsoft Entra ID, `CACHE_DIR`, `VERSION_DISPLAY`,
`WEBHOOK_RESTRICT_PRIVATE`, `WEBHOOK_PRIVATE_ALLOWLIST` och
`VCS_RESTRICT_PRIVATE`.

Hosted Weblate accepterade 20 av 20 PATCH-anrop med HTTP 200. Direkt
API-återläsning bekräftar svensk måltext och status 20 för samtliga enheter.
Statusen betyder översatt och väntar på granskning, inte upstream-godkänd
eller mergad. `svlang skrivregler` har inga fynd; Hunspell-SV-träffar ska
bedömas mot reST-syntax, UI-namn, produktnamn och tekniska identifierare.
`msgfmt` och `l10n-lint` kan inte köras filspecifikt utan en lokal
PO-deltafil.
