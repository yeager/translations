# Weblate Documentation – svensk granskningsbatch 125

Datum: 2026-11-16
Komponent: Documentation (`weblate/documentation`, svenska)

## Sparad och återläst grupp

Tjugo inaktuella svenska dokumentationsöversättningar har ersatts efter
radgranskning mot den engelska källan. Gruppen omfattar formatstöd,
strängtillstånd, versionsvisning, VCS-URL-begränsningar samt åtgärderna
Commit och Push för lokala arkiv.

reST- och HTTP-roller, URI:er, UI-namn, filtervärden och tekniska namn är
bevarade: `:ref:`, `:http:get:`, `:guilabel:`, ``show``, ``https``, ``ssh``,
API, VCS, Commit och Push. Pluralformernas informationsmarkering är också
oförändrad.

Hosted Weblate accepterade 20 av 20 PATCH-anrop med HTTP 200. Direkt
API-återläsning bekräftar svensk måltext och status 20 för samtliga enheter.
Statusen betyder översatt och väntar på granskning, inte upstream-godkänd
eller mergad. `svlang skrivregler` har inga fynd; Hunspell-SV-träffar ska
bedömas mot reST-syntax, URI:er, UI-namn och tekniska identifierare. `msgfmt`
och `l10n-lint` kan inte köras filspecifikt utan en lokal PO-deltafil.
