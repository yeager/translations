# Weblate Documentation – svensk granskningsbatch 135

Datum: 2026-11-16
Komponent: Documentation (`weblate/documentation`, svenska)

## Sparad och återläst grupp

Tjugo inaktuella svenska dokumentationsöversättningar har ersatts efter
radgranskning mot den engelska källan. Gruppen omfattar JavaScript- och
CSS-formattering, Docker-avbildningar, typangivelser, lokal testning,
versionshantering, Markdown/MDX, SBOM, integritet, konton och
granskningslogg.

reST-roller, kommandon, kodvärden, produktnamn, standards och
inställningsnycklar är bevarade: `:program:`, `:pep:`, `:ref:`, `:setting:`,
Biome, Django, mypy, pytest, Docker, GitHub, SBOM, CycloneDX, GDPR, DPDPA,
PIPL, `yarn install --check-files`, `AUDITLOG_EXPIRY` och ``0``.

Hosted Weblate accepterade 20 av 20 PATCH-anrop med HTTP 200. Direkt
API-återläsning bekräftar svensk måltext och status 20 för samtliga enheter.
Statusen betyder översatt och väntar på granskning, inte upstream-godkänd
eller mergad. `svlang skrivregler` har inga fynd. Hunspell-SV körs med låg
prioritet och CPU-gräns. `msgfmt` och `l10n-lint` kan inte köras filspecifikt
utan en lokal PO-deltafil.
