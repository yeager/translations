# Weblate Documentation – svensk granskningsbatch 122

Datum: 2026-11-16
Komponent: Documentation (`weblate/documentation`, svenska)

## Sparad och återläst grupp

Tjugo inaktuella svenska dokumentationsöversättningar har ersatts efter
radgranskning mot den engelska källan. Gruppen omfattar XLIFF med Apple-
tillägg, pseudolokaliseringskomponenten, BBCode samt kvalitetskontroller för
Fluent, AngularJS, C, C#, Java, JavaScript, Laravel och ICU MessageFormat.

Alla reST-referenser och den automatiskt genererade markeringen är bevarade.
Det gäller bland annat `:ref:`, kommandot `./manage.py list_addons`,
`weblate.generate.pseudolocale`, XLIFF, BBCode, Fluent, ICU, JavaScript och
Apple. De samordnade kontrollsträngarna använder konsekvent
”Aktiverar kvalitetskontrollen”.

Hosted Weblate accepterade 20 av 20 PATCH-anrop med HTTP 200. Direkt
API-återläsning bekräftar svensk måltext och status 20 för samtliga enheter.
Statusen betyder översatt och väntar på granskning, inte upstream-godkänd
eller mergad. `svlang skrivregler` har inga fynd; Hunspell-SV-träffar ska
bedömas mot kodformatering, reST-syntax, produktnamn och identifierare.
`msgfmt` och `l10n-lint` kan inte köras filspecifikt utan en lokal
PO-deltafil.
