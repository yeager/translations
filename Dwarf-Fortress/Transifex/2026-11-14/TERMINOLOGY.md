# Dwarf Fortress Steam, svensk terminologi

| Engelska | Svenska | Sammanhang och anmärkning |
|---|---|---|
| `Stockpile` | förråd | Lagerplats för material och föremål. |
| `Track Stop` | spårstopp | Gruvjärnväg; använd inte den allmänna termen hållplats. |
| `Minecart` | gruvvagn | Fordonet som kör på räls i fästningen. |
| `Track` | spår | Räls- och terrängnamn. Väderriktningar och markeringar bevaras när de används som kod. |
| `Upward Track` | uppåtgående spår | Används för räls som lutar uppåt. |
| `Squad` | trupp | Militär eller tilldelad grupp. |
| `Workshop` | verkstad | Byggnad där arbetsuppgifter utförs. |
| `Tannery` | garveri | Verkstad för garvning. |
| `Hauler` | bärare | Dvärg med arbetsuppgift att flytta föremål. |
| `Cavern dweller` | grottinvånare | Varelse- och anfallsinställningar. |
| `Charge attack` | rusningsattack | Stridsmanöver. |
| `Item` | föremål | Generisk spelterm för ett hanterbart objekt. |
| `Gear assembly` | kugghjulsuppsättning | Mekanisk kraftöverföring. |
| `Potash` | pottaska | Kemiskt material; behåll facktermen. |
| `Ashery` | askverkstad | Verkstad för aska och pottaska; används bara när källsträngen avser byggnaden. |
| `Acknowledge lack of …` | Tillstå brist på … | Samtals- eller känslohandling. |
| `State feelings of …` | Uttryck känslor av … | Samtals- eller känslohandling. |
| `Dismiss minor feeling of …` | Avfärda en svag känsla av … | Samtals- eller känslohandling. |

Källor: granskade Transifex-batcher för `hardcoded_steam`, med jämförelse mot tidigare arkiverade svenska strängar. Fragment utan syntaktiskt sammanhang får inte styras enbart av denna lista.
