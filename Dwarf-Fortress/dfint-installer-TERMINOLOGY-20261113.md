# dfint-installer: svensk terminologi

| Engelska | Svenska | Kontext |
| --- | --- | --- |
| localization files | översättningsfiler | Följer projektets befintliga svenska varningsdialog. |
| hook | Hook | Namngiven installationskomponent för `df-steam-hook-rs`; behålls som teknisk term. |
| hook data | hookdata | Metadata och kontrollsumma för Hook-komponenten. |
| dictionary | ordbok | Installerarens lista över valbara språk och dess datafil. |
| executable | körbar fil | Fil som identifierar Dwarf Fortress-installationen. |
| update | uppdatering | UI-status och installationsåtgärd. |
