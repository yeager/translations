# Home Assistant Core – API-sammansättningar i hjälptester

Granskad: 2026-11-21  
Omfattning: 13 aktuella strängar där den svenska texten innehöll den osammansatta formen `API nyckel` eller `API token`.

Samtliga ändrades till `API-nyckel` respektive `API-token`, med övrig text,
platshållare, YAML- och produktnamn bevarade. Varje sträng kontrollerades
slutligen mot Lokalises live-nyckel, engelska källa, svenska översättnings-ID
och sparad måltext.
