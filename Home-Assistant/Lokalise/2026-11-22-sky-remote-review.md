# Home Assistant Core – Sky Remote

Datum: 2026-11-22

Samtliga sex Sky Remote-strängar är granskade rad för rad mot aktuell
källtext och återlästa via Lokalise API. Ingen ändring behövdes.

| Nyckel | Svenska |
| --- | --- |
| `component::sky_remote::config::abort::already_configured` | Enheten är redan konfigurerad |
| `component::sky_remote::config::error::cannot_connect` | Det gick inte att ansluta |
| `component::sky_remote::config::step::user::data::host` | Värd |
| `component::sky_remote::config::step::user::data_description::host` | Värdnamn eller IP-adress för din Sky-enhet |
| `component::sky_remote::config::step::user::title` | Lägg till Sky Remote |
| `component::sky_remote::exceptions::invalid_command::message` | Ogiltigt kommando: {command} |

Platshållaren `{command}` är bevarad; inga pluralformer eller referenser
förekommer. Hunspell/svlang-träffarna gäller produktnamnet respektive
platshållaren. Lokalise API:s verifieringsflagga är inte skrivbar med aktuell
behörighet; granskningen är spårad här.
