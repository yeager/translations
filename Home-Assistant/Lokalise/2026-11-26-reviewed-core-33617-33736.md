## Kontexthänvisningar

- Home Connects officiella API beskriver `KeepMilkTankCool` som en instruktion att ta ut mjölkbehållaren och ställa den svalt. `IDos1FillLevelPoor` och `IDos2FillLevelPoor` betyder att innehållet har låg nivå. Fettfiltersensorerna betyder att filtren snart behöver rengöras respektive är mättade och behöver rengöras. Rengöringsrobotens `EmptyDustBoxAndCleanFilter` är en konkret åtgärd. [Home Connect API – Events](https://api-docs.home-connect.com/events/)
- Samma API anger att `Present` betyder att händelsen har inträffat och fortfarande föreligger, `Off` att händelsen är av och `Confirmed` att användaren har bekräftat händelsen. Dessa tillståndsöversättningar ärvdes från live-målen, inte råöversatta på aliasnivå. [Home Connect API – Event Present State](https://api-docs.home-connect.com/events/#event-present-state-enumeration)
- Habitica-fälten använder de delade, tidigare granskade måltexterna. Källreferenserna och svenska värdena verifierades mot Lokalise; inga aliasöversättningar ändrades.
