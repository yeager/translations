# Sparade ändringar: Xiaomi Aqara

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::xiaomi_aqara::config::step::select::description`: tillagd nödvändig preposition för anslutning till gatewayen.
- `component::xiaomi_aqara::config::step::settings::description`: återställd skiljetecken mellan handledningslänken och nästa mening.
