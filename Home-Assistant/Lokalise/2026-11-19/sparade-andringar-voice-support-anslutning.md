# Home Assistant Core: Voice Support anslutningsfel

Kontrollerat mot aktuell Lokalise-källa och sparat/återläst via API 2026-11-19. Ett förslag från den [tidigare granskningsrapporten](../2026-11-19-granskning/granskning-1501-1740.md) matchade fortfarande den äldre svenska texten och rättades. De övriga tolv förslagen i rapporten skrevs inte över eftersom den aktuella svenska texten eller källtexten inte längre matchade underlaget.

## `component::voice_support::exceptions::cannot_connect::message`

**Engelska:** Cannot connect to the Voice Support app at {url}.

**Tidigare svenska:** Det går inte att ansluta till Voice-appen på { url }.

**Sparad svenska:** Det går inte att ansluta till Voice Support-appen på {url}.
