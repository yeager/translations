# Sparade ändringar: Home Assistant Cloud-status

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::cloud::system_health::info::remote_connected`: korrekt svensk status för en upprättad fjärranslutning.
- `component::cloud::system_health::info::subscription_expiration`: tydlig formulering för prenumerationens utgång.
