# Sparade ändringar: BMW, Motionblinds och AirNow

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::bmw_connected_drive::config::step::user::data::region`: korrekt svensk sammansättning.
- `component::motion_blinds::config::step::connect::description`: tydligare krav på API-nyckel och korrekt meningsindelning.
- `component::motion_blinds::config::step::select::title`: kompletterad styrning med ”ansluta till”.
- `component::airnow::config::error::invalid_location`: idiomatisk feltext med tydlig åtgärd.
