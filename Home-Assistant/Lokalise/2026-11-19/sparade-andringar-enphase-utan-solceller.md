# Home Assistant Core: Enphase Envoy utan solcellsväxelriktare

Sparat och separat återläst via Lokalises API 2026-11-19. Svenska fält var tomma och engelska källtexter stämde med [tidigare granskningsförslag](../2026-11-19-granskning/forslag-0121-0180.md). De fyra referensernas två mål sparades och kontrollerades först. Referenserna förs inte in som vanliga TMX-segment.

## `component::enphase_envoy::config::step::user::data_description::no_solar_mode`

**Engelska:** Enable this option if your Envoy has no solar inverters to avoid production data time-outs during integration load. Do not enable it if you have Enphase AC Batteries (ACB), as it disables collection of their power data.

**Tidigare svenska:** (tom)

**Sparad svenska:** Aktivera det här alternativet om din Envoy saknar solcellsväxelriktare, så att tidsgränsen för produktionsdata inte överskrids när integrationen läses in. Aktivera det inte om du har Enphase AC Batteries (ACB), eftersom insamlingen av deras effektdata då inaktiveras.
