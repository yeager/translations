# Sparade ändringar: OmniLogic och Nightscout

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- OmniLogic: korrekt sammansättning i ”pollningsintervall”.
- Nightscout: korrekt versalisering av produktnamnet med bevarad flerradsformatering och koduttryck.
