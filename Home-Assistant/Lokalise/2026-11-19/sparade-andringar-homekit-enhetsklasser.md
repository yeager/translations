# Sparade ändringar: HomeKit

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::homekit::config::step::user::description`: konsekvent benämning av TV/RECEIVER-enhetsklassen.
- `component::homekit::options::step::advanced::description`: utlösare ”aktiveras” i stället för den tautologiska formuleringen ”utlöses”.
