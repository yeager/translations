# Sparade ändringar: Withings och MQTT

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::withings::config::abort::already_configured`: komplett statusmening.
- `component::mqtt::options::step::options::data::birth_payload`: korrekt MQTT-term, ”uppstartsmeddelande”, i stället för den bokstavliga och felaktiga ”födelsemeddelande”.
