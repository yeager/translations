# Sparade ändringar: WIFFI och OwnTone

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::wiffi::config::abort::addr_in_use`: återställt ”redan” från källtexten.
- `component::forked_daapd::config::error::websocket_not_enabled`: korrekt sats och skrivning av WebSocket.
