# Sparade ändringar: ISY och Flick

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- ISY: korrekt preposition för TLS-version, värdadress i URL-instruktion och sammansättning i ISY-alternativ.
- Flick: korrekt sammansatt rubrik för autentiseringsuppgifter.
