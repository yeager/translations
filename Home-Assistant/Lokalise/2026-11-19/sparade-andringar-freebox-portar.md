# Freebox: porthastigheter

Sparade och återlästa i Lokalise den 19 november 2026 efter kontroll mot [den äldre förslagsrapporten](../2026-11-19-granskning/forslag-0241-0330.md). Svenska måltexter var tomma före sparningen.

| Fullständig nyckel | Engelska | Sparad svenska |
|---|---|---|
| `component::freebox::entity::sensor::port_tx_rate_unnamed::name` | Port {port} transmit rate | Sändningshastighet för port {port} |
| `component::freebox::entity::sensor::port_tx_rate::name` | {port} transmit rate | Sändningshastighet för {port} |
| `component::freebox::entity::sensor::port_rx_rate_unnamed::name` | Port {port} receive rate | Mottagningshastighet för port {port} |
| `component::freebox::entity::sensor::port_rx_rate::name` | {port} receive rate | Mottagningshastighet för {port} |
| `component::freebox::entity::sensor::port_link_speed_unnamed::name` | Port {port} link speed | Länkhastighet för port {port} |
| `component::freebox::entity::sensor::port_link_speed::name` | {port} link speed | Länkhastighet för {port} |

Platshållaren `{port}` bevaras i samtliga sex texter. Skillnaden mellan namngiven och numrerad port följer källan.
