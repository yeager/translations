# Sparade ändringar: OWServer och RainMachine

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::onewire::config::step::user::title`: tydlig formulering för instansens uppgifter.
- `component::rainmachine::options::step::init::data::zone_run_time`: idiomatisk benämning på en zons standardkörtid.
