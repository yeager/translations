# Rättad NWS-platsbeskrivning

Sparad och återläst i Home Assistant Core i Lokalise 2026-11-19. Den tidigare texten hänvisade till latitud och longitud, medan källan anger den valda platsen. Vid redigeringen sparades först en oavsiktligt sammanfogad text; den ersattes omedelbart och slutversionen återlästes.

**Nyckel:** `component::nws::config::step::location::description`

**Engelska:** If a METAR station code is not specified, the specified location will be used to find the closest station. For now, the API key can be anything. It is recommended to use a valid email address.

**Tidigare svenska:** Om en METAR-stationskod inte anges, kommer latitud och longitud att användas för att hitta den närmaste stationen. För närvarande kan API-nyckeln vara vad som helst. Det rekommenderas att använda en giltig e-postadress.

**Sparad svenska:** Om ingen METAR-stationskod anges används den angivna platsen för att hitta närmaste station. För närvarande kan API-nyckeln vara vad som helst. En giltig e-postadress rekommenderas.
