# Sparade ändringar: ZHA och Smappee

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- ZHA: komplett offline-status för enheten.
- Smappee: korrekt värdadress, återställd kodformatering för serienumret samt rätt enhetsantal i rubriken.
