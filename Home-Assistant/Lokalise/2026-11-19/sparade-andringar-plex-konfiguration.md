# Sparade ändringar: Plex

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::plex::config::error::host_or_token`: komplett svensk felmening.
- `component::plex::config::step::user::description`: återställd fullständig vägledning för båda Plex-konfigurationssätten.
