# Sparade ändringar: WOLF-lägen

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- WOLF: *setback* översatt korrekt till sänkningsläge, inklusive stoppet för läget.
- WOLF: korrekt sammansättning i antilegionellafunktionen och tydlig term för automatisk påslagning.
