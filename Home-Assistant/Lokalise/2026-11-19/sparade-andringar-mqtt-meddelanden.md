# Sparade ändringar: MQTT-meddelanden

Datum: 2026-11-19

Åtta svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Alla MQTT-fält för *birth message* använder nu konsekvent ”uppstartsmeddelande”.
- Alla MQTT-fält för *will message* använder nu den funktionella termen ”frånkopplingsmeddelande”.
- Den längre MQTT-beskrivningen har återfått det saknade stycket om upptäcktsprefix och full källbetydelse.
