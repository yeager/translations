# Sparade ändringar: Shelly-utlösare och AirNow

Datum: 2026-11-19

Sju svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::airnow::config::step::user::data::radius`: förtydligar att miles avser engelska mil.
- Shellys sex automationsutlösare: ersätter adjektivformer med fullständiga händelsefraser för enkel-, dubbel- och trippelklick samt långtryckning.
