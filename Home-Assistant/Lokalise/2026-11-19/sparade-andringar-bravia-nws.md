# Sparade ändringar: Bravia TV och NWS

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::braviatv::config::error::unsupported_model`: rätt svensk sammansättning, ”tv-modellen”.
- `component::braviatv::config::step::authorize::description`: korrekt PSK-definition och konsekvent instruktionstext.
- `component::nws::config::step::user::data::station`: rätt sammansättning, ”METAR-stationskod”.
- `component::nws::config::step::user::description`: förtydligad plats för väderdata.
