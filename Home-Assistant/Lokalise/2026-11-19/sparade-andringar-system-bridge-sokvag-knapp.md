# Rättade System Bridge-beskrivningar

Sparade och återlästa i Home Assistant Core i Lokalise 2026-11-19. Värdet default bevarades.

| Nyckel | Engelska | Tidigare svenska | Sparad svenska |
| --- | --- | --- | --- |
| `component::system_bridge::services::send_message::fields::path::description` | File or folder on the computer to open when the notification is clicked. Can't be used with URL. | Fil eller mapp på datorn som öppnas när aviseringen klickas. Kan inte användas tillsammans med URL. | Fil eller mapp på datorn som öppnas när du klickar på aviseringen. Kan inte användas tillsammans med URL. |
| `component::system_bridge::selector::buttons::fields::id::description` | Reported when the button is pressed. Can't be "default", which is reported when the notification itself is clicked. | Rapporteras när knappen trycks ned. Får inte vara "default", som rapporteras när själva aviseringen klickas. | Rapporteras när knappen trycks ned. Får inte vara ”default”, som rapporteras när du klickar på själva aviseringen. |
