# Rättade Seafile-, Raspberry Pi- och ABRP-feltexter

Sparade och återlästa via Lokalise API i Home Assistant Core 2026-11-19. Terminologin har anpassats till svenska bestämdformer och ”inbyggd programvara”.

| Nyckel | Engelska | Tidigare svenska | Sparad svenska |
| --- | --- | --- | --- |
| `component::seafile::exceptions::invalid_auth::message` | The access token of the Seafile account is no longer valid. | Åtkomsttoken för Seafile-kontot är inte längre giltig. | Åtkomsttokenen för Seafile-kontot är inte längre giltig. |
| `component::raspberry_pi::exceptions::firmware_info_error::message` | An error occurred while fetching the Raspberry Pi firmware info | Ett fel inträffade när firmwareinformationen för Raspberry Pi hämtades | Ett fel inträffade när information om den inbyggda programvaran för Raspberry Pi hämtades |
| `component::abrp::exceptions::oauth2_token_refresh_failed::message` | Failed to refresh the OAuth2 access token. | Det gick inte att förnya OAuth2-åtkomsttoken. | Det gick inte att förnya OAuth2-åtkomsttokenen. |
