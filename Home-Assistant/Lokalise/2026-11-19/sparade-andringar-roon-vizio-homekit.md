# Sparade ändringar: Roon, VIZIO och HomeKit

Datum: 2026-11-19

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Roon: korrekt instruktion för fliken **Tillägg**.
- VIZIO: korrekt sammansättning i SmartCast-konfigurationspost.
- HomeKit Controller: korrekt instruktion att avsluta parkoppling och sedan försöka igen.
