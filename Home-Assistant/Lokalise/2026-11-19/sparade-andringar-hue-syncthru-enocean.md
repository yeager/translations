# Sparade ändringar: Hue, SyncThru och EnOcean

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Hue: idiomatisk term ”oåtkomliga” för otillgängliga lampor.
- SyncThru: korrekt URL-konstruktion och komplett kontrollinstruktion.
- EnOcean: rätt svensk form i instruktionen om dongelsökvägen.
