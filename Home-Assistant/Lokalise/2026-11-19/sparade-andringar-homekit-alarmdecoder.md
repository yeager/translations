# Sparade ändringar: HomeKit Controller och AlarmDecoder

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- HomeKit Controller: konsekventa utlösarfraser i preteritum för enkel-, dubbel- och långtryckning.
- AlarmDecoder: återställd lyckad anslutning i statusmeddelandet.
