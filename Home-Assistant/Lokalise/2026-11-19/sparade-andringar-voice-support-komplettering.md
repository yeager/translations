# Kompletterade Voice Support-texter

Sparade och återlästa i Home Assistant Core i Lokalise 2026-11-19. De tidigare svenska texterna saknade information eller speglade en äldre källtext.

## `component::voice_support::preview_features::next_generation_voice::enable_confirmation`

**Engelska:**

This feature is still in development and may change. On Home Assistant OS, Home Assistant installs the Voice Support app for you.

**Tidigare svenska:**

Funktionen är fortfarande under utveckling och kan ändras. På ett system med Home Assistant OS eller Supervised installeras Voice-appen när funktionen aktiveras.

**Sparad svenska:**

Funktionen är fortfarande under utveckling och kan ändras. På Home Assistant OS installerar Home Assistant Voice Support-appen åt dig.

## `component::voice_support::preview_features::next_generation_voice::description`

**Engelska:**

Enables the next generation voice stack in Home Assistant.

It needs the Voice Support app. On Home Assistant OS, the app is installed for you. If you run Home Assistant in a container, select **Learn more** to see how to install the app.

Your Home Assistant Voice Preview Edition needs the beta firmware.

**Tidigare svenska:**

Aktiverar nästa generations röstsystem i Home Assistant. På system med Home Assistant OS eller Supervised installeras appen när funktionen aktiveras.

**Sparad svenska:**

Aktiverar nästa generations röstsystem i Home Assistant.

Voice Support-appen krävs. På Home Assistant OS installeras appen åt dig. Om du kör Home Assistant i en container väljer du **Läs mer** för att se hur du installerar appen.

Din Home Assistant Voice Preview Edition behöver betaversionen av den inbyggda programvaran.

## `component::voice_support::config::progress::start_app`

**Engelska:**

Please wait while the Voice Support app starts. This may take some seconds.

**Tidigare svenska:**

Startar Voice-appen

**Sparad svenska:**

Vänta medan Voice Support-appen startar. Det kan ta några sekunder.
