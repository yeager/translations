# Sparade ändringar: HomeKit Controller och Sentry

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- HomeKit Controller: återställd korrekt uppmaning att försöka parkoppla igen efter omstart.
- Sentry: korrekt svensk satsstruktur för loggnivåerna och etablerad term ”brödsmulor” för breadcrumbs.
