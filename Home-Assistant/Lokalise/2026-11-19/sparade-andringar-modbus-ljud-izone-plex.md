# Rättade Modbus-, ljud-, iZone- och Plex-texter

Sparade och återlästa via Lokalise API i Home Assistant Core 2026-11-19. Platshållarna `{name}` och `{value}` bevarades.

| Nyckel | Engelska | Tidigare svenska | Sparad svenska |
| --- | --- | --- | --- |
| `component::modbus::common::tcp_port_description` | The Modbus TCP port to connect to. | Den Modbus TCP-port att ansluta till. | Modbus TCP-porten som anslutningen ska använda. |
| `component::system_bridge::entity::switch::audio_input_mute::name` | {name} input mute | Stäng av ljudingång för {name} | Stäng av ljudet för ingången {name} |
| `component::izone::exceptions::invalid_airflow_step::message` | Airflow {value}% is not a multiple of 5% | Luftflödet {value}% är inte en multipel av 5 % | Luftflödet {value} % är inte en multipel av 5 % |
| `component::plex::config::step::reconfigure::description` | Change the address used to connect to your Plex server. The existing token is kept. | Ändra adressen som används för att ansluta till din Plex-server. Den befintliga åtkomsttoken behålls. | Ändra adressen som används för att ansluta till din Plex-server. Den befintliga åtkomsttokenen behålls. |
