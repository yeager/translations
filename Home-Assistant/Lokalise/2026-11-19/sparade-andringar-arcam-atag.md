# Sparade ändringar: Arcam och Atag

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::arcam_fmj::device_automation::trigger_type::turn_on`: korrekt betydelse för en begärd påslagning.
- `component::atag::config::error::unauthorized`: grammatisk, tydlig instruktion vid nekad parkoppling.
