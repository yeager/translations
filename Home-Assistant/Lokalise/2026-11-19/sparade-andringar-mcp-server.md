# Sparad ändring för MCP Server

Sparad och återläst i Lokalise 2026-11-19. Den aktuella källtexten jämfördes med den tidigare granskningsrapporten.

| Fullständig nyckel | Engelska | Tidigare svenska | Sparad svenska |
|---|---|---|---|
| `component::mcp_server::options::step::init::data_description::require_admin` | Only allow administrator accounts to use the main URL. Some tools always require an administrator account. | Tillåt endast administratörskonton att använda Model Context Protocol-slutpunkten. | Tillåt endast administratörskonton att använda huvud-URL:en. Vissa verktyg kräver alltid ett administratörskonto. |

Den tidigare översättningen saknade källans andra mening och angav en mer specifik slutpunkt än den aktuella källtexten.
