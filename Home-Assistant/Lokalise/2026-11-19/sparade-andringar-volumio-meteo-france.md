# Sparade ändringar: Volumio och Meteo-France

Datum: 2026-11-19

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Volumio: komplett anslutningsfel för den upptäckta instansen.
- Meteo-France: idiomatiska svenska fel- och söktexter för stadsvalet.
