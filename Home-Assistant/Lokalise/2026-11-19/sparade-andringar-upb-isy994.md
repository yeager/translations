# Sparade ändringar: UPB och ISY994

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::upb::config::error::invalid_upb_file`: komplett, tydlig felmening om saknad eller ogiltig exportfil.
- `component::isy994::config::error::invalid_host`: korrekt term för värdadressen i URL-felet.
