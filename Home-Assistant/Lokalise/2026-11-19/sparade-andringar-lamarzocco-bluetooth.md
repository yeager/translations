# Kompletterad La Marzocco-instruktion

Sparad och återläst i Home Assistant Core i Lokalise 2026-11-19. Tidigare svenska var avbruten efter ”Ditt La Marzocco-konto saknar en Bluetooth-token för {name}, så Home Assist”. Platshållare och styckesindelning bevarades.

**Nyckel:** `component::lamarzocco::issues::missing_bluetooth_token::fix_flow::step::confirm::description`

**Engelska:**

Your La Marzocco account has no Bluetooth token for "{name}", so Home Assistant can't connect to it over Bluetooth.

To fix this, remove the machine in the La Marzocco app, add it again, and then reload the integration.

If you don't want to use Bluetooth, select **Submit** to turn off Bluetooth and offline mode for this machine.

**Sparad svenska:**

Ditt La Marzocco-konto saknar en Bluetooth-token för ”{name}”, så Home Assistant kan inte ansluta till den via Bluetooth.

Ta bort maskinen i La Marzocco-appen, lägg till den igen och läs sedan in integrationen på nytt.

Om du inte vill använda Bluetooth väljer du **Skicka** för att stänga av Bluetooth och offlineläget för den här maskinen.
