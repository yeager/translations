# Sparade ändringar: SolarEdge-feltexter

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::solaredge::config::error::could_not_connect`: korrekt bestämd form för SolarEdge API:t.
- `component::solaredge::config::error::site_not_active`: återställer uppgiften om den angivna API-nyckeln.
