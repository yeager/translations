# Sparade ändringar: Kodi och Shelly

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Kodi: korrekt possessivform i anslutningsinstruktionen.
- Shelly: tydlig instruktion för batteridrivna enheter med korrekt meningsindelning och väckning via enhetsknappen.
