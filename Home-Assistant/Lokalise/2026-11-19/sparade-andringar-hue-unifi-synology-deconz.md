# Sparade ändringar: Hue, UniFi, Synology och deCONZ

Datum: 2026-11-19

Fem svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Två Hue-utlösare: korrekt svensk sats för att båda knapparna släppts.
- UniFi: rätt betydelse för logiken som kringgår felet för trådbundna anslutningar.
- Synology DSM: idiomatisk formulering när data saknas.
- deCONZ: tillagd artikel i valet av upptäckt gateway.
