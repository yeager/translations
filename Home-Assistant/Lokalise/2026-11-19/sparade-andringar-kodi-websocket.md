# Sparade ändringar: Kodi

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::kodi::config::step::discovery_confirm::title`: rätt ordklass i upptäcktsrubriken.
- `component::kodi::config::step::ws_port::description`: komplett instruktion om att lämna portfältet tomt.
