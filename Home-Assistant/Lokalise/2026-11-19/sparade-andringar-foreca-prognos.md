# Rättad Foreca-beskrivning

Sparad och återläst i Home Assistant Core i Lokalise 2026-11-19. ”Plan” avser abonnemanget; tjänsten `weather.get_forecasts` bevarades.

**Nyckel:** `component::foreca::services::get_3_hour_forecast::description`

**Engelska:** Retrieves the forecast in 3-hour steps for the next 14 days, in the weather entity's units, with the values weather.get_forecasts has no place for. Every call makes a request to the Foreca Weather API and counts toward the daily limit of your plan.

**Tidigare svenska:** Hämtar prognosen i 3-timmarssteg för de kommande 14 dagarna, i väderentitetens enheter, med de värden som weather.get_forecasts saknar plats för. Varje anrop gör en förfrågan till Foreca Weather API och räknas mot din plans dagliga gräns.
