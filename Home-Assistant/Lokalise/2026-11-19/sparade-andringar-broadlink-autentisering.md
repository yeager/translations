# Sparade ändringar: Broadlink

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::broadlink::config::step::reset::description`: återställd exakt menytext ``...`` och korrekt numrerad Markdown-lista.
