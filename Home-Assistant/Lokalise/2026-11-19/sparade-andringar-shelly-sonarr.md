# Sparade ändringar: Shelly och Sonarr

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Shelly: återställd den helt saknade instruktionen om att välja enhet eller ange adress, samt korrekt batteriinstruktion.
- Sonarr: korrekt svensk API-böjning och omautentiseringstext.
