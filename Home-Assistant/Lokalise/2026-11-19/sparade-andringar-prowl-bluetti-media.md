# Rättade Prowl-, Bluetti- och mediespelartexter

Sparade och återlästa via Lokalise API i Home Assistant Core 2026-11-19. Platshållaren `{error}` bevarades.

| Nyckel | Engelska | Tidigare svenska | Sparad svenska |
| --- | --- | --- | --- |
| `component::template::config::step::media_player::title` | Template media player | Mall för mediaspelare | Mallbaserad mediespelare |
| `component::bluetti_modbus::config::step::reconfigure::description` | Update the address Home Assistant reaches this power station at. | Uppdatera den adress som Home Assistant använder för att nå detta kraftverk. | Uppdatera adressen som Home Assistant använder för att nå kraftstationen. |
| `component::prowl::exceptions::api_error::message` | Unexpected error when calling the Prowl API: {error} | Oväntat fel vid anrop till Prowl API: {error} | Oväntat fel vid anrop till Prowl-API:t: {error} |
| `component::prowl::exceptions::api_timeout::message` | Timeout accessing the Prowl API. | Tidsgränsen överskreds vid åtkomst till Prowl API. | Tidsgränsen överskreds vid åtkomst till Prowl-API:t. |
