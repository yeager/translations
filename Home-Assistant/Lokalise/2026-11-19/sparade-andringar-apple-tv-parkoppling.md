# Sparade ändringar: Apple TV-parkoppling

Datum: 2026-11-19

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::apple_tv::config::step::confirm::description`: borttagna oavsiktliga Markdown-indrag och tydligare svenska.
- `component::apple_tv::config::step::pair_with_pin::description`: konsekvent term för parkoppling och bibehållen kodmarkering.
- `component::apple_tv::config::step::service_problem::description`: idiomatisk formulering för protokollets parkopplingsfel.
