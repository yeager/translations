# Sparade ändringar: Luftfuktare och Control4

Datum: 2026-11-19

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Luftfuktare: komplett utlösartext för ändrad målfuktighet.
- Control4: grammatisk anslutningstext och svensk term ”styrenhet”.
