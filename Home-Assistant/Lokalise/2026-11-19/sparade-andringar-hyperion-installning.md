# Sparade ändringar: Hyperion-installning

Datum: 2026-11-19

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::hyperion::config::step::auth::data::token`: korrekt formulering för en befintlig token.
- `component::hyperion::config::step::confirm::description`: korrekt svensk preposition och fungerande Markdown utan oavsiktliga indrag.
- `component::hyperion::options::step::init::data::priority`: idiomatisk sammansättning och tydligare etikett.
