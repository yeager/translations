# Sparad svensk översättning: deCONZ

Datum: 2026-11-19

Sparad via Lokalise API och läst tillbaka efter uppdateringen.

## `component::deconz::config::step::link::description`

- Engelska: Uppdaterad väg till deCONZ Settings > Gateway > Advanced och knappen **Authenticate app**.
- Tidigare svenska: Beskrev den äldre knappen ”Lås upp gateway”.
- Sparad svenska: Återger den aktuella menykedjan och **Authenticate app**.
