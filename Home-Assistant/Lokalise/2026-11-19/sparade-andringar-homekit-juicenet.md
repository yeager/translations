# Sparade ändringar: HomeKit och JuiceNet

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::homekit::options::step::cameras::description`: korrekt uppmaning att markera kameror och tydligare krav på processorprestanda.
- `component::juicenet::config::step::user::description`: rätt term och stil för API-token.
