# Sparade ändringar: BSB-LAN och Lutron Caséta

Datum: 2026-11-19

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `component::bsblan::config::step::user::description`: korrekt aktiv infinitiv för integrering med Home Assistant.
- `component::lutron_caseta::config::step::import_failed::description`: komplett relativsats för den importerade bryggan.
