# Sparade Tuya-felmeddelanden

Sparade och återlästa i Home Assistant Core i Lokalise 2026-11-19. Svenska fält var tomma. ”Tuyas molntjänst” följer den befintliga översättningen av `component::tuya::exceptions::command_rejected::message`. Platshållaren `{code}` bevarades.

| Fullständig nyckel | Engelska | Sparad svenska |
| --- | --- | --- |
| `component::tuya::exceptions::command_sign_invalid::message` | The Tuya cloud rejected the command because the request signature is invalid. | Tuyas molntjänst avvisade kommandot eftersom begärans signatur är ogiltig. |
| `component::tuya::exceptions::command_rejected_with_reason::message` | The Tuya cloud rejected the command (error {code}). | Tuyas molntjänst avvisade kommandot (fel {code}). |
| `component::tuya::exceptions::command_rate_limited::message` | The Tuya cloud is limiting requests, try again later. | Tuyas molntjänst begränsar antalet begäranden. Försök igen senare. |
| `component::tuya::exceptions::command_not_accepted::message` | The Tuya cloud does not accept this command or value for this device (error {code}). | Tuyas molntjänst godtar inte det här kommandot eller värdet för den här enheten (fel {code}). |
