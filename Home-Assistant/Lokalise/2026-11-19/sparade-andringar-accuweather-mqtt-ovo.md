# Sparade ändringar: AccuWeather, MQTT och OVO Energy

Datum: 2026-11-19

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- AccuWeather: korrekt status för stabil trycktrend.
- MQTT: enhetliga termer för uppstarts- och frånkopplingsmeddelanden.
- OVO Energy: korrekt sammansättning i kontorubriken.
