# Sparade ändringar: Sensorvillkor och utlösare

Datum: 2026-11-19

Åtta svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Sensorvillkor för ström, energi, effektfaktor och spänning använder nu konsekvent mönstret ”Aktuell … för {entity_name}”.
- Motsvarande utlösare använder korrekt bestämd form och ordföljden ”… för {entity_name} ändras”.
