# Template Alarm Control Panel: kodidentifierare

Fjorton konfigurations- och alternativssträngar rättades via Lokalise API den
22 november 2026 och lästes tillbaka efter sparning. Mallvariabeln `code`
hade översatts till `kod` i samtliga berörda larmåtgärder, och det giltiga
formatvärdet `number` hade översatts till `nummer`. Identifierarna återställdes
utan att den svenska förklarande texten ändrades.
