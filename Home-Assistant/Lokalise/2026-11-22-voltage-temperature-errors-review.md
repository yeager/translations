# Home Assistant Core – spännings- och temperaturfel

Tretton Fronius- och Victron-felmeddelanden rättades. Gruppen innehöll
utelämnade verb i hög/låg-meddelanden och den upprepade felstavningen
`Laddartempartur`; samtliga använder nu fullständiga svenska formuleringar.
Varje post sparades och återlästes via Lokalise API och finns i den kanoniska
TMX-filen.
