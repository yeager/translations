# Husqvarna Automower: API-namn som kod

Två Husqvarna Automower-strängar rättades via Lokalise API den 22 november
2026. De tekniska namnen `Authentication API` och `Automower Connect API`
återställdes med Markdown-kodmarkering. Länken med `{application_url}` är
bevarad och båda värdena lästes tillbaka efter sparning.
