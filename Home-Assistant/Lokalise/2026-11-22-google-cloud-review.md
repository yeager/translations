# Google Cloud: fullständig komponentgranskning

Samtliga tretton svenska strängar lästes från Lokalise API och granskades rad
för rad den 22 november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar Google Cloud-servicekonto och JSON-fil, samt alternativ
för röstsyntes: ljudkodare, dB-förstärkning, röst, tonhöjd, hastighet,
ljudprofiler och tal-till-text-modell.
