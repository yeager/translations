# Core — Network

Datum: 2026-11-21

Network-komponenten granskades direkt i Lokalise. Docker-varningen för värdnätverk rättades med tydlig svensk syntax och konsekventa termer: `värdnätverksläge`, `värdnätverk`, `enhetsupptäckt` och `Home Assistant-installationsguiden`. Kodfragment och länkar bevarades. Ändringen sparades, återlästes och lades till i validerat TMX-minne.
