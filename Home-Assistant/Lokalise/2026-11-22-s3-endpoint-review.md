# Home Assistant Core – S3-slutpunkt

Tre S3-strängar använde det oöversatta `endpoint`. De har normaliserats till
`slutpunkt` respektive `slutpunkten`, i linje med den etablerade
API-terminologin. Ändringarna är sparade och återlästa via Lokalise API och
ingår i den kanoniska Home Assistant-TMX-filen.
