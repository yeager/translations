# Kodi, MQTT, Kalender och HomeWorks: teknisk kodmarkering

Fem strängar rättades via Lokalise API den 22 november 2026. Samtliga värden
lästes tillbaka efter sparning.

| Område | Återställda identifierare |
| --- | --- |
| Kodi | `songid`, `albumid`, `kodi_call_method_result` |
| MQTT | `mqtt_dump.txt` |
| Kalender | `calendar.get_events` |
| HomeWorks | `homeworks` |

Ändringarna återställer synlig Markdown-kodmarkering för värden som användaren
ska kopiera eller känna igen i konfiguration och händelser.
