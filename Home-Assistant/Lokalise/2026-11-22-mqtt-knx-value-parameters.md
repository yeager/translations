# MQTT och KNX: parametern `value`

Tre strängar rättades via Lokalise API den 22 november 2026 och lästes
tillbaka efter sparning. Mallparametern `value` hade översatts till `värde` i
MQTT och KNX. MQTT-beskrivningen förtydligades samtidigt med den etablerade
termen ”nyttolast”; de namngivna värdena ”on” och ”off” bevarades.
