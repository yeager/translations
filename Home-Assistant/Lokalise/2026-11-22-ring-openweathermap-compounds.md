# Ring- och OpenWeatherMap-integrationer

Två Core-strängar rättades via Lokalise API den 22 november 2026 och lästes
tillbaka efter sparning.

| Nyckel | Ändring |
| --- | --- |
| `component::ring::config::step::reauth_confirm::description` | `Ring integrationen behöver åter-autentisera ...` → `Ring-integrationen behöver återautentisera ...` |
| `component::openweathermap::config::step::user::data_description::api_key` | `OpenWeatherMap integrationen` → `OpenWeatherMap-integrationen` |

Platshållaren `{username}` är bevarad.
