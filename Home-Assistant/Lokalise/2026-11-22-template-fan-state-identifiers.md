# Template Fan: körbara tillståndsvärden

Konfigurations- och alternativsflödets `state`-beskrivning rättades via
Lokalise API den 22 november 2026. De körbara värdena `on`, `off`, `True`,
`yes` och `enable` hade översatts till svenska. De återställdes som kod och
båda värdena lästes tillbaka efter sparning.
