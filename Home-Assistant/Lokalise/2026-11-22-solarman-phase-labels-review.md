# Home Assistant Core – Solarman-faser

Tolv Solarman-sensorer rättades från engelskinspirerade fasetiketter, såsom
`AC Fas-A ström`, till konsekventa svenska eltermer: `AC-ström, fas A`,
`AC-spänning, fas A` och motsvarande effektetiketter för faserna A–C.
Termbanken anger `AC Power` → `AC-ström`; Hunspell och svlang användes som
ytterligare kontroll. Alla resultat sparades och återlästes via Lokalise API.
