# Home Assistant Core – TriggerCMD

Datum: 2026-11-22

Komponentens sju strängar är granskade rad för rad mot aktuell engelsk
källtext och återlästa via Lokalise API. Ingen ändring behövdes.

| Nyckel | Svenska |
| --- | --- |
| `component::triggercmd::config::abort::already_configured` | Enheten är redan konfigurerad |
| `component::triggercmd::config::error::cannot_connect` | Det gick inte att ansluta |
| `component::triggercmd::config::error::invalid_auth` | Ogiltig autentisering |
| `component::triggercmd::config::error::invalid_token` | Ogiltig token |
| `component::triggercmd::config::error::unknown` | Oväntat fel |
| `component::triggercmd::config::step::user::data::token` | Åtkomsttoken |
| `component::triggercmd::config::step::user::data_description::token` | Token från instruktionssidan för TRIGGERcmd |

Inga platshållare, pluralformer eller referenser förekommer. Hunspell/svlang
har endast den förväntade träffen för produktnamnet. Lokalise API:s
verifieringsflagga är inte skrivbar med aktuell behörighet; granskningen är
spårad här.
