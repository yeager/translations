# LG Netcast: fullständig komponentgranskning

Samtliga tretton svenska strängar lästes från Lokalise API och granskades rad
för rad den 22 november 2026. Två livevärden rättades och lästes tillbaka efter
sparning. Sammansättningen `LG Netcast TV` skrevs enligt svensk skrivregel som
`LG Netcast-TV` i rubrik och värdbeskrivning. Övriga elva strängar var
korrekta.
