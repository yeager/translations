# Home Assistant Core – Compit, temperaturinställningar

Datum: 2026-11-21

Alla 12 aktuella `number`-strängar kontrollerades mot Core `2fdaa177` och direkt återlästes. `component::compit::entity::number::mixer_target_temperature_zone::name` korrigerades från `Mixer {zone} måltemperatur` till `Måltemperatur för blandare {zone}`.
