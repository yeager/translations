# Underhåll krävs

Två statusetiketter med källtexten `Maintenance required` rättades via
Lokalise API den 22 november 2026:

- `component::overkiz::entity::sensor::sensor_defect::state::maintenance_required`
- `component::flow_it::entity::binary_sensor::service::name`

`Service krävs` ersattes med `Underhåll krävs`. Termbanken i
`swedish-foss-terminology` har `Maintenance` → `Underhåll`; den svenska
formuleringen är också mer precis för ett underhållsbehov. Båda värdena lästes
tillbaka efter sparning.
