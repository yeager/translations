# Home Assistant Core – Growatt: tokenautentisering

`component::growatt_server::config::step::user::description` rättades från
`API-token autentisering` till `Tokenautentisering`. Källan säger *Token
authentication*, inte *API token authentication*, och `tokenautentisering` är
den etablerade sammansättningen i översättningsminnet. MIN/SPH, användarnamn
och lösenordsautentisering bevarades. Ändringen sparades och återlästes via
Lokalise API.
