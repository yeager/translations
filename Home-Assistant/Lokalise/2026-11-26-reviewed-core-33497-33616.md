## Retroaktiv Home Connect-referenskorrigering

Home Connects delade `Present`-mål var felöversatt som `Nuvarande`. Källan använder tillståndet för att ange att händelsen/villkoret är aktivt. Gemensamt mål ändrades till `Aktiv`, och samtliga **47** aktuella sensoralias verifierades via Lokalise API mot målet. Rapport och TM-manifest listar varje alias med fullständig Lokalise-nyckel, ID och källa.

## Retroaktiv referenskorrigering: Vodafone Station

Ändringen av reconfigure-aliaset `component::vodafone_station::config::step::reconfigure::data_description::host` krävde samma uppdatering av dess delade mål `component::vodafone_station::config::step::user::data_description::host`. Målet och aliaset har verifierats mot aktuell `strings.json`-referens och lästs tillbaka via Lokalise API. Det fullständiga mål-ID:t, befintlig text och ny text finns i `2026-11-26-retroactive-reference-targets.json`.

## Källor och verktyg

- Home Assistant Core källrevision `86a2eabe7e43f526db5821ef068087ce8404ae07`; kontrollerade komponenternas `strings.json` samt kodkontext för NUT-uttag, Home Connect-sensorer och PGLab-cover.
- Home Connect API `EventPresentState` definierar `Present` som en händelse som har inträffat och fortfarande föreligger; översättningen `Aktiv` bedöms passa för samtliga händelse-/varningssensorer ([officiell API-dokumentation](https://api-docs.home-connect.com/events)).
- SmartThings knappvärden synkade med tidigare granskade `up`-/`down`-värden och dokumenterad knapphändelsekontext.
- `svlang skrivregler` fann inga skrivregelavvikelser. `svlang check` gav 32 heuristiska träffar på sammanslaget batchmaterial, främst längd/V2-varningar samt kod- och platshållarord; dessa granskades manuellt. Hunspell lämnade efter ordboksuppdateringen endast platshållare/kodidentifierare och varumärkesdelarna i `Calc'N'Clean`. Swediskt lexikalt innehåll täcks av 19/19 godkända Hunspell-regressionstester. Termbanken gav stöd för `Confirmed` → `Bekräftad`; inget projektoberoende `Present`-mål tillämpades utan att kontrollera händelsekontexten.
- Lokalise-befintlig/föreslagen text, källväg, pluralflagga, platshållare och TM-status finns i JSON-manifestet.
