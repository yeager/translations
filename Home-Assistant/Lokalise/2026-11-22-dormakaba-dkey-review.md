# Dormakaba dKey: fullständig komponentgranskning

Samtliga sexton svenska strängar lästes från Lokalise API och granskades rad
för rad den 22 november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar aktiveringskoder med exempelvärdet `GBZT-HXC0`,
Bluetooth-räckvidd, omautentisering, dKey-adminappen och dörrlås-sensorn.
