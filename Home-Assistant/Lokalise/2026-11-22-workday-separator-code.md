# Workday: kodmarkerad kommateckensavgränsare

Fyra parallella Workday-strängar rättades via Lokalise API den 22 november
2026. Kommatecknet som används som konfigurationsavgränsare ändrades från
`','` till Markdown-kodmarkeringen `` `,` `` i samtliga relevanta konfigurations-
och åtgärdsflöden. Alla fyra värden lästes tillbaka efter sparning.
