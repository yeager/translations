# Home Assistant Core – återautentisering lyckades

Fyra statusmeddelanden med `Re-authentication was successful` förenhetligades
från `Återautentiseringen lyckades` till projektets etablerade
`Återautentisering lyckades` (Victron Remote Monitoring, Cync, Airly och
Threema). Varje ändring sparades och återlästes via Lokalise API.
