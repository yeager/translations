# Modbus: konfigurationsnyckel som kod

Två Modbus-strängar rättades via Lokalise API den 22 november 2026:

- `component::modbus::issues::removed_lazy_error_count::description`
- `component::modbus::issues::deprecated_retries::description`

Den tekniska platshållaren `{config_key}` återställdes med
Markdown-kodmarkering i båda strängarna. Båda ändringarna lästes tillbaka
efter sparning.
