# Home Assistant – Acmeda: svensk radgranskning

Datum: 2026-11-21  
Projekt: Home Assistant Core i Lokalise  
Komponent: `acmeda`

Aktuellt lokalt källträd och Lokalise API jämfördes för samtliga 4/4 komponentnycklar. Ingen tidigare Acmeda-rapport hittades.

| Fullständig nyckel | Engelska | Svenska | Resultat |
| --- | --- | --- | --- |
| `component::acmeda::config::abort::no_devices_found` | No devices found on the network | Inga enheter hittades i nätverket | Korrekt. |
| `component::acmeda::config::step::user::data::id` | Host ID | Värd-ID | Korrekt teknisk term och svensk sammansättning. |
| `component::acmeda::config::step::user::title` | Pick a hub to add | Välj en hubb att lägga till | Korrekt. |
| `component::acmeda::exceptions::hub_reset_failed::message` | Could not reset the Acmeda hub while unloading | Det gick inte att återställa Acmeda-hubben när den kopplades från. | Korrekt; produktnamn och bindestreck bevaras. |

Inga platshållare, pluralformer, länkreferenser eller formatmarkörer förekommer. Inga ändringar behövde sparas och inga lokala, osparade förslag återstår.
