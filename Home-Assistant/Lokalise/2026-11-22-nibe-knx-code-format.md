# NIBE Heat Pump och KNX: kodmarkering och källfullständighet

Tre Core-strängar rättades via Lokalise API den 22 november 2026 och lästes
tillbaka efter sparning.

| Nyckel | Ändring |
| --- | --- |
| `component::nibe_heatpump::config::error::read` | Återställd kodmarkering för `Fjärrläsningsport` och `Fjärr-IP-adress`. |
| `component::knx::services::event_register::description` | Återställd kodmarkering för händelseidentifieraren `knx_event`. |
| `component::knx::services::read::description` | Återställd kodmarkering för `knx_event` och översatt den tidigare bortfallna meningen om att vänta på svar från en enskild gruppadress. |
