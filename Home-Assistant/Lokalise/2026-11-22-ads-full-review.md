# ADS

Samtliga åtta aktuella ADS-strängar kontrollerades direkt via Lokalise API den
22 november 2026. ADS-specifika fältnamn, handlingarna för att skriva värden
och konsekvent bindestrecksskrivning (`ADS-enhet`, `ADS-typ` och
`ADS-variabel`) är korrekta.

Den tidigare korrigeringen för
`component::ads::services::write_data_by_name::name` finns sparad i Lokalise:
`Skriv data med variabelnamn`. Inga ytterligare ändringar behövdes.
