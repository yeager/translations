# Template: tillstånd och parameteridentifierare

Tio Template-strängar rättades via Lokalise API den 22 november 2026 och
lästes tillbaka efter sparning. Källans maskinvärden `on` och `off`,
mallvariablerna `value`, `option` och `options`, samt uppdateringsalternativet
`automatic backup before update` hade översatts till svenska. Kodidentifierarna
återställdes medan den svenska förklarande texten behölls.
