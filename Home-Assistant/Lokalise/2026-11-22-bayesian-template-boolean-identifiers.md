# Bayesian: körbara mallvärden

28 Bayesian-strängar rättades via Lokalise API den 22 november 2026 och
lästes tillbaka efter sparning. I beskrivningar av mallresultat hade de
körbara värdena `True`, `False` och `None` översatts till `Sant`, `Falskt`
och `Inget`. De återställdes exakt som kodvärden; svenska förklaringar och
användargränssnittsetiketter lämnades oförändrade.
