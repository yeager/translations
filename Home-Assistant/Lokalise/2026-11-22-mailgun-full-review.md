# Mailgun

Samtliga tio aktuella Mailgun-strängar kontrollerades direkt via Lokalise API
den 22 november 2026. Markdown, länkar, platshållarna `{mailgun_url}`,
`{webhook_url}` och `{docs_url}`, samt de tekniska värdena `POST` och
`application/json` är bevarade.

De tidigare terminologiändringarna finns sparade: `Metod`, `Innehållstyp` och
`Mailgun-webhooken`. `webhooks` i den länkade Mailgun-vyn lämnas avsiktligt som
ett externt gränssnittsnamn. Inga ytterligare ändringar behövdes.
