# Template Update: återställda identifierare

Två Template Update-strängar rättades via Lokalise API den 22 november 2026.
De maskinella värdena `version`, `install`, `specific_version` och `None`
hade översatts eller fått typografiska citattecken. De är nu återställda som
kod i både konfigurations- och alternativsflödet och har lästs tillbaka efter
sparning.
