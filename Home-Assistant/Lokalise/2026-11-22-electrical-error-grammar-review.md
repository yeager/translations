# Home Assistant Core – elektriska felmeddelanden

Tre ytterligare felmeddelanden fick fullständig svensk grammatik: två
Husqvarna-meddelanden om för hög intern ström och ett Fronius-meddelande om
en uppmätt DC-komponent. De sparades och återlästes via Lokalise API och
fördes in i den kanoniska TMX-filen.
