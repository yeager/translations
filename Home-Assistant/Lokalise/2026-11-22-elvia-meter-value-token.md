# Elvia: API-token för mätvärden

`component::elvia::config::step::user::description` rättades från `Ange din API-token för mätpunkt från Elvia` till `Ange din API-token för mätvärden från Elvia`. Källtexten avser uttryckligen *meter value API token*, inte en mätpunkt. Ändringen sparades och lästes tillbaka via Lokalise API den 22 november 2026.
