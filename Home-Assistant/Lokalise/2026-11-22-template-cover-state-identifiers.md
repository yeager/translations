# Template Cover: körbara tillståndsvärden

Konfigurations- och alternativsflödets `state`-beskrivning rättades via
Lokalise API den 22 november 2026. De körbara värdena `open`, `opening`,
`closing` och `closed` hade översatts till svenska. De återställdes som kod och
båda värdena lästes tillbaka efter sparning.
