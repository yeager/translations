# Home Assistant Core – retroaktiv korrigering av Release URL

Datum: 2026-11-26  |  Källrevision: `c03d786a2335a70d01860cae56286798bb272871`

Den tidigare svenska termen `Version URL` ersattes med `Versions-URL` för den fullständiga nyckeln `component::update::entity_component::_::state_attributes::release_url::name`. Rättelsen sparades och lästes tillbaka via Lokalise API. De två aktiva Template Update-aliasen synkades till samma term och matchar sina källor. Den äldre TM-posten ska skrivas över, inte lämnas kvar som parallellt förslag. Se JSON-filen för key-ID, translation-ID och verifieringsstatus.
