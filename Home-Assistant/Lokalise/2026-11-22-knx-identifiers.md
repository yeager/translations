# KNX: tekniska identifierare

Två KNX-strängar rättades via Lokalise API den 22 november 2026 och lästes
tillbaka efter sparning.

| Nyckel | Ändring |
| --- | --- |
| `component::knx::services::event_register::fields::type::description` | Den faktiska händelsedatanyckeln `value` återställdes som kod i stället för den felaktiga översättningen `värdenyckel`. |
| `component::knx::services::send::fields::response::description` | `GroupValueResponse` och `GroupValueWrite` återställdes med Markdown-kodmarkering. |

Platshållaren `{sensor_value_types_url}` är bevarad.
