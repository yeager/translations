# Liveverifierad terminologisynk: `integration`

Arton tidigare sparade Lokalise-ändringar synkades den 22 november 2026 till
Home Assistant-minnet. De ersätter den inkonsekventa äldre termen
`integrering` med `integration` eller `integrationer` i bland annat Xiaomi
Mijia BLE, Sonos, Mitsubishi Comfort, Teslemetry, Discogs, Volkszaehler,
Gree, Ring, Fronius, MCP Server, Marketplace och LiteLLM.

Varje post lästes tillbaka från Lokalise API med fullständig nyckel,
Lokalise-nyckel-id och översättnings-id. Markdown, radbrytningar och
platshållare som `{device_ip}`, `{documentation_url}`, `{devices}` och
`{scripts}` bevarades. Den kanoniska HA-TMX-filen validerar med 3 368 poster
(`swedish-tm`-commit `1fce04d`).
