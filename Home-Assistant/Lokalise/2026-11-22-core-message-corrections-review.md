# Home Assistant Core – meddelanderättningar

Tre kontextkontrollerade Core-strängar rättades: TotalConnects `night` är nu
`nattläge` i stället för `hemmaläge`, Homematic IP:s timeoutmeddelande är
fullständig svenska och System Bridge använder den naturliga formuleringen
`Ingen data togs emot`. Platshållarna kontrollerades, svlang användes för de
nya formuleringarna och varje resultat återlästes från Lokalise API.
