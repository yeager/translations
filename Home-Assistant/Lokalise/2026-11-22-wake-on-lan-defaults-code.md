# Wake-on-LAN: standardvärden som kod

Sex parallella Wake-on-LAN-strängar rättades via Lokalise API den 22 november
2026. Standardvärdena `255.255.255.255` och `9` återställdes med
Markdown-kodmarkering i tjänst-, konfigurations- och alternativsflödena.
Samtliga värden lästes tillbaka efter sparning.
