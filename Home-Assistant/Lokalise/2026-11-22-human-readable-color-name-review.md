# Home Assistant Core – läsbart färgnamn

LIFX hade den avvikande formuleringen `Människoläsbart färgnamn.`. Den har
normaliserats till `Ett mänskligt läsbart färgnamn.`, vilket matchar
termbanken och de tre övriga Core-strängarna med samma källtext. Ändringen
sparades och återlästes via Lokalise API.
