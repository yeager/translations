# NextBus: fullständig komponentgranskning

Samtliga elva svenska strängar lästes från Lokalise API och granskades rad för
rad den 22 november 2026. Två rättades och lästes tillbaka efter sparning:

- `component::nextbus::config::step::agency::title`: `Väl` → `Välj`.
- `component::nextbus::title`: `NextBus prognoser` → `NextBus-prognoser`.

Övriga nio strängar var korrekta.
