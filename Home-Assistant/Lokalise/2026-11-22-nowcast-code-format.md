# Nowcast-prognosentitet

Två parallella vädersträngar rättades via Lokalise API den 22 november 2026:

- `component::climacell::options::step::init::description`
- `component::tomorrowio::options::step::init::description`

Identifieraren `nowcast` återställdes med Markdown-kodmarkering i den svenska
sammansättningen `nowcast`-prognosentiteten. Värdena lästes tillbaka efter
sparning.
