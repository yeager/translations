# Home Assistant Core – Prowl: API-nyckelinstruktion

`component::prowl::config::step::user::description` rättades från
`Ange Prowl API-nyckel och dess namn.` till `Ange Prowl API-nyckel.`

Den tidigare svenska texten lade till ett krav på namn som inte finns i den
engelska källan. Nyckelidentitet, källa och sparad text verifierades via
Lokalise API.
