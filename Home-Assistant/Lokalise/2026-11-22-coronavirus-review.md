# Home Assistant Core – Coronavirus

Datum: 2026-11-22

Komponentens samtliga fyra strängar är granskade mot den aktuella engelska
källan och återlästa från Lokalise API. Ingen ändring behövdes.

| Nyckel | Svenska |
| --- | --- |
| `component::coronavirus::config::abort::already_configured` | Tjänsten är redan konfigurerad |
| `component::coronavirus::config::abort::cannot_connect` | Det gick inte att ansluta |
| `component::coronavirus::config::step::user::data::country` | Land |
| `component::coronavirus::config::step::user::title` | Välj ett land att övervaka |

Inga platshållare, referenser eller pluralformer förekommer. Hunspell och
svlang godkänner texten. Lokalise API:s verifieringsflagga är ej skrivbar med
projektets behörighet; innehållsgranskningen är därför spårad här.
