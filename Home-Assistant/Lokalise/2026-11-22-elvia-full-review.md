# Elvia

Samtliga åtta aktuella Elvia-strängar kontrollerades direkt via Lokalise API den
22 november 2026. Platshållaren `{metering_point_id}`, produktnamnet Elvia och
termen `API-token` är korrekta.

Den tidigare korrigeringen i
`component::elvia::config::step::user::description` finns sparad i Lokalise:
`Ange din API-token för mätvärden från Elvia`. Den ersätter den mindre precisa
formuleringen `... för mätpunkt ...`; källtexten avser en token för
mätvärdes-API:t, inte en mätpunktsidentifierare.

Inga ytterligare ändringar behövdes.
