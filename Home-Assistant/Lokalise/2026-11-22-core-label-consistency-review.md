# Home Assistant Core – konsekventa tekniska etiketter

Tolv etiketter normaliserades mot etablerade Core-former efter live-kontroll:
OT- och RTSP-termer, Dolby-läge, Smart-läge, PV-effekt, Gateway-läge,
Nextcloud-information och Tal-till-text. Varje sparad svensk måltext
återlästes via Lokalise API.
