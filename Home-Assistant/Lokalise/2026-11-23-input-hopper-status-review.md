# Hassio Input och Litter-Robot Hopper status

Datum: 2026-11-23. Båda aktiva fältetiketterna kontrollerades direkt i Lokalise.

| Fullständig nyckel | Befintlig svenska | Sparad svenska | Motivering |
| --- | --- | --- | --- |
| `component::hassio::services::app_stdin::fields::input::name` | `Input` | `Indata` | Fältet avser data som skickas till appens standardindata. |
| `component::litterrobot::entity::sensor::hopper_status::name` | `Hopper status` | `Status för behållaren` | Full svensk sensorbenämning för status på behållaren. |

Ändringarna sparades via Lokalise API och lästes tillbaka. De verifierade live-posterna har lagts in i den kanoniska Home Assistant-TMX:en.
