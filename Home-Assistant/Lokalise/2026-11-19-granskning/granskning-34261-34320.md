### `component::bayesian::config_subentries::observation::step::user::description`
- Engelska: 'Observations' are the sensor or template values that are monitored and then combined in order to inform the Bayesian sensor's final probability. Each observation will update the probability of the Bayesian sensor if it is detected, or if it is not detected. If the state of the entity becomes `unavailable` or `unknown` it will be ignored. If more than one state or more than one numeric range is configured for the same entity then inverse detections will be ignored.
- Nuvarande: "Observationer" är de sensor- eller mallvärden som övervakas och sedan kombineras för att informera den bayesianska sensorns slutliga sannolikhet. Varje observation uppdaterar den bayesianska sensorns sannolikhet om den upptäcks eller om den inte upptäcks. Om enhetens tillstånd blir "otillgängligt" eller "okänt" ignoreras det. Om mer än ett tillstånd eller mer än ett numeriskt intervall är konfigurerat för samma enhet ignoreras inversa detektioner.
- Förslag: ”Observationer” är de sensor- eller mallvärden som övervakas och sedan kombineras för att beräkna den bayesianska sensorns slutliga sannolikhet. Varje observation uppdaterar sannolikheten både när den upptäcks och när den inte upptäcks. Om entitetens tillstånd blir `unavailable` eller `unknown` ignoreras det. Om mer än ett tillstånd eller numeriskt intervall är konfigurerat för samma entitet ignoreras uteblivna observationer.

### `component::bayesian::config_subentries::observation::step::template::data_description::value_template`
- Engelska: A template that evaluates to `True` will update the prior accordingly, A template that returns `False` or `None` will update the prior with inverse probabilities. A template that returns an error will not update probabilities. Results are coerced into being `True` or `False`
- Nuvarande: En mall som utvärderas till `Sant` kommer att uppdatera prioriteten i enlighet med detta, En mall som returnerar `Falskt` eller `Inget` kommer att uppdatera prioriteten med omvända sannolikheter. En mall som returnerar ett fel kommer inte att uppdatera sannolikheter. Resultaten tvingas till att vara `Sant` eller `Falskt`
- Förslag: En mall som utvärderas till `True` uppdaterar förhandssannolikheten utifrån detta. En mall som returnerar `False` eller `None` uppdaterar förhandssannolikheten med omvända sannolikheter. En mall som returnerar ett fel uppdaterar inte sannolikheterna. Resultaten omvandlas till `True` eller `False`.

### `component::bayesian::config_subentries::observation::step::state::description`
- Engelska: Add an observation which evaluates to `True` when the value of the sensor exactly matches *'To state'*. When `False`, it will update the prior with probabilities that are the inverse of those set below. This behavior can be overridden by adding observations for the same entity's other states.
- Nuvarande: Lägg till en observation som utvärderas till `Sant` när värdet på sensorn exakt matchar *'Till tillstånd'*. När `Falskt`, kommer den att uppdatera prioriteten med sannolikheter som är inversen av de som anges nedan. Detta beteende kan åsidosättas genom att lägga till observationer för samma enhets andra tillstånd.
- Förslag: Lägg till en observation som utvärderas till `True` när sensorns värde exakt matchar *'Till tillstånd'*. När resultatet är `False` uppdateras förhandssannolikheten med de omvända sannolikheterna till dem som anges nedan. Detta kan ändras genom att lägga till observationer för samma entitets andra tillstånd.
