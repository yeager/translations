## 8965. `component::command_line::issues::shell_command_template_deprecation::description`

**Engelska:** The `command_line` `{platform}` `{name}` runs a command (`{program}`) that uses a template. For security, commands that use a template will run without a shell in Home Assistant 2027.4, so shell features (pipes, redirects, globbing, etc.) anywhere in the command will no longer work.

Update the command to avoid shell features, or move the logic into a script the command calls.

**Befintlig svenska:** `command_line` `{platform}` `{name}` kör ett kommando (`{program}`) som använder en mall. Av säkerhetsskäl körs kommandon som använder en mall utan skal i Home Assistant 2027.4. Därför fungerar skalfunktioner som rör, omdirigeringar, globbning och liknande inte längre någonstans i kommandot.

Uppdatera kommandot så att det inte använder skalfunktioner eller flytta logiken till ett skript som kommandot anropar.

**Bedömning:** Ingen ändring föreslås.
