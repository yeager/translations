# Home Assistant Core: position 34 981–34 997

De gemensamma Teslemetry-nycklarna har granskats rad för rad i Lokalise, sorterat efter senast tillagda; positionerna är en ögonblicksbild. Inga ändringar har gjorts i Lokalise. sv-lang och hunspell-sv har använts för språk- och stavningskontroll samt swedish-foss-terminology och swedish-tm som terminologistöd. Hunspell markerar produktnamnet Home Assistant. Förslagen gäller referensmålen, så hänvisande fält kan behålla sina referenser. Övriga referensmål återstår att kontrollera.

## Ändringsförslag

### `component::teslemetry::common::start_time_description`
- Engelska: The time this schedule begins, e.g. 01:05 for 1:05 AM.
- Nuvarande: Den tid då schemat börjar, t.ex. 01:05 för 1:05 AM.
- Förslag: Tiden då schemat börjar, till exempel 01:05 för fem minuter över ett på natten.

### `component::teslemetry::common::end_time_description`
- Engelska: The time this schedule ends, e.g. 01:05 for 1:05 AM.
- Nuvarande: Den tid då schemat slutar, t.ex. 01:05 för 1:05 AM.
- Förslag: Tiden då schemat slutar, till exempel 01:05 för fem minuter över ett på natten.

### `component::teslemetry::common::precondition_time_description`
- Engelska: The time the vehicle should complete preconditioning, e.g. 01:05 for 1:05 AM.
- Nuvarande: Den tid då fordonet ska slutföra förkonditionering, t.ex. 01:05 för 1:05 AM.
- Förslag: Tiden då fordonets förkonditionering ska vara klar, till exempel 01:05 för fem minuter över ett på natten.

### `component::teslemetry::common::schedule_id_description`
- Engelska: The ID of the schedule, use an existing ID to modify.
- Nuvarande: Schemats ID, använd ett befintligt ID för att ändra.
- Förslag: Schemats ID. Ange ett befintligt ID för att ändra schemat.

### `component::teslemetry::common::schedule_enable_description`
- Engelska: If this schedule should be considered for execution.
- Nuvarande: Om det här schemat ska övervägas för körning.
- Förslag: Om schemat ska vara aktivt.

### `component::teslemetry::common::location_description`
- Engelska: The approximate location the vehicle must be at to use this schedule. Defaults to Home Assistant's configured location.
- Nuvarande: Den ungefärliga plats där fordonet måste befinna sig för att använda detta schema. Standard är den plats som konfigurerats av Home Assistant.
- Förslag: Den ungefärliga plats där fordonet måste befinna sig för att använda schemat. Som standard används platsen som är inställd i Home Assistant.
