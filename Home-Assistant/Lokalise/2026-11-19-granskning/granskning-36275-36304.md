# Home Assistant Core: position 36 275–36 304

Granskat rad för rad i Lokalise, sorterat efter senast tillagda; positionerna är en ögonblicksbild. Inga ändringar har gjorts i Lokalise. Beskrivningarna av öppning och stängning tolkas som åtgärder vid kommandot, i linje med fältnamnen; kontrollera funktionens beteende.

## Ändringsförslag

### `component::template::config::step::cover::title`
- Engelska: Template cover
- Nuvarande: Mall för ett skydd
- Förslag: Mallenhet för öppning och stängning

### `component::template::config::step::cover::data_description::state`
- Engelska: Defines a template to get the state of the cover. Valid output values from the template are `open`, `opening`, `closing` and `closed` which are directly mapped to the corresponding states. If both a state and a position are specified, only `opening` and `closing` are set from the state template.
- Nuvarande: Definierar en mall för att hämta enhetens tillstånd. Giltiga utdatavärden från mallen är `öppen`, `öppnar`, `stänger` och `stängd`, vilka direkt motsvarar de respektive tillstånden. Om både ett tillstånd och en position anges, används endast `öppnar` och `stänger` från tillståndsmallen.
- Förslag: Anger en mall som hämtar enhetens tillstånd. Giltiga värden från mallen är `open`, `opening`, `closing` och `closed`, som motsvarar respektive tillstånd. Om både tillstånd och position anges används endast `opening` och `closing` från tillståndsmallen.

### `component::template::config::step::cover::data_description::position`
- Engelska: Defines a template to get the position of the cover. Value values are numbers between `0` (`closed`) and `100` (`open`).
- Nuvarande: Definierar en mall för att hämta öppningsgraden. Värdet är ett tal mellan 0 (stängd) och 100 (öppen).
- Förslag: Anger en mall som hämtar öppningsgraden. Värdet är ett tal mellan `0` (stängd) och `100` (öppen).

### `component::template::config::step::cover::data_description::open_cover`
- Engelska: Defines actions  to run when the cover is opened.
- Nuvarande: Definierar åtgärder som ska köras när enheten har öppnats.
- Förslag: Anger vilka åtgärder som ska utföras när enheten öppnas.

### `component::template::config::step::cover::data_description::close_cover`
- Engelska: Defines actions  to run when the cover is closed.
- Nuvarande: Definierar åtgärder som ska köras när enheten har stängts.
- Förslag: Anger vilka åtgärder som ska utföras när enheten stängs.

### `component::template::config::step::cover::data::set_cover_position`
- Engelska: Actions on set position
- Nuvarande: Åtgärder när position sätts
- Förslag: Åtgärder när positionen ställs in

## Referenser och övriga strängar

Nitton rader innehåller samma nyckelreferens på engelska och svenska och bör behållas som referenser. Referensen `component::template::options::step::cover::data_description::state` påverkas av förslaget till målnyckeln ovan. De övriga fem direkta strängarna kan behållas: beskrivningarna av stopp och positionskommando samt etiketterna för stoppåtgärder, position och öppningsåtgärder.
