### `component::neopool::issues::corrupted_gpio::description`

- Engelska: The following GPIO register(s) on your pool controller contain invalid values:

{details}

This typically happens when the Modbus gateway framing mode does not match the integration's framer setting. The affected function(s) will not work correctly until the register(s) are restored to valid values.

See the integration documentation for repair instructions.
- Nuvarande svenska: Följande GPIO-register på din poolkontroller innehåller ogiltiga värden:

{details}

Detta händer vanligtvis när Modbus-gatewayens framing-läge inte matchar integrationens framer-inställning. De berörda funktionerna kommer inte att fungera korrekt förrän registret har återställts till giltiga värden.

Se integrationsdokumentationen för reparationsinstruktioner.
- Förslag: Följande GPIO-register på din poolstyrenhet innehåller ogiltiga värden:

{details}

Detta inträffar vanligtvis när Modbus-gatewayens inramningsläge inte stämmer överens med integrationens inställning för inramning. De berörda funktionerna fungerar inte korrekt förrän registren har återställts till giltiga värden.

Se integrationens dokumentation för anvisningar om hur du åtgärdar felet.

### `component::neopool::config::step::user::data_description::modbus_framer`

- Engelska: Wire protocol used by the gateway. Select TCP for MBAP framing (default for Ethernet-native gateways). Select RTU for RTU framing tunnelled through a TCP socket, used by passthrough serial-to-TCP bridges like ESPHome's stream_server.
- Nuvarande svenska: Det nätverksprotokoll som används av gatewayen. Välj TCP för MBAP-framing (standardinställning för Ethernet-baserade gateways). Välj RTU för RTU-framing som tunnlas via en TCP-socket, vilket används av passthrough mellan seriell anslutning och TCP, såsom ESPHomes stream_server.
- Förslag: Protokollet som gatewayen använder på anslutningen. Välj TCP för MBAP-inramning (standard för Ethernet-baserade gatewayenheter). Välj RTU för RTU-inramning som tunnlas via en TCP-socket. Det används av bryggor som vidarebefordrar seriell trafik via TCP, till exempel ESPHomes stream_server.
