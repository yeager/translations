### `component::mqtt::config_subentries::device::step::mqtt_platform_config::data_description::code_trigger_required`
- Engelska: If set, the code is required to manually trigger the alarm. If not set, the code is not validated.
- Nuvarande: Om denna inställning är aktiverad måste koden anges manuellt för att larmet ska utlösas. Om den inte är aktiverad kontrolleras inte koden.
- Förslag: Om inställningen är aktiverad krävs koden för att utlösa larmet manuellt. Annars kontrolleras inte koden.

### `component::mqtt::config_subentries::device::step::entity_platform_config::data_description::alarm_control_panel_code_mode`
- Engelska: Configures how the alarm control panel validates the code. A local code is configured with the entity and is validated by Home Assistant. A remote code is sent to the device and validated remotely. [Learn more.]({url}#code)
- Nuvarande: Ställer in hur larmpanelen validerar koden. En lokal kod konfigureras i enheten och valideras av Home Assistant. En fjärrkod skickas till enheten och valideras på distans. [Läs mer.]({url}#code)
- Förslag: Anger hur larmpanelen validerar koden. En lokal kod konfigureras för entiteten och valideras av Home Assistant. En fjärrkod skickas till enheten och valideras där. [Läs mer.]({url}#code)
