## Ändringsförslag

### `component::bayesian::config_subentries::observation::step::numeric_state::description`
- Engelska: Add an observation which evaluates to `True` when a numeric sensor is within a chosen range.
- Nuvarande: Lägg till en observation som utvärderas till `Sant` när en numerisk sensor är inom ett valt intervall.
- Förslag: Lägg till en observation som utvärderas till `True` när en numerisk sensors värde ligger inom ett valt intervall.

### `component::bayesian::config_subentries::observation::step::numeric_state::data_description::below`
- Engelska: Optional - the upper end of the numeric range. Values exactly matching this will only count if more than one range is configured for the same entity.
- Nuvarande: Valfritt - den övre änden av det numeriska intervallet. Värden som exakt matchar detta kommer endast att räknas om mer än ett intervall har konfigurerats för samma enhet.
- Förslag: Valfritt – intervallets övre gräns. Värden som är lika med gränsen räknas bara om mer än ett intervall är konfigurerat för samma entitet.

### `component::bayesian::config_subentries::observation::step::numeric_state::data_description::above`
- Engelska: Optional - the lower end of the numeric range. Values exactly matching this will not count
- Nuvarande: Valfritt - den nedre delen av det numeriska intervallet. Värden som exakt matchar detta kommer inte att räknas
- Förslag: Valfritt – intervallets nedre gräns. Värden som är lika med gränsen räknas inte.

### `component::bayesian::config::step::user::title`
- Engelska: Add a Bayesian sensor
- Nuvarande: Lägg till en Bayesiansk sensor
- Förslag: Lägg till en bayesiansk sensor

### `component::bayesian::config::step::user::data_description::probability_threshold`
- Engelska: The probability above which the sensor will show as 'on'. 50% should produce the most accurate result. Use numbers greater than 50% if avoiding false positives is important, or vice-versa.
- Nuvarande: Den sannolikhet över vilken sensorn kommer att visa "på". 50% bör ge det mest exakta resultatet. Använd siffror som är större än 50% om det är viktigt att undvika falska positiva resultat, eller vice versa.
- Förslag: Sannolikheten som måste överskridas för att sensorn ska visa ”på”. 50 % bör ge det mest exakta resultatet. Använd ett värde över 50 % om det är viktigt att undvika falskt positiva resultat, och ett lägre värde om det motsatta är viktigare.

### `component::bayesian::config::step::user::data_description::prior`
- Engelska: The baseline probability the sensor should be 'on', this is usually the percentage of time it is true. For example, for a sensor 'Everyone sleeping' it might be 8 hours a day, 33%.
- Nuvarande: Baslinjesannolikheten för att sensorn ska vara "på", detta är vanligtvis procentandelen av tiden som den är sann. För sensorn "Alla sover" kan det t.ex. vara 8 timmar om dagen, 33 %.
- Förslag: Förhandssannolikheten för att sensorn ska vara ”på”. Den motsvarar vanligtvis andelen av tiden då tillståndet är sant. För sensorn ”Alla sover” kan det till exempel vara 8 timmar om dagen, alltså 33 %.

### `component::bayesian::config::step::user::data::prior`
- Engelska: Prior
- Nuvarande: Före
- Förslag: Förhandssannolikhet
