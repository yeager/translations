## 1757. `component::izone::issues::yaml_exclude_unused::description`

**Engelska:** iZone now sets up each controller as its own entry, so the `exclude` option in the `izone:` section of your `configuration.yaml` file is no longer needed and has no effect. Controllers that were listed in it now show up as discovered devices. Add them, or select **Ignore** to hide them.

Remove `exclude` from your `configuration.yaml` file and restart Home Assistant to fix this issue.

**Befintlig svenska:** iZone konfigurerar nu varje styrenhet som en egen post. Alternativet `exclude` i avsnittet `izone:` i din configuration.yaml behövs därför inte längre och har ingen effekt. Styrenheter som fanns i listan visas nu som upptäckta enheter. Lägg till dem eller välj **Ignorera** för att dölja dem.

Ta bort `exclude` från din configuration.yaml och starta om Home Assistant för att åtgärda problemet.

**Bedömning:** Ingen ändring föreslås.
