## 2275. `component::fitbit::issues::integration_removed::description`

**Engelska:** The Fitbit integration has been removed from Home Assistant.

On November 2, 2026, Google permanently shut down the legacy Fitbit Web API ([Fitbit Web API Migration Guide]({migration_guide})). Because legacy Fitbit OAuth credentials and tokens do not carry over, existing entries can no longer sync data or re-authenticate.

To resolve this issue:
1. Set up the [Google Health integration]({google_health_docs}), which replaces the Fitbit integration using the Google Health API.
2. Remove your defunct [Fitbit integration entries]({entries}).
3. Optionally remove any unused Fitbit OAuth credentials in [Application credentials]({application_credentials}).

Once all Fitbit entries are removed, this issue will automatically clear.

**Befintlig svenska:** Fitbit-integrationen har tagits bort från Home Assistant.

Den 2 november 2026 stängde Google permanent ner det äldre Fitbit Web API ([migreringsguide för Fitbit Web API]({migration_guide})). Eftersom äldre Fitbit OAuth-inloggningsuppgifter och token inte följer med kan befintliga poster inte längre synkronisera data eller autentisera på nytt.

Åtgärda problemet så här:
1. Konfigurera [Google Health-integrationen]({google_health_docs}), som ersätter Fitbit-integrationen med Google Health API.
2. Ta bort dina nedlagda [Fitbit-integrationsposter]({entries}).
3. Du kan även ta bort oanvända Fitbit OAuth-inloggningsuppgifter i [programinloggningsuppgifter]({application_credentials}).

När alla Fitbit-poster har tagits bort försvinner problemet automatiskt.

**Bedömning:** Ingen ändring föreslås.
