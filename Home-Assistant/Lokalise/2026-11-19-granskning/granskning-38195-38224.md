# Home Assistant Core: nyckel 38 195–38 224

Granskat i Lokalise enligt den dokumenterade ögonblicksbildens sortering. Först används prefixet `component::unifiprotect::entity::binary_sensor::`; därefter `component::miele::entity::sensor::program_id::state::`. Inga ändringar har gjorts i Lokalise.

| Nyckel efter angivet prefix | Bedömning och eventuellt förslag |
|---|---|
| `car_alarm_detected::name` | Föreslå ”Billarm upptäckt”. |
| `barking_detected::name` | Föreslå ”Hundskall upptäckt”. |
| `baby_cry_detected::name` | Föreslå ”Barnskrik upptäckt”. |
| `audio_object_detected::name` | Föreslå ”Ljudobjekt upptäckt”; produktkontexten kan ge en mer begriplig term för ljudobjekt. |
| `animal_detected::name` | Föreslå ”Djur upptäckt”. |
| `alarm_sound_detection::name` | Behåll ”Larmljudsdetektering”. Detta är även målet för omkopplarens referens. |
