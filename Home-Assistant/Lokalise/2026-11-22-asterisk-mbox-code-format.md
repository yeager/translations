# Asterisk Mbox: återställd kodmarkering

`component::asterisk_mbox::issues::deprecated_integration::description`
rättades via Lokalise API den 22 november 2026. Den svenska texten hade
tappat Markdown-kodmarkeringen för `{mailbox}`, `{domain}` och
`configuration.yaml`. Alla tre fragment är nu markerade som kod, i enlighet
med källtexten, och värdet lästes tillbaka efter sparning.
