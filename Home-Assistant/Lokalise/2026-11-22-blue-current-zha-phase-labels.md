# Blue Current och ZHA: fasetiketter

Elva strängar sparades och lästes tillbaka via Lokalise API den 22 november 2026.

- Blue Current: `Elnätsström, fas 1–3` ersätter den otydliga formen utan avskiljare.
- ZHA: `Effektfaktor, fas B/C`, `Energi, fas A–C` och `Producerad energi, fas A–C` använder samma etablerade etikettformat.

Varje post är dokumenterad med fullständig nyckel, tidigare svensk text, sparad svensk text, engelsk källa och Lokalise-ID i `yeager/swedish-tm/Home-Assistant/2026-11-22-blue-current-zha-phase-labels-verified.json`. Posterna är API-lästa efter sparandet och validerade i det kanoniska Home Assistant-TMX-minnet.
