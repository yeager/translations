# Template: `available`- och `unavailable`-värden, batch 1

Fyra Template-texter rättades via Lokalise API den 22 november 2026:

- gemensam tillgänglighetsbeskrivning
- avancerade alternativ för larmpanel, binär sensor och knapp

De körbara värdena `available` och `unavailable` hade översatts till svenska
trots att de används i mallkonfiguration. De återställdes tillsammans med
övriga kodvärden (`True`, `"1"`, `"true"`, `"yes"`, `"on"`, `"enable"`,
`"TrUe"` och `"yEs"`). Samtliga fyra värden lästes tillbaka efter sparning.
