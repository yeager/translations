# Uppföljning: etablerad term `integration`

Den 22 november 2026 livegranskades och rättades följande ytterligare
Lokalise-poster. Samtliga lästes tillbaka via API och fördes till validerad
HA-TMX.

| Nyckel | Sparad svenska |
| --- | --- |
| `component::weatherkit::exceptions::authentication_error::message` | `Autentiseringsfel vid initiering av WeatherKit-integrationen` |
| `component::cpuspeed::exceptions::not_compatible::message` | `… CPU Speed-integrationen är inte kompatibel med ditt system` |
| `component::huawei_lte::exceptions::serial_number_not_found_unauthenticated::message` | `… i integrationens inställningar` |
| `component::shelly::exceptions::custom_integration_entry::message` | `… en anpassad integration … Shelly-integrationen …` |
| `component::ps4::exceptions::region_migration_failed::message` | `… PlayStation 4-integrationen … lägg till integrationen igen` |
| `component::airvisual::exceptions::migrated_to_airvisual_pro::message` | `… AirVisual Pro-integrationen` |

Tekniska platshållare (`{title}`, `{url}`) bevarades. TMX validerar efter
synkningen med 3 375 poster (`e77013a`).
