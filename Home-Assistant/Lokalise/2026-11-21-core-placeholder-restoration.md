# Home Assistant Core: återställda platshållare

En global kontroll av käll- och målplatshållare hittade tre svenska texter där `{name}` saknades.

- `component::reolink::issues::https_webhook::description`: `{name}` återställt.
- `component::lamarzocco::issues::unsupported_gateway_firmware::description`: `{name}` återställt tillsammans med `{gateway_version}`.
- `component::smlight::issues::unsupported_firmware::description`: `{name}` återställt.

Varje värde sparades via Lokalise API och återlästes. Spårbart manifest: `Home-Assistant/2026-11-21-placeholder-restoration-verified.json`; TMX validerad till 2 478 poster.
