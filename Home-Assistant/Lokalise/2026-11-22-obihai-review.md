# Obihai: fullständig komponentgranskning

Samtliga tolv svenska strängar lästes från Lokalise API och granskades rad för
rad den 22 november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar anslutning och autentisering, värd- och
inloggningsuppgifter samt DHCP-bekräftelse med platshållaren `{host}`.
