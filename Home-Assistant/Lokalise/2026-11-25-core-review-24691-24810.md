- `component::chess_com::entity::sensor::total_daily_won::unit_of_measurement` saknar sökväg i aktuell `strings.json`. Källan använder nu `chess_daily_won::unit_of_measurement`; målnyckeln kontrollerades via Lokalise API och har engelska `games`, svenska `partier`. Legacy-mappningen är markerad för uppföljning.
- Chess.com beskriver Daily Chess som ett flerdagarsformat, med separat rating från Live Chess. Se [Chess.com Help: What is Daily Chess?](https://support.chess.com/en/articles/8588171-what-is-daily-chess) och [How do ratings work?](https://support.chess.com/en/articles/8566476-how-do-ratings-work-on-chess-com).
