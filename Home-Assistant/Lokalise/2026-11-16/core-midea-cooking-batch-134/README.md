# Midea: matlagningslägen, del två

29 svenska matlagningslägen har granskats och sparats i Lokalise. Förinställda maträtter har fått begripliga svenska namn utan att ändra teknik- eller produktnamn.

Kontroller: `l10n-lint`, Gitleaks och exakt läsning tillbaka från Lokalise för samtliga poster (`is_unverified: false`). `msgfmt` är inte tillämpligt på JSON-katalogen.
