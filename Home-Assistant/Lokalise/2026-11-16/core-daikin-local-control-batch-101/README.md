# Home Assistant Core: Daikin med lokal styrning, batch 101

Två felmeddelanden för Daikin-enheter utan lokalt styrnings-API. Benämningen *inbyggd programvara* förklarar firmware på svenska utan att förlora den tekniska innebörden.

Kontroller före inskick:

- JSON och platshållare är giltiga.
- `l10n-lint`, Hunspell-sv och `svlang` har körts. Hunspell-sv kan markera egennamn och produktnamn som förväntade träffar.
- `git diff --check` och Gitleaks har körts.
- `msgfmt` är inte tillämpligt eftersom Lokalise API-batchen är JSON, inte en PO-fil.

Upstreamstatus: båda översättningarna har sparats med Lokalise API och har en separat, exakt API-läsning efteråt. Det bekräftar sparat innehåll, inte extern granskning, sammanslagning eller en utgåva.
