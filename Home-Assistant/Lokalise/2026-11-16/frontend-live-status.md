# Home Assistant Frontend: livekontroll, 16 november 2026

En autentiserad kontroll av Lokalise-projektet *Home Assistant - frontend*
bekräftar följande för svenska (`sv`):

- framsteg: 100 %
- återstående ord: 0

Det betyder att Lokalise för närvarande inte rapporterar någon oöversatt
svensk frontendtext. Det är ett statusmått, inte ett påstående om att varje
översättning är formellt upstreamgranskad eller med i en release.

Home Assistant Core kontrollerades också, men den nuvarande Lokalise-tokenen
fick HTTP 403 för Core-projektet. Core får därför behålla sin senast
arkiverade, separata API-verifiering tills läsbehörighet finns igen.
