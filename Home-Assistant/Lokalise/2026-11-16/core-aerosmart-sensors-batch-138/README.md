# aerosmart: sensorer och drift

35 svenska aerosmart-strängar för värmepump, ventilation, filter och driftsstatus har granskats, sparats och lästs tillbaka i Lokalise.

Kontroller: `l10n-lint`, Gitleaks och exakt Lokalise-läsning tillbaka (`is_unverified: false`). `msgfmt` är inte tillämpligt på JSON-katalogen.
