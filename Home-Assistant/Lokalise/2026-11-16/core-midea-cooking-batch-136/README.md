# Midea: matlagningslägen, del tre

24 svenska Midea-strängar har granskats, sparats och lästs tillbaka i Lokalise. Batchen omfattar ingredienser, ångkokning, upptining, rengöring och värmehållning.

Kontroller: `l10n-lint`, Gitleaks och exakt Lokalise-läsning tillbaka för samtliga poster (`is_unverified: false`). `msgfmt` är inte tillämpligt på JSON-katalogen.
