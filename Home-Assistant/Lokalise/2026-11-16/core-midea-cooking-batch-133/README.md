# Midea: matlagningslägen

19 svenska Midea-strängar har granskats och sparats i Lokalise. De täcker barnlås och grundläggande matlagningslägen med vanliga svenska namn på ingredienser och tillagningsmetoder.

En tvetydig källa, `Bake swing`, har medvetet lämnats utanför denna batch för separat källkontroll i stället för att få en gissad översättning.

Kontroller: platshållarparitet, `l10n-lint`, Gitleaks samt Lokalise-sparning med läsning tillbaka av samtliga 19 poster (`is_unverified: false`). `msgfmt` är inte tillämpligt på JSON-katalogen.
