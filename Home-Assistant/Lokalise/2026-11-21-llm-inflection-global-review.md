# Home Assistant Core – LLM:en

Tre aktuella hjälptester rättades från `LLMen` till `LLM:en`:
OpenRouter samt OVHcloud AI Endpoints (inställning och omkonfigurering).
Kolonet är svensk böjningsmarkering efter förkortning. Två sparades via API
och den tredje var redan korrekt vid live-läsning; samtliga nyckelidentiteter
och texter verifierades.
