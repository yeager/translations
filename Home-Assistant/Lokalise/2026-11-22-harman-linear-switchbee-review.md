# Harman Luxury, Linear Garage Door och SwitchBee: komponentgranskning

Samtliga 27 svenska strängar för Harman Luxury (9), Linear Garage Door (10)
och SwitchBee (8) lästes från Lokalise API och granskades rad för rad den 22
november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar anslutnings- och autentiseringsfel, värdadresser,
platshållaren `{name}`, avvecklingsinformationen för Linear Garage Door och
dess länkplatshållare `{nice_go}` och `{entries}`.
