# Persistent Notification: fullständig komponentgranskning

Samtliga femton svenska strängar lästes från Lokalise API och granskades rad
för rad den 22 november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar skapande, avfärdande och radering av beständiga
aviseringar, meddelande, rubrik och aviserings-ID.
