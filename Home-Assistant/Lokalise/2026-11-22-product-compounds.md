# Produktsammansättningar och FRITZ!Box-fel

Tre Core-strängar rättades via Lokalise API den 22 november 2026 och lästes
tillbaka efter sparning.

| Nyckel | Ändring |
| --- | --- |
| `component::ekeybionyx::config::step::webhooks::data_description::url` | `Home Assistant instans` → `Home Assistant-instansen` och formuleringen för URL:en gjordes grammatisk. |
| `component::fritz::exceptions::service_dial_failed::message` | Den fragmentariska satsen ersattes med `Det gick inte att ringa. Kontrollera att FRITZ!Box-tjänsten ”klicka för att ringa” är aktiverad.` |
| `component::roborock::issues::cloud_api_used::description` | `Roborock integrationen`, `moln API` och `Home Assistant instans` → korrekta sammansättningar. |

Platshållaren `{device_name}` är bevarad.
