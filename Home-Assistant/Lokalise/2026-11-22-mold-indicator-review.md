# Mold Indicator: fullständig komponentgranskning

Samtliga 19 svenska strängar lästes från Lokalise API och granskades rad för
rad den 22 november 2026. Alla var korrekta; ingen ändring behövdes.

Granskningen omfattar kalibreringsfaktor, sensorer för inom- och
utomhustemperatur och luftfuktighet, entitets-ID, hjälpare samt fel- och
alternativsflöden.
