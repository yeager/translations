# Sparade ändringar: Roomba och Google Travel Time

Datum: 2026-11-20

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Roomba: begriplig status för förkortad BLID.
- Google Travel Time: källtrogen beskrivning av platsformat och korrekt ruttinställning för kollektivtrafik.
