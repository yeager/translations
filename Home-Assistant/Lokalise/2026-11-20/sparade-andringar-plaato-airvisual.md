# Sparade ändringar: Plaato och AirVisual

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Plaato webhook: fungerande rubrik och Markdown.
- AirVisual: tydliga formuleringar för plats via koordinater respektive stad, delstat och land samt rubriken ”Konfigurera en plats”.
