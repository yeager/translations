# Sparade ändringar: FRITZ!Box, motionEye och Modern Forms

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- FRITZ!Box: korrekt betydelse av hemma-intervallet.
- motionEye: korrekt interpunktion i tilläggsinstruktionen.
- Modern Forms: idiomatisk integrationstext och korrekt term ”fläkt”.
