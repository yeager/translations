# Sparade ändringar: SMA och Lyric

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- SMA: feltexten anger korrekt att anslutningen lyckades, plus tydligare enhetsinformation och konfigurationsrubrik.
- Lyric: konsekvent återautentiseringsformulering.
