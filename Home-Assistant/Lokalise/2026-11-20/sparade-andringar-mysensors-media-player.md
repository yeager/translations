# Sparade ändringar: MySensors och mediaspelare

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- MySensors: två aktiva konfigurationsrubriker och korrekt sammansättning i Gatewaytyp.
- Mediaspelare: korrekt fullständig pausutlösare med verbet ”är”.
