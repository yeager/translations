# Sparade ändringar: Google Cast, sensorer, KMTronic och Hive

Datum: 2026-11-20

Sex svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Google Cast: korrekt singular och fungerande beskrivning av kända värdar.
- Sensorer: idiomatisk ordföljd för koldioxid- och kolmonoxidkoncentration.
- KMTronic: tydlig invertering av brytarlogik.
- Hive: ren Markdown och tydlig förfrågan om ytterligare kod.
