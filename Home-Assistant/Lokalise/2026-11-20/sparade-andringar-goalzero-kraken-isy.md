# Sparade ändringar: Goal Zero, Kraken och ISY

Datum: 2026-11-20

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Goal Zero: tydlig DHCP-reservering och korrekt routerreferens.
- Kraken: finansspråk för bevakade tillgångspar.
- ISY: tydlig status för händelseanslutningen.
