# Sparade ändringar: FRITZ!Box Tools och ZHA-alternativ

Datum: 2026-11-20

Fem svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- FRITZ!Box Tools: konsekvent produktnamn och tydlig titel för autentiseringsuppgifter.
- ZHA: enklare larminställningar och korrekt sammansättning i belysningsövergångstid.
