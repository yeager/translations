# Sparade ändringar i Lokalise – Yale Access Bluetooth

Datum: 2026-11-20

Fyra svenska Yale Access Bluetooth-översättningar har granskats, sparats via Lokalise API och lästs tillbaka ordagrant från API:t.

- Enhetliggjorde sammansättningen ”offlinenyckel”.
- Rättade beskrivningen av hexadecimal sträng på 32 byte.
- Tog bort felaktigt blanksteg före frågetecken.

Ändrade nycklar: `204293331`, `204293332`, `204293335`, `204293337`.

TMX-posterna är verifierade mot engelskt källinnehåll och märkta `saved-and-read-back`.
