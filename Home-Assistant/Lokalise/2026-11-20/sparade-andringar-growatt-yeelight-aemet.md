# Sparade ändringar: Growatt, Yeelight och AEMET

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Growatt: solanläggningar i stället för botaniska växter samt korrekt val av autentiseringsmetod.
- Yeelight: konsekvent konfigurationsfråga.
- AEMET: korrekt sammansättning i väderstationer.
