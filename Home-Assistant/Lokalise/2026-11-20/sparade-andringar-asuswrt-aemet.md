# Sparade ändringar: ASUSWRT och AEMET

Datum: 2026-11-20

Sex svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- ASUSWRT: tydligare router-, tidsgräns-, gränssnitts-, IP-adress- och spårningsinstruktioner.
- AEMET: idiomatisk instruktion för att skapa en API-nyckel.
