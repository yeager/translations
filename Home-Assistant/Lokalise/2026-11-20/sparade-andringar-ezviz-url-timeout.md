# Sparade ändringar: EZVIZ URL och tidsgräns

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- EZVIZ: korrekt varumärkesskrivning, IP-adress, URL-formulering och URL-sammansättning.
- Begärans timeout: svensk beteckning ”Tidsgräns”.
