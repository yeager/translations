# Sparade ändringar: Waze, Nuki och EZVIZ

Datum: 2026-11-20

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Waze: korrekt term ”restidsberäkning”.
- Nuki: tydlig aktiv återautentisering med bryggan.
- EZVIZ: fullständig instruktion för saknat molnkonto.
