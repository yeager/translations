# Sparade ändringar: Buienradar och System Bridge

Datum: 2026-11-20

Två svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Buienradar: tydlig prognoshorisont för nederbörd.
- System Bridge: återställer inloggning med nyckel eller parkopplingskod enligt källtexten.
