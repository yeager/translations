# Sparade ändringar: Modern Forms, WLED och Xiaomi Miio

Datum: 2026-11-20

Fyra svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- Modern Forms: korrekt upptäcktsrubrik för fläkt.
- WLED: huvudreglaget beskrivs korrekt även för ett LED-segment.
- Xiaomi Miio: begriplig värdadress-/token-varning och komplett text om molnuppgifter.
