# Sparade ändringar: MySensors MQTT

Datum: 2026-11-20

Tre svenska Home Assistant Core-översättningar sparades via Lokalise API och lästes tillbaka ordagrant.

- `not_a_number`: använder ”tal” konsekvent för numeriska värden.
- MQTT retain: tydlig konsekvens av inställningen, ”Behåll MQTT-meddelanden”.
- MQTT-gateway: aktiv och kort rubrikform.
