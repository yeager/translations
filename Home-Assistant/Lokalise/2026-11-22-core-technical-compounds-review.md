# Home Assistant Core – tekniska sammansättningar

Sju live-verifierade etiketter rättades: `AC-in-1`, `Molnrecept`,
`Batteriöverspänning`, `Gör-det-själv 2`, `Att-göra-lista`, `Högspänning`
och `Lågspänning`. Tvetydigare former som `Frost lock`, `Eco dry` och
`Anti-legionella` lämnades för separat begreppskontroll.
