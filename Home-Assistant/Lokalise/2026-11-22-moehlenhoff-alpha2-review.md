# Home Assistant Core – Möhlenhoff Alpha2

Datum: 2026-11-22

Komponentens sex strängar är granskade rad för rad mot aktuell engelsk källa
och återlästa via Lokalise API. Ingen ändring behövdes.

| Nyckel | Svenska |
| --- | --- |
| `component::moehlenhoff_alpha2::config::abort::already_configured` | Enheten är redan konfigurerad |
| `component::moehlenhoff_alpha2::config::error::cannot_connect` | Det gick inte att ansluta |
| `component::moehlenhoff_alpha2::config::error::unknown` | Oväntat fel |
| `component::moehlenhoff_alpha2::config::step::user::data::host` | Värd |
| `component::moehlenhoff_alpha2::config::step::user::data_description::host` | Värdnamnet eller IP-adressen för ditt Möhlenhoff Alpha2-system. |
| `component::moehlenhoff_alpha2::title` | Möhlenhoff Alpha2 |

Inga platshållare, pluralformer eller referenser berörs. Hunspell och svlang
ger endast förväntade träffar för produktnamnet. Lokalise API:s
verifieringsflagga är inte skrivbar med projektets behörighet; granskningen är
spårad här.
