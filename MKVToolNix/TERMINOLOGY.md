# MKVToolNix: svensk terminologi

Senast uppdaterad: 13 november 2026. Listan gäller programgränssnittet och
kommandoradshjälpen i `programs`; Matroska-, codec- och standardnamn behålls
när de är etablerade egennamn eller protokolltermer.

| Engelska | Svenska | Sammanhang och undantag |
| --- | --- | --- |
| chapter | kapitel | Metadata-/kapitelredigeraren. |
| mass modification | massändring | `Massändring av kapitel`; svensk sammansättning, inte versal intern rubrik. |
| track | spår | Ljud-, video- och undertextspår. |
| segment | segment | Matroska-struktur och UID-etiketter. |
| timestamp | tidsstämpel | Start-, slut- och kapitelvärden. |
| multiplexer | multiplexer | Program- och verktygsnamn i gränssnittet; undvik att försvenska produktnamnet `mkvmerge`. |
| source file | källfil | Filer som läggs till i multiplexern. |
| directory | katalog | I filval och inställningar; `mapp` används bara när texten avser användarens målmapp. |
| drag and drop | dra och släpp | UI-handling; använd inte tekniskt `drag & drop` i löpande svensk text. |
| escape | escape | Behålls i `escape-läge` och `escape-argument`, eftersom det är en synlig teknisk funktion i programmet. |
| UID | UID | Teknisk identifierare och synlig etikett; skrivs inte ut. |
