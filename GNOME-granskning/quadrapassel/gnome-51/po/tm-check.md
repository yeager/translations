# GNOME TM-kontroll — Quadrapassel gnome-51/po

Exakta TM-träffar kontrollerades och användes som stöd: `_Keyboard Shortcuts` → `_Kortkommandon`, `Start a New Game` → `Starta ett nytt spel`, `Pause the game` → `Pausa spelet`, `Score` → `Poäng`, `Preferences` → `Inställningar`, `Rows` → `Rader`, `Level` → `Nivå`, `Fit falling blocks together` → `Passa ihop fallande klossar` och `Game` → `Spel`. Övriga strängar bedömdes i spelkontext; inga osäkra TM-förslag kopierades.
