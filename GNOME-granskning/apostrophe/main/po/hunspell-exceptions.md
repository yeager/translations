# Hunspell-SV – rimliga undantag

Kontrollerat med den utökade hunspell-sv-ordlistan. Följande okända former är egennamn, produkt-/formatnamn, källkodstermer, acceleratorfragment eller godtagbara sammansättningar/böjningar; de är inte stavfel i den här katalogen.

- Apostrophe / Apostrophes / UberWriter / uberwriter / aA (exempelformat)
- Produkt- och formatnamn: Markdown, TeX Live, TeX, LaTeX, LibreOffice, HTML, PDF, Pandoc, JavaScript, Word, filändelsen md
- Personnamn: Manuel Genovés, Wolf V., Åke Engelbrektson. Även den avsiktliga exempelformateringen aA lämnas som den är.
- Sammansättningar och böjningar som saknas i ordlistan: autosparningen, Markdown-redigerare, Markdown-varianten, sepiafärger, Hemingway-notis/notiser, indataformat, automatiska sparningar
- Acceleratorernas markering kan ge ordfragment som Öppna eller Stäng; tecknen Ö och Ä står här inte efter acceleratorunderstrecket och används alltså inte som nordiska acceleratorer.
