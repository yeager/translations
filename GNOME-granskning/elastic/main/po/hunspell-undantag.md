# Hunspell-undantag — Elastic

Kontrollerade stavningsflaggningar:

- `Elastic`, `Adwaita`, `libadwaita`, `GTK`: produkt- och plattformsnamn.
- `Mikhaylenko`: personnamn.
- `JavaScript`, `Python`, `Rust`, `Vala`: namn på programspråk.
- `.0lf`, `.2lf`: tekniska formatsträngar.
- `fjäderfysikbaserade`: korrekt svensk sammansättning som Hunspell inte känner igen.

Inga felstavade svenska strängar hittades.
