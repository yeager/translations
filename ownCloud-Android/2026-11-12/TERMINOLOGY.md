# ownCloud Android – svensk terminologi

| Källterm | Rekommenderad svensk term | Kontext och undantag |
| --- | --- | --- |
| share | delning | UI för att skapa, redigera och ta bort fil- eller mappdelningar. |
| remove share | ta bort delning | Åtgärdsetikett; status använder ”Delningen har tagits bort”. |
| edit share | redigera delning | Åtgärdsetikett. |
| file / folder | fil / mapp | Etablerad Android- och ownCloud-terminologi. |
| permanent link / permalink | permanent länk | Versionsnotis; inte ”permalänk” i denna UI-kontext. |
| Infinite Scale | Infinite Scale | Produktnamn, översätts inte. |
| member | medlem | Medlem i delning eller samarbete. |
