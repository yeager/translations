# Wireshark, svensk terminologi

| Engelska | Svenska | Kontext |
| --- | --- | --- |
| display filter | visningsfilter | Wiresharks filterfält och statistikdialoger. |
| field | fält | Protokollfält, inte UI-fält i allmän bemärkelse. |
| distribution | fördelning | Statistisk fördelning av fältvärden. |
| I/O Graph | I/O-diagram | Synligt funktionsnamn med svensk beskrivning. |
| packet | paket | Nätverkspaket. |
| event | händelse | Händelsedata, åtskilt från paket. |
| protocol | protokoll | Nätverksprotokoll. |
| value | värde | Fältvärde eller räknat värde. |
| count | antal | Kolumn och statistikvärde. |
| resolve values | slå upp värden | Namn- och värdeuppslagning i statistikdialogen. |
| Theme Designer | temadesigner | Verktyg för att skapa gränssnittstema. |
