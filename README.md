# Svenska översättningar

Här samlas kopior av färdiga svenska översättningar och tillhörande granskningsunderlag.

- **Tenacity:** komplett svensk PO- och MO-katalog, kontrollerad med `msgfmt` och lokal Hunspell `sv_SE`.
- **mc6:** komplett svensk PO-katalog för M-Commander, publicerad och återläst från Codeberg Weblate.
- **Midnight Commander:** en kompatibel svensk katalog, framtagen från mc6 och kontrollerad med `msgfmt`; den är avsedd för import i Transifex.
- **Codeberg Weblate:** arbetsjournal för de komponenter som har uppdaterats och verifierats under den pågående tjänsteomfattande granskningen.

Hemliga nycklar, autentiseringsuppgifter och API-svar med känslig information ingår inte.
