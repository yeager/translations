# Svenska översättningar

Här samlas svenska översättningar och tillhörande granskningsunderlag. Tabellen är ett register över projektmappar med Git-spårade filer; den visar arkivets innehåll, inte automatiskt vad som är publicerat eller färdiggranskat.

Senaste arkivändring är datumet för den senaste Git-incheckningen som berör mappen. Datumet kan avse underlag eller en del av projektet och är inte en kontroll av upstream. Länkarna till underlag visar historisk dokumentation, vars uppgifter kan ha ändrats. Uppdatera tabellen när arbete, granskning eller verifierad upstreamstatus ändras.

Övergripande dokument: [statusjournal](STATUS.md), [väntande upstreamarbete](PENDING_UPSTREAM.md), [policy för aktuell release](RELEASE-FRESHNESS-POLICY.md), [arkiverade projekt](PROJECTS-TOUCHED-20261030.md) och [bloggposten om översättningsarbetet](BLOGGPOST-OVERSATTNINGSARBETE-20261030.md).
