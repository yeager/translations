# RetroAchievements: svensk terminologi

Den här listan gäller webbgränssnittets flöde för rapporterade prestationer och topplistor. Termval ska alltid kontrolleras mot den konkreta skärmbilden och handlingen.

| Engelska | Svenska | Anmärkning |
| --- | --- | --- |
| ticket | ärende | Ett fel- eller granskningsärende, inte en biljett. |
| reporter | rapportör | Personen som lämnat rapporten. Äldre poster med *anmälare* bör bedömas i sin specifika kontext. |
| claim (ticket workflow) | reservation | Anger att en underhållare tar ett ärende temporärt. Undvik *anspråk*, som har fel betydelsenyanser i gränssnittet. |
| claim ticket | reservera ärendet | Åtgärdsknapp för att ta hand om ärendet. |
| release claim | släpp reservationen | Avslutar den tillfälliga tilldelningen. |
| maintainer | underhållare | Ansvarig för det aktuella granskningsflödet. |
| achievement | prestation | RetroAchievements etablerade UI-term. |
| leaderboard | topplista | Resultatlista för spelprestationer. |
| demote | nedgradera | Statusändring för prestation eller topplista. |
| unpromote | ta bort framhävningen | Tar bort en topplistas framhävda status. |
| logic change | logikändring | Ändring av villkoren som avgör en prestation eller topplista. |
| note (ticket workflow) | meddelande | Text till rapportören i ärendeflödet. |
| subscribe to a ticket | prenumerera på ett ärende | Följ ärendet och få dess uppdateringar. `Subscribed Tickets` blir **Prenumererade ärenden**. |

Platshållare som `{{duration}}`, `{{date}}`, `{{user}}` och taggar som `<1>...</1>` måste bevaras byte för byte.
